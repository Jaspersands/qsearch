edit and send, or not send.

| Draft | Audience | Result |

report. If the paper's numbers change, update the drafts by hand.

- Fill in the recipients and the repository link. Every placeholder is in square brackets.
- Confirm that the cited papers are the right ones for each recipient.
- Decide whether to attach the paper draft, which is marked "not for circulation".

  Each draft says so. Keep that sentence.
