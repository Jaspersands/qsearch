# Review: differential/specialization algorithm for growing unit tuples (rational prime-domain branch)

## Verdict

**I found no fatal mathematical or cost error, so I give conditional acceptance.** The identity Rel_A(u) = L ∩ M is a correct deduction from the prime/domain promise. Every step that could be exponential in k stays polynomial.

Three source and bit-size obligations remain open (Section 4). One step should be tightened as a fix, not a patch: force the specialization B to be étale, i.e. a product of number fields. That removes any dependence on Lenstra–Silverberg (LS) handling nonreduced algebras. Hand computations on two finite cases are consistent with the claim. They are finite controls only.

## 1. Cheapest attacks first

**A1. Prescribed toy instance (computed by hand; no tools were run).**
- Setup: A = Q[x,y]/(xy−1), with T = {x}, y = 1/x, g = x, and specialization a = 1.
- L: every w_i is a multiple of dx/x, giving the row (1,2,4,1). So L = {e₁+2e₂+4e₃+e₄ = 0}.
- M: the images are (2,3,12,1). Then M = {e₁+2e₃ = 0, e₂+e₃ = 0}, with e₄ free.
- Intersection: substituting gives −2e₃−2e₃+4e₃+e₄ = e₄ = 0. So L ∩ M = Z·(−2,−1,1,0).
- Check: (2x)⁻²(3x²)⁻¹(12x⁴) = 1. The two "single-filter" vectors fail as the document states.

This instance does **not** test the crucial step, faithfulness on C, because there C = Q.

**A2. Stronger control (proposed; computed by hand).** This case has a nontrivial algebraic constant field.
- Setup: A = Q[x,y,z]/(y²−2x², xz−1). The ideal is prime because y²−2x² is irreducible over Q. Put t = yz, so t² = 2 and C = Q(√2).
- Units: (x, t, 1+t, 2, x²t).
- Log rows: L = {e₁ + 2e₅ = 0}.
- Specialize x = 1, giving B = Q(√2). The images are (1, √2, 1+√2, 2, √2).
- M = {e₃ = 0, e₂+e₅+2e₄ = 0}.
- Expected Rel basis: (−2,−1,0,0,1) and (0,−2,0,1,0). Both check exactly.

This exercises injectivity of ρ on C ≠ Q. Recommend this as the single exact control instead of, or in addition to, A1.

**A3. Promise attack.** If the input is not prime, then L ∩ M ⊋ Rel is possible; the document's Q[x,x⁻¹]×Q example shows this. The algorithm cannot detect the violation.
- The output is guaranteed only under the promise.
- This must be stated as a promise problem, not an algorithm on all inputs.
- Unit-hood (u_i·u_i′ ≡ 1 mod I) *is* checkable by fixed-m ideal membership and should be checked.

**Computing L with growing k.** Better than one giant system:
- Compute N_{≤2D−1} = N ∩ (Q[X]^m)_{≤2D−1} once, independent of k.
- Then compute the kernel of Q^k → W/N_{≤2D−1}, where W has dimension m·C(m+2D−1, m).
- Finish with HNF to get the integer saturation.
- The k right-hand sides only add columns. The membership degree bound depends on target degree 2D−1 and generator degree, not on k.

**B nonzero and ρ a ring hom.**
- Let O be the Q[T]_g-span of the standard monomials. Then O = A[1/g]: O is generated by monomials in A, and the map is injective.
- O is free of rank δ ≥ 1, so B = O/(T−a)O ≠ 0 and ρ: A → B is a unital ring hom.
- Unit/inverse identities hold automatically because B is a quotient ring.

## 3. Cost points the document gets slightly wrong or loosely

1. **g need not involve the units.** Since each uᵢ ∈ A ⊂ O = Q[T]_g-span, uᵢ's coordinates already lie in Q[T]_g.
   - g should be built from the structure constants and the coordinates of the variables only. Then deg g is independent of k.
   - Compute ρ(uᵢ) by evaluating the given representative at ρ(X) inside B, using B's multiplication tables. This costs poly(D^m, δ) operations, with bit growth linear in D.
   - This avoids reducing k rational-function normal forms.
2. **Force B to be étale.** Multiply g by the discriminant of the trace form of F0/Q(T). It is nonzero because F0 is a separable field extension (char 0). Then B is a product of number fields. This removes the question of whether LS Theorem 1.11 needs reduced E.
3. **Point search.** A grid of size (deg g + 1)^|T| with |T| ≤ m is deterministic and polynomial. This is fine.
4. **Exponent sizes.** No unit power is ever expanded; only lattices and coordinates are manipulated. Output entries may be as large as k!·D^{(m+1)k} in magnitude, but that is polynomial *bit* length. This is consistent.

## 4. Remaining obligations (exact statements)

**O1 — Lenstra–Silverberg Theorem 1.11(i).** The excerpt does not fix the encoding. Confirm three things from the actual text:
- (a) A "Q-algebra" is a commutative finite-dimensional Q-algebra given by rational structure constants. MU's paraphrase says so, but that is secondary.
- (b) The running time is polynomial in total input length with |S| unrestricted. "Finite system S" suggests yes, but the excerpt does not say.
- (c) Whether E may be nonreduced. This is moot if the étale fix is adopted.

The output is a generating set, which is then reduced by HNF.

**O2 — Fixed-variable module membership bound.** The excerpt states Hermann only for ideals (MU Lemma 2.5, citing [2, Thm 3.4]). Supply the reduction:
- Identify N ⊂ Q[X]^m with the ideal J ⊂ Q[X,Y₁..Y_m] generated by Σ_l f_j Y_l-type linear forms.
- Take the Y-degree-1 component of a Hermann representation.
- This uses s = 2m fixed variables and degree D+1.
- Check that the cited bound is independent of the number of generators, here r(m+1).

**O3 — Bit sizes over Q(T).** The proposal needs a lemma that the following have T-degree and height polynomial in the input for fixed m:
- the Gröbner basis G (elimination order) over Q;
- the structure constants of F0;
- the variable coordinates.

A viable proof route:
- Dubé-type degree bound Γ = D^{2^{O(m)}}, with G computed by Macaulay-matrix linear algebra over Q.
- Normal forms of products of standard monomials (degree ≤ 2Γ) via Hermann over Q(T) in |X∖T| variables.
- Then Cramer over Q[T], which gives T-degree ≤ (system size)·D and polynomial height. Uniqueness of the coordinates makes the Cramer solution the coordinate vector.
- KW Prop. 5.1(b) (G remains Gröbner over Q(T)) and (c), with I : h^∞ = I for prime I and h ∈ Q[T]∖0, justify clearing denominators.

This must be written, not cited as "standard."

**O4 — Scope statement.** The guarantee covers only the following, and is not an algorithm verifying primality:
- prime I over Q, fixed m;
- dense or polynomially bounded numerical degrees;
- inverses supplied and charged;
- polynomial in total length ≥ k.

Nonprime, nonreduced, positive-characteristic and growing-m inputs remain excluded.

## 5. Falsifiers that would overturn acceptance

- **LS Theorem 1.11 restricts |S|**, or is polynomial only for fixed |S|. Then the k-dependence returns and the claim fails at step 3.
- **The Q(T) normal forms need superpolynomial T-degree** for fixed m. Then g or B would be too large and O3 fails.
- **A prime-domain instance where the computed L ∩ M ≠ Rel.** This would contradict a proved lemma, so it would indicate an implementation or representation error. Most likely causes: a nonsaturated L, or ρ computed on reduced representatives inconsistently with B's multiplication.

Passing A1/A2 is a finite check only. The all-input claim rests on the proofs above plus O1–O3.
