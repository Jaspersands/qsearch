# Disposition of the dyadic unit-norm lemma for quadratic orders

## Verdict

I found **no counterexample.** The central lemma is correct as stated:

- the generator list,
- squarehood of the deep tail,
- the norm-image test,
- the scalar correction,
- the square-root loop, including the j = 2e step,
- the binary realization.

There are four places where the statement should be tightened. None of them is a mathematical error.

1. **Precision is under-specified.** To output z mod π^L you need c = Norm(u)/η mod π^(L+e). So η and u must be supplied to that precision.
2. **The binary output is a nearby exact vector, not the requested η.** A finite-precision preimage gives an *exact* lattice vector of norm aη′, where η′ ≡ η mod π^L. It does not give norm exactly aη. This is harmless at squareclass level once L ≥ 2e+1, but it must be stated.
3. **Separability is never used.** The hypothesis that F⊗R is separable can be dropped. Only nondegeneracy (b ≠ 0) is needed in the lattice section.
4. **The quadratic-form convention must be fixed.** The note uses q(x) = B(x,x). With q(x) = B(x,x)/2, T changes and the formulas must be redone.

The cheapest decisive attacks (unit-norm closure, odd-j squarehood, solvability at j = 2e, the tail binomial bound) all fail. Proofs follow.

## 1. Generators of R^*/R^*2 (proved)

**Reduction to residue and filtration.** Let A = R/πR = k[X]/(X² + T̄X + N̄), using characteristic 2. Reduction R^* → A^* is surjective, with kernel U_1.

- Let u ∈ R^*. Write ū = g̅·s̄², where g̅ is a product of chosen generators of A^*/A^*2 and s̄ ∈ A^*.
- Lift s̄ to any s. Then u = g·s²·w with w ∈ U_1.
- So R^*/R^*2 is generated by lifts of generators of A^*/A^*2 together with the image of U_1.

**Filtration layers.** For j ≥ 1, (1+π^j a)(1+π^j b) ≡ 1+π^j(a+b) mod π^(j+1), because 2j ≥ j+1. So U_j/U_(j+1) ≅ R/πR additively.

- R/πR = k ⊕ kθ̄ has F2-basis {β̄_i, β̄_i θ̄}.
- Hence U_1 is generated by the 4ef elements 1+π^jβ_i and 1+π^jβ_iθ (1 ≤ j ≤ 2e), together with U_(2e+1).

**Residue cases.**

- **T̄ ≠ 0.** The polynomial is separable. A is F_(q²) or k×k, with |A^*| equal to q²−1 or (q−1)², which is odd. Squaring is bijective, so no generators are needed.
- **T̄ = 0.** The polynomial is X² + N̄ = (X+r)² with r = N̄^(2^(f−1)), computed with f squarings. Then A = k[ε]/ε² with ε = θ̄ + r.
  - (a + bε)² = a², so A^*2 = k^*.
  - Hence A^*/A^*2 ≅ 1 + kε ≅ k, an f-dimensional F2-space.
  - It is spanned by 1+β̄_iε. The lifts 1+β_i(θ−r̃) are units, since their residue is 1+β̄_iε.
- This covers nonmaximal orders: Z2[2^k i] has T̄ = 0, r = 0. It covers ramified and unramified cases. It covers the split case: T̄ = 1 gives k×k.

The total is 4ef or 4ef+f, so at most (4e+1)f. Only a generating set is needed and only a generating set is claimed. Note that for separable A, the even layers j < 2e are redundant, since (1+π^(j/2)s)² = 1+π^j s² + (higher). This makes the list overcomplete, which is harmless.

## 2. Tail squarehood inside R (proved)

v₂ of binom(1/2, j) equals s₂(j) − 2j, where s₂ is the binary digit sum. This is at least 1 − 2j. So the coefficient has F-valuation at least −(2j−1)e.

For X ∈ π^(2e+1)R, each term lies in π^(j(2e+1) − (2j−1)e)R = π^(j+e)R. The series converges in the complete free O-module R. The power-series identity (Σ)² = 1+X holds in any commutative complete O-algebra.

Nothing about maximality, field-ness or separability is used. The bound is exactly as in the note.

## 3. Norm-image membership and scalar correction (proved)

**Unit-norm elements are units.** Let α ∈ R and put ᾱ := T − α. Since θ̄ = T − θ ∈ R, we have ᾱ ∈ R and αᾱ = N(α). If N(α) ∈ O^*, then α^(−1) = ᾱ/N(α) ∈ R. So {α ∈ R : N(α) ∈ O^*} = R^*. Thus "unit norm of an R-element" and "norm of an R-unit" coincide.

**Membership test.**

- O^* ⊂ R^*, so N(R^*) ⊇ N(O^*) = O^*2.
- N(R^*2) ⊆ O^*2.
- So N(R^*) is the full preimage in O^* of its image in O^*/O^*2.
- That image is spanned by the norms of any generating set of R^*/R^*2.
- O^*/O^*2 → F^*/F^*2 is injective, because a unit that is a square in F is the square of a unit.

Hence η ∈ N(R^*) if and only if [η] lies in the F2-span of [N(g_i)]. The test is a single linear system.

**Scalar correction.** Suppose N(u) = ηz². Then z ∈ O^* ⊂ R^*, so u/z ∈ R^* and N(u/z) = η. The order is preserved because the correction is a scalar unit of O.

**Encoding.** Each class depends only on its residue mod π^(2e+1), by §2 applied to F. So:

- the generator norms N(1+π^jβθ) = 1 + π^jβT + π^(2j)β²N need only T, N mod π^(2e+1);
- any lift to K is a valid Hilbert-symbol input.

## 4. Scalar square-root loop (proved, with a precision repair)

Let c ∈ O^* be a known square. Start with ȳ = c̄^(2^(f−1)) and set j = v(c − y²).

**Odd j below 2e is impossible.** Write c/y² = 1+w and suppose 1+w = (1+t)² with v(t) = s, so w = 2t + t².

- If s < e, then v(w) = 2s.
- If s > e, then v(w) = e+s > 2e.
- If s = e, then v(w) ≥ 2e.

So v(w) < 2e forces v(w) to be even.

**Steps with j = 2r < 2e.** Take d̄ = γ̄^(1/2), where γ = (c−y²)/π^(2r). The cross term 2π^r yd has valuation e+r > 2r. So the valuation of the error strictly increases. There are at most e such steps.

**Step with j = 2e.** Let y′ be a square root of c and s = y′ − y with v(s) = t. Then y′² − y² = s(s+2y).

- If t < e, the valuation would be 2t < 2e, a contradiction.
- So t ≥ e. Writing s = π^e d gives exactly c − y² = π^(2e)(d² + (2/π^e)y d).
- So the residue equation is solvable, and t = e is forced because j = 2e exactly.
- The map d ↦ d² + ū₀ȳd, with u₀ = 2/π^e ∈ O^*, is F2-linear on k. Solve it with one f×f F2 system.
- The update leaves error valuation at least 2e+1.

**Steps with j = s ≥ 2e+1.** Use y += π^(s−e)d with d̄ = γ̄/(ū₀ȳ). The square term has valuation 2s−2e > s, so the step is linear and involves no division by 2. Newton's method also works: the excess m − 2e doubles each step, at a cost of about e guard digits. j may jump past 2e directly; that is fine.

**Precision repair.** z mod π^(s−e) is determined by c mod π^s. So outputting u/z mod π^L requires:

- u mod π^(L+e), in R/π^(L+e)R;
- η mod π^(L+e).

The note's "e guard digits" is consistent with this, but it should state the input-precision requirement on η explicitly.

## 6. Binary lattice realization (correct; caveats)

**Setup.** Take x with q(x) = a generating nL. Then x is primitive, since π·x′ has norm in π²nL. Extend to a basis (x, y). Since 2B(x,y) and q(y) lie in nL = aO:

- T = 2c and N = q(y)/a are integral;
- c itself may be nonintegral, which is harmless;
- q(px+qy) = a(p² + Tpq + Nq²);
- y − cx has norm b = q(y) − ac², and det Gram = ab.

**Correspondence.** By §3, {v ∈ L : q(v) ∈ aO^*} = {px+qy : p+qθ ∈ R^*}. So the operation decides exactly whether aη is represented by L. Every such v is primitive.

**New basis.** Extend to a unit-determinant basis: take w = p^(−1)y if p is a unit, or w = −q^(−1)x if q is a unit. Then:

- q(w_⊥) = ab/(aη) = b/η;
- O w_⊥ = pr_(v⊥) L, so w_⊥, and any unit multiple such as ηw_⊥ (norm bη), is a norm generator of the projection;
- hence (v, ηw_⊥) is a BONG of the same lattice L.

**BONG versus integral basis.** (v, w) is an integral basis of L. (v, w_⊥) is generally not contained in L: w_⊥ ∈ L only if B(v,w)/q(v) ∈ O. A transporter must carry both:

- the GL2(O) change of basis (x, y) → (v, w), which is the actual lattice data;
- the BONG pair, which is invariant bookkeeping.

The note distinguishes these correctly.

**Finite precision.** Let p, q be the truncations mod π^L lifted to K. Then v is an exact lattice vector with q(v) = aη′ exactly, where η′ ∈ ηU_L.

- For L ≥ 2e+1, the classes [η′] = [η], so the BONG ≺aη′, bη′≻ is exact and in the right squareclasses.
- Exact equality with aη generally requires an irrational unit √(η/η′). Finite output cannot supply it.
- Any downstream step that compares BONG entries as elements, not squareclasses, must be audited for this.

**Scope of the move.** Every BONG ≺a′, b′≻ of L has a′ = aη with η a unit and b′ ∈ (b/η)O^*2. Hence:

- this operation, together with exact rational rescaling by s ∈ O^*, realizes every binary BONG change *within a fixed lattice*;
- matching a prescribed b′ exactly needs an explicit root of b′η/b, which is again the §4 loop and is again finite-precision.
