# New parent proposal: torus logarithms plus vertical valuations

Full native growing-delta sparse relation contract is unchanged. GeneralAlg is already classically computed. This is a different operation from leading-place or cyclotomic specialization: approximate ARCHIMEDEAN logarithms at a random complex torus point, then combine with finite vertical valuations. Neither piece alone is an algorithm.

Parent elementary analytic proposal to attack: for a NONZERO INTEGER multivariate polynomial H with l1norm<=A, iterated Jensen gives m(H)=E_theta log|H(exp(i theta))|>=0. Since log^+|H|<=log A, E log^-|H|<=log A. Thus P(|H|<exp(-t))<=logA/t. Native denominator/norm/discriminant polynomials can be implicit: determinant l1norm bounds have logA polynomial in sparse input bits, although degrees are exponential. Taking t polynomial gives constant-probability simultaneous nonvanishing/conditioning. A dyadic phase grid with resolution paying degree*norm Lipschitz bound needs only polynomially many BITS (logdegree enters). Verify both the argument and complete finite-precision cost, including ALL delta root branches, cancellations, logarithms and correct conjugate embedding grouping of the constant field. Repeated constant-success trials may cost log1/eta; do not use a 1/eta precision as if logarithmic.

If this works, every original u_i has moderate logarithmic absolute values in each complex branch and can be evaluated to polynomially many bits. Multiply these logarithm rows by the known Alg-basis integer matrix without expanding algebraic products. The retained elementary height gap for degree<=delta non-torsion constants is exp(-poly(delta)); with ALL places, this could pay a logarithmic-lattice relation algorithm.
