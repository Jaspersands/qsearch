**Decision criterion (session A, proved; proof checked by the integrator).** Let H's rows span the

- Theorem B′ (n²/4 + 3n/2 + 2) is unaffected. n²/6 at p = 5 needs a selection rule that keeps each
  piece's label set feasible; none is known.
- Later on 11-11 (integrator's pointer): Theorem S in `2026-11-11-rees-sde-p5-below-quarter.md` gets

## Small-set certification (2026-11-11, subagent)

Setting as above (p = 5, S = {0,±1}, d = 3, "feasible" with all α and nondegeneracy per direction).
Code and outputs: `2026-11-11-rees-sde-p5-d3/small/`. All runs local, `nice -n 19`.

**Three lemmas (proved here by hand; elementary).**
- (G) *GL_3 invariance.* If (Φ, γ) is a model for L and M ∈ GL_3(F_5), then Φ*(Mℓ) = Φ(ℓ),
  γ*_α = M^{-T} γ_α is a model for ML: ⟨γ*_α, Mℓ⟩ = ⟨γ_α, ℓ⟩, so y*_α(Mℓ) = y_α(ℓ) for all α, ℓ.
- (±) *Signs.* If −ℓ₀ ∉ L, replacing ℓ₀ by −ℓ₀ with Φ*(−ℓ₀) = −Φ(ℓ₀) gives y*_α(−ℓ₀) = −y_α(ℓ₀)
  (S = −S), same zero pattern, so models correspond. If ℓ₀ ∈ L, adding −ℓ₀ with Φ(−ℓ₀) = −Φ(ℓ₀)
  keeps a model (old nondegeneracy witnesses stay). Hence L is feasible as soon as one transversal
  of its set Q(L) of ±-classes is feasible.
- (M) *Monotonicity.* L ⊆ L′ both spanning, (Φ′, γ′) a model for L′ ⇒ its restriction is a model for L.
  Only nondegeneracy needs an argument. Suppose y_{λα} ≡ 0 on L for all λ ∈ F_5^*. On L′,
  y_{λα} − λ y_α = ⟨γ_{λα} − λγ_α, ·⟩ (the Φ-terms cancel) is linear and vanishes on the spanning set L,
  so it is 0 on L′. Then y_{2α} = 2y_α on L′ with values in S ∩ 2S = {0}, so y_α ≡ 0 on L′ and every
  y_{λα} = λ y_α ≡ 0 on L′, contradicting nondegeneracy of L′. ∎ (Needs only 2S ∩ S = {0}; not the
  criterion. Session B's step (2) is therefore confirmed.)
- With (M), the converse of (±) holds too: feasibility of L is a GL_3-invariant function of
  Q(L) ⊆ Q, the 62 classes {v, −v}. GL_3 acts on Q through GL_3/{±1} (order 744,000).

*Normal form used by `msplit.py` / `sbsat.py` (proof).* For a model (Φ, γ) and A ∈ GL_3(F_5) with rows
a_1, a_2, a_3, put Φ'(ℓ)_j = y_{a_j}(ℓ) and γ'_α = γ_{A^Tα} − Σ_j α_j γ_{a_j}. Then
y'_α = ⟨A^Tα, Φ⟩ + ⟨γ_{A^Tα}, ·⟩ = y_{A^Tα}, so (Φ', γ') is a model (directions are permuted by A^T),
γ'_{e_j} = 0 (N), and (R) is kept. Choose a_1 with |supp y_{a_1}| minimal (= m) over all α,
a_2 minimal outside ⟨a_1⟩, a_3 minimal outside ⟨a_1,a_2⟩, then a_1 ↦ −a_1 if needed: the new model
has |supp y_α| ≥ m for all α, y_{e1} = Φ_1 of support m with first nonzero entry +1, and the level-2/3
support order. Before this, each γ_α may be re-chosen to give a minimum-support S-representative
(with γ_{−α} = −γ_α); the transform preserves that, which justifies `msplit.minrep_supp`.

**(c) Structure of the 1,417 infeasible 10-orbits (cheap statistics, `analyze10.py`; no rule found).**
Compared with the 118,329 feasible orbits without an S-functional:
- not explained by collinearity (every line profile with ≥ 3 collinear points that occurs among the
  infeasible ones also occurs among feasible ones, almost always far more often);
- projective points: 10 classes can lie on 6..10 projective points (ℓ and 2ℓ are different classes on
  one point); the infeasible rate is 0.4% with 10 points and about 1.5% with 7, 8 or 9 points;
- min over functionals g of #{ℓ : ⟨g,ℓ⟩ = ±2} is 1 (663) or 2 (754); it is also 1 or 2 for all but one
  of the feasible ones, so it does not separate;
- |Σ_L| (with 0) is 41,069..46,137 of 5^7 = 78,125; feasible ones range from 29,115 up, so small Σ
  never gives infeasibility here;
- the clearest signal: among the ten 9-subsets, the number having an S-functional has median 1 for
  infeasible orbits (0: 706, 1: 542, 2: 135, 3: 26, 4: 8) against 2 for a 3,000-orbit feasible sample.
  So infeasible 10-sets are those that are "far" from every S-functional, but this is a tendency,
  not a criterion. A piece-selection rule must keep label count ≤ 9, or test the criterion
  (9 ms average per 10-set in `feas.c`, about 0.6 s when infeasible) and re-select.
