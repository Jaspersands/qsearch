```c
/*
 * e2.c -- decide whether a prime p lies in E_2(K).
 *
 * Problem.  p prime, K | p-1, g the least primitive root mod p.
 *   Q_m = { y in F_p^* : log_g y = m (mod K) },  A_m = Q_m u {0}.
 * Find alpha, beta in F_p^K (indices in Z_K), alpha_0 = 1, beta_0 = 0, with
 *   cell(i,j) := alpha_j + beta_i  in  A_{-(i+j) mod K}   for all i,j in Z_K.
 * FEASIBLE  <=> such (alpha,beta) exists  <=> p not in E_2(K).
 *
 * Method.  Complete backtracking (CSP) over the 2K-2 free variables
 * alpha_1..alpha_{K-1}, beta_1..beta_{K-1}.  Every free variable keeps an
 * explicit domain list (a subset of F_p).  After each assignment we do
 * forward checking: every constraint that now has exactly one unassigned
 * variable filters that variable's domain; an empty domain is a dead end.
 * The next variable is the one with the smallest current domain (MRV).
 * A leaf (all variables assigned) satisfies every constraint; it is then
 * re-verified cell by cell with an independent membership test (Euler-type
 * criterion y^((p-1)/K), not the log table) before it is reported.
 *
 * Constraints used:
 *   (C) cell constraints  alpha_j + beta_i in A_{-(i+j)}   (all i,j; those
 *       with i=0 or j=0 are unary because alpha_0, beta_0 are constants).
 *   (S) symmetry-breaking constraints (optional, flag -nosym disables them).
 *
 * ---------------------------------------------------------------------------
 * SOUNDNESS OF THE SYMMETRY BREAKING (S)
 *
 * Call (alpha,beta) a "solution" if all K^2 cell constraints hold, and
 * "normalized" if moreover alpha_0 = 1, beta_0 = 0.  The question is whether
 * a normalized solution exists.
 *
 * (1) Cell renormalization N(.,r,s).  Let (alpha,beta) be a solution and
 *     (r,s) in Z_K^2 a cell with v := alpha_s + beta_r != 0.  Define
 *        a~_j = (alpha_{j+s} + beta_r) / v,   b~_i = (beta_{i+r} - beta_r) / v.
 *     Then a~_0 = 1, b~_0 = 0 and a~_j + b~_i = (alpha_{j+s} + beta_{i+r})/v.
 *     The numerator lies in A_{-(i+j+r+s)}; v lies in Q_{-(r+s)} (it is a
 *     nonzero element of A_{-(r+s)}), and Q_a / Q_b = Q_{a-b}, 0/v = 0, so
 *     the quotient lies in A_{-(i+j)}.  Hence N(sol,r,s) is a normalized
 *     solution.  Composition: N(N(sol,r,s),r',s') = N(sol,r+r',s+s')
 *     (direct substitution: the product of the two scalings is
 *     alpha_{s+s'} + beta_{r+r'}, which is nonzero iff cell (r',s') of
 *     N(sol,r,s) is nonzero), and N(sol,0,0) = sol for normalized sol.
 *
 * (2) Swap W.  For a normalized solution n = (alpha,beta) put
 *     W(n) = (beta + 1, alpha - 1).  Cells: (beta_j + 1) + (alpha_i - 1) =
 *     cell(j,i) of n, whose class -(i+j) is symmetric in i,j, so W(n) is a
 *     solution; W(n)_alpha_0 = beta_0 + 1 = 1 and W(n)_beta_0 = alpha_0 - 1 = 0,
 *     so W(n) is normalized; W(W(n)) = n; and a direct substitution gives
 *     W(N(n,r,s)) = N(W(n),s,r)  (both equal  alpha~_j = (beta_{j+r}+alpha_s)/v,
 *     beta~_i = (alpha_{i+s} - alpha_s)/v  with v = alpha_s + beta_r).
 *
 * (3) Orbit set.  For a normalized solution n let
 *        O(n) = { N(n,r,s) : cell (r,s) of n nonzero }
 *             u { N(W(n),r,s) : cell (r,s) of W(n) nonzero }.
 *     O(n) is a finite set of normalized solutions containing n, and by (1),(2)
 *     O(m) = O(n) for every m in O(n) (closure under N and W).
 *
 * (4) Key.  key(n) := alpha_1 of n, as an integer in [0,p).  Let m be an
 *     element of O(n) with minimal key (exists: O(n) finite, nonempty).  For
 *     every element m' of O(m) = O(n), key(m) <= key(m').  Writing
 *     m = (alpha,beta), the elements of O(m) and their keys are
 *        N(m,r,s):     (alpha_{s+1} + beta_r) / (alpha_s + beta_r)   if alpha_s + beta_r != 0,
 *        N(W(m),r,s):  (beta_{s+1} + alpha_r) / (beta_s + alpha_r)   if beta_s + alpha_r != 0
 *     (indices mod K).  [W(m) = (beta+1, alpha-1), so its cell (r,s) is
 *     beta_s + alpha_r and its alpha~_1 is (beta_{s+1}+1 + alpha_r-1)/(...)].
 *     Therefore: IF any normalized solution exists, THEN a normalized solution
 *     exists that satisfies, for all r,s in Z_K,
 *        (S_A(r,s))  alpha_s + beta_r = 0  or  (alpha_{s+1}+beta_r)/(alpha_s+beta_r) >= alpha_1,
 *        (S_B(r,s))  beta_s + alpha_r = 0  or  (beta_{s+1}+alpha_r)/(beta_s+alpha_r) >= alpha_1,
 *     with ">=" comparing representatives in [0,p).  Adding all S_A, S_B as
 *     constraints thus never turns a FEASIBLE prime into INFEASIBLE, and any
 *     leaf found is still an honest solution of the original problem (S only
 *     removes candidates).  S_A(0,0) is the tautology alpha_1 >= alpha_1 and
 *     is omitted.  Ties are allowed (">=", not ">"), so no tie-breaking
 *     argument is needed.
 *
 * Forward checking soundness: a value is removed from a domain only when some
 * constraint (C or S) whose other variables are all assigned is violated by
 * it; so no extension of the current partial assignment using that value can
 * satisfy all constraints.  An empty domain therefore proves that the current
 * partial assignment has no extension.  MRV only changes the order.
 * The search over the root variable alpha_1 enumerates its whole domain
 * A_{-1}; every other variable's domain starts as all of F_p filtered by the
 * constraints, so the enumeration is complete.
 * ---------------------------------------------------------------------------
 *
 * Usage:  e2 K p [timelimit_sec (0 = none)] [-nosym] [-count]
 *   threads: OMP_NUM_THREADS.  -count: do not stop at the first solution,
 *   count canonical leaves instead (diagnostic only).
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>
#include <limits.h>
#include <omp.h>

static int K, P, G, NV, ROOTV;
static int *dlog_t;
static uint8_t *memb;      /* memb[s], 0<=s<2P: bitmask of m with (s mod P) in A_m */
static uint32_t *inv_t;
static int use_sym = 1, count_mode = 0;
static double tlimit = 0, t0;
static volatile int stopflag = 0;   /* 1 = solution found, 2 = timeout */
static long long total_nodes = 0, total_leaves = 0;
static int sol_val[16];

typedef struct { int a, b, c; } Tern;
static Tern tern[256];
static int ntern;
static int pairT[16][16][32], npairT[16][16];
static int varT[16][128], nvarT[16];

static int isalpha_(int v) { return v < K; }
static int idx(int v) { return v < K ? v : v - K; }
static int modK(int x) { x %= K; return x < 0 ? x + K : x; }
/* class mask of binary cell constraint between alpha_j and beta_i */
static int cellmask(int u, int w) { return 1 << modK(-(idx(u) + idx(w))); }

static long long powmod(long long b, long long e, long long m) {
    long long r = 1; b %= m; if (b < 0) b += m;
    while (e) { if (e & 1) r = r * b % m; b = b * b % m; e >>= 1; }
    return r;
}

static int least_primroot(int p) {
    int f[32], nf = 0, n = p - 1;
    for (int q = 2; (long long)q * q <= n; q++) if (n % q == 0) { f[nf++] = q; while (n % q == 0) n /= q; }
    if (n > 1) f[nf++] = n;
    for (int g = 2; g < p; g++) {
        int ok = 1;
        for (int i = 0; i < nf; i++) if (powmod(g, (p - 1) / f[i], p) == 1) { ok = 0; break; }
        if (ok) return g;
    }
    return -1;
}

/* Independent membership test: y in A_m  <=>  y == 0  or  y^((p-1)/K) == (g^((p-1)/K))^m. */
static int indep_in_A(long long y, int m) {
    y %= P; if (y < 0) y += P;
    if (y == 0) return 1;
    long long w = powmod(G, (P - 1) / K, P);
    return powmod(y, (P - 1) / K, P) == powmod(w, modK(m), P);
}
static int verify(const int *al, const int *be) {
    if (al[0] != 1 || be[0] != 0) return 0;
    for (int i = 0; i < K; i++) for (int j = 0; j < K; j++)
        if (!indep_in_A((long long)al[j] + be[i], -(i + j))) return 0;
    return 1;
}

static uint64_t FM;   /* Lemire fastmod constant for P */
static inline uint32_t fmod_p(uint32_t a) {   /* a mod P, valid for a < 2^32 */
    uint64_t low = FM * a;
    return (uint32_t)(((__uint128_t)low * (uint32_t)P) >> 64);
}
static inline int tern_ok(int va, int vb, int vc, int x) {
    int den = va + vc; if (den >= P) den -= P;
    if (den == 0) return 1;
    int num = vb + vc; if (num >= P) num -= P;
    return (int)fmod_p((uint32_t)num * inv_t[den]) >= x;
}

typedef struct {
    int val[16], asg[16];
    uint16_t *dp[17][16];
    int dl[17][16];
    uint16_t *buf[17];
    long long nodes, leaves, lastchk;
} Ctx;

/* Filter domain of free variable Z given the currently assigned values.
 * bin: assigned var whose binary constraint with Z is applied (or -1).
 * tl/ntl: ternary constraint ids to apply (all other vars assigned).  */
static int filter(Ctx *c, int Z, const uint16_t *src, int n, uint16_t *dst,
                  int bin, const int *tl, int ntl) {
    int x = c->val[ROOTV];
    int cnt = 0;
    if (bin >= 0) {             /* binary cell constraint first (cheap, keeps ~1/K) */
        int bv = c->val[bin], bm = cellmask(bin, Z);
        for (int k = 0; k < n; k++) { int y = src[k]; dst[cnt] = (uint16_t)y; cnt += (memb[y + bv] & bm) != 0; }
    } else { memcpy(dst, src, n * sizeof(uint16_t)); cnt = n; }
    for (int t = 0; t < ntl && cnt; t++) {   /* then each ternary constraint, in place, role-specialised */
        const Tern *T = &tern[tl[t]];
        int m = 0;
        if (T->b == Z) {              /* numerator variable: den fixed */
            int vc = c->val[T->c];
            int den = c->val[T->a] + vc; if (den >= P) den -= P;
            if (den == 0) continue;   /* vacuous */
            uint32_t id = inv_t[den];
            for (int k = 0; k < cnt; k++) { int y = dst[k]; int num = y + vc; if (num >= P) num -= P;
                dst[m] = (uint16_t)y; m += (int)fmod_p((uint32_t)num * id) >= x; }
        } else if (T->a == Z) {       /* denominator variable */
            int vc = c->val[T->c];
            int num = c->val[T->b] + vc; if (num >= P) num -= P;
            for (int k = 0; k < cnt; k++) { int y = dst[k]; int den = y + vc; if (den >= P) den -= P;
                dst[m] = (uint16_t)y; m += (den == 0) || ((int)fmod_p((uint32_t)num * inv_t[den]) >= x); }
        } else {                      /* shared variable c */
            int va = c->val[T->a], vb = c->val[T->b];
            for (int k = 0; k < cnt; k++) { int y = dst[k];
                dst[m] = (uint16_t)y; m += tern_ok(va, vb, y, x); }
        }
        cnt = m;
    }
    return cnt;
}

/* Arc consistency on the binary cell constraints between free alpha_j and
 * free beta_i (both domains <= 64 values, so supports fit in a 64-bit mask).
 * A value u of alpha_j with no w in D(beta_i) such that u + w in A_{-(i+j)} is
 * removed (and symmetrically).  Sound: D(beta_i) contains every value beta_i
 * can take in any extension of the current partial assignment (domains are
 * only ever reduced by violated constraints), so such u occurs in no
 * extension.  Iterated to a fixpoint.  Returns 0 if a domain becomes empty. */
static int acmax = 16, ac_on = 1;
static int ac_bin(Ctx *c, int d, uint16_t **bpp) {
    int fa[8], nfa = 0, fb[8], nfb = 0;
    for (int v = 0; v < NV; v++) if (!c->asg[v]) { if (isalpha_(v)) fa[nfa++] = v; else fb[nfb++] = v; }
    uint16_t *lo = c->buf[d], *hi = c->buf[d] + (size_t)NV * (P + 1);
    int changed = 1;
    while (changed) {
        changed = 0;
        for (int ia = 0; ia < nfa; ia++) for (int ib = 0; ib < nfb; ib++) {
            int a = fa[ia], b = fb[ib];
            int na = c->dl[d][a], nb = c->dl[d][b];
            if (na > acmax || nb > acmax) continue;
            const uint16_t *Da = c->dp[d][a], *Db = c->dp[d][b];
            int mask = cellmask(a, b);
            uint64_t rowok = 0, colsup = 0;
            for (int u = 0; u < na; u++) {
                uint64_t row = 0; const uint8_t *mb = memb + Da[u];
                for (int w = 0; w < nb; w++) row |= (uint64_t)((mb[Db[w]] & mask) != 0) << w;
                rowok |= (uint64_t)(row != 0) << u; colsup |= row;
            }
            uint64_t fulla = na == 64 ? ~0ULL : ((1ULL << na) - 1), fullb = nb == 64 ? ~0ULL : ((1ULL << nb) - 1);
            for (int side = 0; side < 2; side++) {
                int v = side ? b : a; uint64_t keep = side ? colsup : rowok; uint64_t full = side ? fullb : fulla;
                if (keep == full) continue;
                if (keep == 0) return 0;
                const uint16_t *src = c->dp[d][v]; int n = c->dl[d][v];
                uint16_t *dst = (src >= lo && src < hi) ? (uint16_t *)src : *bpp;
                int m = 0;
                for (int k = 0; k < n; k++) if (keep >> k & 1) dst[m++] = src[k];
                if (dst == *bpp) *bpp += m;
                c->dp[d][v] = dst; c->dl[d][v] = m; changed = 1;
                if (side == 0) { na = m; }   /* domain of a changed; recompute later via fixpoint */
            }
            if (changed) { /* restart scanning with fresh pointers */ }
        }
    }
    return 1;
}

static double now(void) { return omp_get_wtime(); }

static int dfs(Ctx *c, int d) {
    if (stopflag) return -1;
    if (tlimit > 0 && (c->nodes >> 20) != c->lastchk) { c->lastchk = c->nodes >> 20; if (now() - t0 > tlimit) { stopflag = 2; return -1; } }
    int best = -1, bl = INT_MAX;
    for (int v = 0; v < NV; v++) if (!c->asg[v] && c->dl[d][v] < bl) { bl = c->dl[d][v]; best = v; }
    if (best < 0) {
        int al[8], be[8];
        for (int j = 0; j < K; j++) { al[j] = c->val[j]; be[j] = c->val[K + j]; }
        if (!verify(al, be)) { fprintf(stderr, "INTERNAL ERROR: leaf failed verification\n"); exit(3); }
        c->leaves++;
        if (count_mode) return 0;
        #pragma omp critical
        {
            if (stopflag != 1) { stopflag = 1; memcpy(sol_val, c->val, sizeof(sol_val)); }
        }
        return 1;
    }
    const uint16_t *dom = c->dp[d][best];
    int n = c->dl[d][best];
    for (int k = 0; k < n; k++) {
        c->nodes++;
        c->val[best] = dom[k]; c->asg[best] = 1;
        uint16_t *bp = c->buf[d + 1];
        int ok = 1;
        for (int Z = 0; Z < NV && ok; Z++) {
            if (c->asg[Z]) continue;
            int tl[32], ntl = 0;
            if (use_sym)
                for (int t = 0; t < npairT[best][Z]; t++) {
                    const Tern *T = &tern[pairT[best][Z][t]];
                    int third = (T->a != best && T->a != Z) ? T->a : (T->b != best && T->b != Z) ? T->b : T->c;
                    if (c->asg[third]) tl[ntl++] = pairT[best][Z][t];
                }
            int bin = (isalpha_(best) != isalpha_(Z)) ? best : -1;
            if (bin < 0 && ntl == 0) { c->dp[d + 1][Z] = c->dp[d][Z]; c->dl[d + 1][Z] = c->dl[d][Z]; continue; }
            int m = filter(c, Z, c->dp[d][Z], c->dl[d][Z], bp, bin, tl, ntl);
            if (m == 0) { ok = 0; break; }
            c->dp[d + 1][Z] = bp; c->dl[d + 1][Z] = m; bp += m;
        }
        if (ok && ac_on) ok = ac_bin(c, d + 1, &bp);
        if (ok) { int r = dfs(c, d + 1); if (r) { c->asg[best] = 0; return r; } }
        c->asg[best] = 0;
    }
    return 0;
}

int main(int argc, char **argv) {
    if (argc < 3) { fprintf(stderr, "usage: e2 K p [tlimit] [-nosym] [-count]\n"); return 1; }
    K = atoi(argv[1]); P = atoi(argv[2]);
    if (argc > 3 && argv[3][0] != '-') tlimit = atof(argv[3]);
    for (int i = 3; i < argc; i++) { if (!strcmp(argv[i], "-nosym")) use_sym = 0; if (!strcmp(argv[i], "-count")) count_mode = 1; if (!strcmp(argv[i], "-noac")) ac_on = 0; if (!strncmp(argv[i], "-acmax=", 7)) acmax = atoi(argv[i] + 7); }
    if (K < 2 || K > 8 || (P - 1) % K != 0 || P >= 65536) { fprintf(stderr, "bad K/p\n"); return 1; }
    NV = 2 * K; ROOTV = 1; /* alpha_1 */
    G = least_primroot(P);
    dlog_t = calloc(P, sizeof(int));
    { long long y = 1; for (int e = 0; e < P - 1; e++) { dlog_t[y] = e; y = y * G % P; } }
    memb = malloc(2 * P);
    for (int s = 0; s < 2 * P; s++) { int y = s % P; memb[s] = y == 0 ? (uint8_t)((1 << K) - 1) : (uint8_t)(1 << (dlog_t[y] % K)); }
    FM = UINT64_C(0xFFFFFFFFFFFFFFFF) / (uint32_t)P + 1;
    inv_t = malloc(P * sizeof(uint32_t)); inv_t[0] = 0;
    for (int y = 1; y < P; y++) inv_t[y] = (uint32_t)powmod(y, P - 2, P);

    /* symmetry constraints: S_A(r,s): (alpha_s, alpha_{s+1}, beta_r), (r,s) != (0,0);
       S_B(r,s): (beta_s, beta_{s+1}, alpha_r). Ternary (a,b,c): a+c==0 or (b+c)/(a+c) >= alpha_1. */
    ntern = 0;
    for (int r = 0; r < K; r++) for (int s = 0; s < K; s++) {
        if (!(r == 0 && s == 0)) tern[ntern++] = (Tern){ s, (s + 1) % K, K + r };
        tern[ntern++] = (Tern){ K + s, K + (s + 1) % K, r };
    }
    for (int t = 0; t < ntern; t++) {
        int v[3] = { tern[t].a, tern[t].b, tern[t].c };
        for (int u = 0; u < 3; u++) {
            varT[v[u]][nvarT[v[u]]++] = t;
            for (int w = 0; w < 3; w++) if (w != u) pairT[v[u]][v[w]][npairT[v[u]][v[w]]++] = t;
        }
    }

    /* base domains: all of F_p filtered by unary cell constraints with alpha_0 = 1, beta_0 = 0 */
    int maxd = P;
    uint16_t **base = malloc(NV * sizeof(uint16_t *)); int *bl = calloc(NV, sizeof(int));
    for (int v = 0; v < NV; v++) {
        base[v] = malloc(maxd * sizeof(uint16_t));
        for (int y = 0; y < P; y++) {
            int ok;
            if (v == 0) ok = (y == 1);
            else if (v == K) ok = (y == 0);
            else if (isalpha_(v)) ok = (memb[y + 0] & cellmask(v, K)) != 0;    /* alpha_j + beta_0 */
            else ok = (memb[y + 1] & cellmask(0, v)) != 0;                      /* alpha_0 + beta_i */
            if (ok) base[v][bl[v]++] = (uint16_t)y;
        }
    }
    int nroot = bl[ROOTV];
    t0 = now();
    #pragma omp parallel
    {
        Ctx *c = calloc(1, sizeof(Ctx));
        for (int d = 0; d <= NV; d++) c->buf[d] = malloc((size_t)NV * (maxd + 1) * sizeof(uint16_t));
        #pragma omp for schedule(dynamic, 1)
        for (int ri = 0; ri < nroot; ri++) {
            if (stopflag) continue;
            memset(c->asg, 0, sizeof(c->asg));
            c->val[0] = 1; c->asg[0] = 1; c->val[K] = 0; c->asg[K] = 1;
            c->val[ROOTV] = base[ROOTV][ri]; c->asg[ROOTV] = 1;
            c->nodes++;
            uint16_t *bp = c->buf[0]; int ok = 1;
            /* fully-assigned symmetry constraints at the root (only S_A(0,0)-type, omitted; check anyway) */
            if (use_sym) for (int t = 0; t < ntern; t++)
                if (c->asg[tern[t].a] && c->asg[tern[t].b] && c->asg[tern[t].c] &&
                    !tern_ok(c->val[tern[t].a], c->val[tern[t].b], c->val[tern[t].c], c->val[ROOTV])) ok = 0;
            for (int Z = 0; Z < NV && ok; Z++) {
                if (c->asg[Z]) continue;
                int tl[128], ntl = 0;
                if (use_sym) for (int t = 0; t < nvarT[Z]; t++) {
                    const Tern *T = &tern[varT[Z][t]];
                    int na = (T->a != Z && !c->asg[T->a]) + (T->b != Z && !c->asg[T->b]) + (T->c != Z && !c->asg[T->c]);
                    if (na == 0) tl[ntl++] = varT[Z][t];
                }
                int bin = isalpha_(Z) ? -1 : ROOTV;
                int m = filter(c, Z, base[Z], bl[Z], bp, bin, tl, ntl);
                if (m == 0) { ok = 0; break; }
                c->dp[0][Z] = bp; c->dl[0][Z] = m; bp += m;
            }
            if (ok && ac_on) ok = ac_bin(c, 0, &bp);
            if (ok) dfs(c, 0);
        }
        #pragma omp atomic
        total_nodes += c->nodes;
        #pragma omp atomic
        total_leaves += c->leaves;
    }
    double secs = now() - t0;
    if (stopflag == 1) {
        int al[8], be[8];
        for (int j = 0; j < K; j++) { al[j] = sol_val[j]; be[j] = sol_val[K + j]; }
        if (!verify(al, be)) { printf("OPEN k=%d p=%d reason=witness_failed_verification\n", K, P); return 2; }
        printf("FEASIBLE k=%d p=%d g=%d beta=", K, P, G);
        for (int i = 0; i < K; i++) printf("%d%s", be[i], i < K - 1 ? "," : "");
        printf(" alpha=");
        for (int j = 0; j < K; j++) printf("%d%s", al[j], j < K - 1 ? "," : "");
        printf("\n");
        fprintf(stderr, "# p=%d nodes=%lld secs=%.2f\n", P, total_nodes, secs);
    } else if (stopflag == 2) {
        printf("OPEN k=%d p=%d reason=timeout_%.0fs_nodes_%lld\n", K, P, tlimit, total_nodes);
    } else if (count_mode && total_leaves > 0) {
        printf("COUNT k=%d p=%d canonical_leaves=%lld nodes=%lld secs=%.2f\n", K, P, total_leaves, total_nodes, secs);
    } else {
        printf("INFEASIBLE k=%d p=%d nodes=%lld secs=%.2f\n", K, P, total_nodes, secs);
    }
    return 0;
}
```

## (4) Why each prune is sound
1. **Starting domains.** Cells with i=0 or j=0 involve one unknown, since α_0=1 and β_0=0, so they restrict that variable on their own. Each variable starts as all of F_p minus values that break such a cell. Only values that violate the definition are removed.
2. **Forward checking.** A value is removed only if it breaks a constraint whose other variables are all already set. No completion of the current branch can use it. An empty domain therefore proves the branch has no solution.
3. **Arc consistency.** A value of α_j is removed if no remaining value of β_i makes α_j + β_i a member of A_{-(i+j)}, and the same rule applies with α and β swapped. Domains only ever lose values that cannot appear in any solution of the branch. So a removed value has no partner in any solution, and removing it is safe.
4. **Symmetry pruning.** Any nonzero cell can be moved to position (0,0) by shifting indices and renormalizing. Swapping the roles of α and β also preserves the problem. These moves map normalized solutions to normalized solutions and form a closed set of at most 128 forms per solution. In that set, a form with the smallest α_1 always exists. Every other form then has α_1 at least that large; written in terms of the minimal form, this gives the constraints S_A(r,s) and S_B(r,s). Requiring those constraints keeps at least one solution whenever any exists, so the pruning can never turn FEASIBLE into INFEASIBLE. Ties use ≥, so no tie-breaking rule is needed. The full proof is in the header comment.
5. **Variable order and parallelism.** Picking the smallest domain first (MRV) and the parallel split over root values only change the order of the search, not what it covers. Every value of α_1 in A_{-1} is a root.
6. **Time caps.** A time cap can only produce OPEN. INFEASIBLE is printed only when every root ran to completion.

Measured effect at p=5009: the symmetry pruning cuts the search about 10×. Arc consistency cuts the node count a further 5× (from 11.5M to 2.2M) and the time about 2×. An alternative key using the minimum over all α_t was sound but slower, so I dropped it.
