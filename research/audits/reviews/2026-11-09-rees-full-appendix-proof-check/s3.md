### 1. GAP: appendix-schedule3.tex:316, paragraph "Application to Corollary `cor:fpt-r`" (the same step is in main.tex:1167, the proof of `cor:fpt-r`, outside my part)

The text reads: "As shown in the proof of that corollary, $c \le r + 1 = u$ and $a_d \le g_d \le r = u-1$ at every grade [...] When $p \ge 16(r+1)^2$, Theorem (iv) applies." The cited proof (main.tex:1167) says "$g_2 > g_3 > \cdots > g_c \ge 1$. Hence $c \le r+1$". That step needs $\gamma_c(\mathcal L) \ne 0$, that is, c must equal the class of ℒ. In Definition `def:input-contract` (main.tex:165–167), c is only a bound: an instance has "class $c < p$" and ℒ is "of class at most $c$ (a promise ...)". Corollary `cor:fpt-r` takes the instance's c ("$c < p$; the class need not be fixed").

**Counterexample** (by hand). Take ℒ the Heisenberg algebra, [x,y] = z, so m = 3 and r = 1, given with c = 5 and p = 67. This is a valid instance: p > c, the class is 2 ≤ 5, and p ≥ 16(r+1)² = 64. Then g_2 = 1 and g_3 = g_4 = g_5 = 0, so "g_c ≥ 1" fails and c = 5 > r+1 = u = 2. Theorem (iv) requires c ≤ u, so "Theorem (iv) applies" is false as written. Running the trees with the instance's c and u = c instead gives (4c)^{c−1} leaves per tree. Since c can be as large as p−1, that route gives no bound of the form 2^{O(r log(r+2))}·poly(m, log p, w, log(1/ε)).

**Fix.** The statement survives, because the true class is computable from public data. Replace the sentence "As shown in the proof of that corollary, $c \le r + 1 = u$ and $a_d \le g_d \le r = u - 1$ at every grade, and $u$ is computed from public data by linear algebra." with:

> First replace $c$ by the class $c' \le c$ of $\mathcal{L}$, computed from the structure constants by linear algebra (the lower central series); this keeps $p > c'$. As shown in the proof of that corollary, $g_2 > \dots > g_{c'} \ge 1$, so $c' \le r + 1 = u$ and $a_d \le g_d \le r = u - 1$ at every grade, and $u$ is computed from public data by linear algebra.

For whoever checks `cor:fpt-r`: main.tex:1167 needs the same repair, for example by starting the proof with "Replacing $c$ by the class of $\mathcal{L}$, computed by linear algebra, we may assume $\gamma_c(\mathcal{L}) \ne 0$; this keeps $p > c$, and an instance with $p = c+1$ whose true class is smaller falls under~(i)." With that change, the rest of the paragraph (Theorem (iv), Proposition `prop:s3-uniform`, the label law) is correct.
