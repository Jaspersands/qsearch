## Verdict: ADD WITH CAVEATS

The composition survives every break attempt below. One finding
**simplifies it**: Γ(M) is generated by the x_ij^M (peel the
superdiagonals), so Γ(M) ⊆ H as soon as every period e_ij divides M.
Hence **M = lcm(e_ij) suffices**, and Lemmas N1–N3 and the factor (n−1)!
are not needed for G = UT_n(Z) [proved, §2.1; computed, §3]. N1–N3 are
correct, but the draft no longer uses them. Three statement repairs (input
box, accepted multiples, the Imran–Ivanyos input model) are written into
`utz.tex`.

No prior polynomial-time algorithm for a finite-index HSP in a finitely
generated, non-virtually-abelian infinite group was found in the sources
read. Caveats, all to stay in the paper text:

1. The result rests on Thm `is-import` through `cor:black-box-pe`, at
   primes q ≥ n. For n ≤ 3 no part of the paper is needed (ISS 2012 for
   q ≥ 3, Imran–Ivanyos for q = 2), so n ≤ 3 is not new for Rees.
2. Not an application: f is an arbitrary oracle (TRAPS 3).
3. The classical lower bound is not specific to the non-abelian structure
   (n = 2 is already period finding).
4. Only G = UT_n(Z) itself (the subgroup counterexample of search 3 §3.4
   stands, now explained by the generation step).
5. The reduction is elementary, the non-abelian analogue of Mosca–Ekert's
   abelian step. All new content is `cor:black-box-pe` applied to
   UT_n(Z/q^k). One survey that may discuss H_3(Z) could not be opened
   (§1, row 1), and a specialist priority check is still needed before any
   "new" wording.

## 2. Proof check (task 2)

### 2.1 Lemmas

- **Simplification [proved].** For g = I + MA ∈ Γ(M), right
  multiplication by ∏_i x_{i,i+1}^{−M A_{i,i+1}} stays in Γ(M) and clears
  the first superdiagonal; repeat level by level. So
  Γ(M) = ⟨x_ij^M : i < j⟩. If e_ij | M for all i < j, every generator lies
  in H, so Γ(M) ⊆ H. The index N is never needed, only e_ij ≤ N ≤ 2^b
  (pigeonhole) for the period-finding range. M = lcm e_ij ≤ 2^{mb}.
- **N1** (g^N ∈ Core(H) in nilpotent G). Re-proved: P = G/Core is finite
  nilpotent; Core_{P_q}(S_q) is normal in P (the other Sylows centralize
  P_q) and lies in S, so it is trivial; a q-group acting faithfully on q^a
  points has exponent dividing q^a. **Correct, not needed here.**
- **N2** (e_ij ≤ N, N | ∏ e_ij). Re-proved via the level-ordered normal
  series with infinite cyclic factors. **Correct; only e_ij ≤ N is used.**
- **N3** (Γ((n−1)!N′) ⊆ G^{N′}). Re-derived: M^k/(kN′) = (n−1)!^k N′^{k−1}/k
  is a multiple of (n−1)! for k ≤ n−1. **Correct, not needed here.** The
  search-3 remark "the factor (n−1)! cannot be dropped" is true for the
  roots in N3, not for Γ(M) ⊆ H. Control: Γ(∏ e_ij) ⊆ H in every one of
  7,463 (7,088 + 375) random instances (`gamma_control_search.out` and the
  control line of `utz_e2e_check.out`), as the simplification predicts.
- N1 + N2 would matter for other finitely generated nilpotent groups,
  where G^{[∏ e_k]} ⊆ Core(H) replaces the congruence step. That needs a
  unique encoding of G/G^{[∏e_k]} and is not treated.
