Problem. v_1..v_m ∈ F_3^n arbitrary; find nonempty S with Σ_{i∈S} v_i = 0 in poly(n, m) time.

## 0. Verdict

1. **Question (1), an algorithm with a proved constant c < 1/3: NOT obtained.** Every route I
   found to gain two dimensions from one piece either (a) costs exactly what two KOW rounds
   cost, or (b) requires solving an F_3 subset-sum sub-instance in the hard regime
   (m′ ≈ 1.6 n′), or a syndrome-decoding instance below the Plotkin radius. The p = 3 analogue
   of the large-p block-steered round does exist combinatorially (Theorem 4: two dependencies
   with nested supports realize a 2-dimensional subgroup by eight explicit class unions), but
   its precondition is a dependency whose support carries a second dependency, which is not a
   general-position event and which no averaging method produces.
2. **Question (2), barrier [proved in a stated model, Theorem 6].** In the model "disjoint
   pieces, each certified by dependencies that are uniform samples from affine solution spaces
   of linear systems" (Model A, §5), on uniformly random instances, every scheme whose pieces use
   at most two dependencies needs m ≥ n²/3 − O(n^{3/2} log n) columns, and every scheme (any
   number of dependencies per piece) needs m ≥ (log₂3 − 1)·n²/3 − o(n²) ≥ 0.195 n². The first
   bound is tight: KOW's algorithm is in the model and attains n²/3 + O(n log n). The second
   constant is only the counting bound 2^t ≥ 3^d and is probably not tight.
3. **Structural results behind the barrier [proved + exact].** Theorem 2: a piece of columns
   whose dependency space has all 3^k − 1 joint patterns present realizes at most one dimension
   (finite check: the defect set E_2 ⊂ F_3^6 contains no 2-dimensional linear subspace,
   `generic_piece.out`, `confined_k2.out`). Theorem 3: two dependencies realize at most two
   dimensions, never three (`complete_k2.out`: no 0/1-complete 2-dimensional subspace of
   F_3^5). Theorem 5 (classification): the pattern sets of two dependencies that admit a
   2-dimensional realization are exactly the subsets of four 6-sets; each forces either nested
   supports or a prescribed 0/1 pattern on the first support.
4. **Question (3), small cases [exact/sampled].** For the implemented KOW algorithm the least m
   at which it never fails is 6 for n = 2 (exhaustive over all 3003 multisets; 53 of the 1287
   multisets at m = 5 = 2n + 1 defeat it although they all have zero-sum subsets) and the
   recursion values 9, 13 for n = 3, 4 (failure instances found at 8, 12). For n = 5..8 failures
   were found up to m = 16, 21, 26, 32 against recursion budgets 18, 24, 30, 37 (`calib.out`).
5. **KOMSW worst case [argued].** The 0.1022 n² average-case figure is built from gadgets whose
   validity depends on the input distribution (the lit report, §1.1). By Theorem 2, any gadget
   that gains several dimensions from a bundle of dependencies must have a pattern gap; on
   random inputs pattern gaps of a chosen bundle occur with probability exponentially small in
   the class sizes, so an average-case gadget must select its columns adaptively. A worst-case
   version would need the adversary to be unable to destroy that selection; nothing in Model A
   does this, and I see no mechanism. I cannot say more without the paper.
6. **Weakest step.** Theorem 6 is only as strong as Model A: it excludes exactly the step that
   would help (finding representations sparser than the averaging bound, i.e. decoding). The
   self-similarity reductions of §4 show that this step is an F_3 subset-sum or syndrome-decoding
   instance, but they do not prove it hard. Finite computations prove nothing about scaling.

## 1. Notation and the piece framework

Columns are in F_3^q after passing to the quotient by the subgroup already realized (q = current
codimension). For X ⊆ [m] let φ_X : F_3^X → F_3^q, x ↦ Σ x_i v_i, D(X) = ker φ_X (the
dependency space) and R(X) = φ_X({0,1}^X) (the realizable set). A **piece** is a set X with a
subgroup H ⊆ R(X); it **realizes** H and **gains** d = dim H. The **cost** of a piece is |X|.

**Lemma 1 (recursion) [proved].** R(X ∪ Y) = R(X) + R(Y) for disjoint X, Y. If X realizes H and
T ⊆ [m] ∖ X is nonempty with Σ_T v_i ∈ H, then some S ⊆ X makes T ∪ S a nonempty zero-sum set.
Hence an algorithm that realizes subgroups H_1, H_2, … on disjoint pieces until the codimension is
0 and then takes any remaining column solves the instance; its column consumption is Σ |X_j|.
*Proof.* Minkowski sum of disjoint supports; take S with Σ_S v_i = −Σ_T v_i ∈ H. ∎

KOW's round is the piece X = supp δ for a dependency δ, A = {δ_i = 1}, B = {δ_i = 2},
u = Σ_A v_i = Σ_B v_i, H = {0, u, 2u} realized by ∅, A, A ∪ B [literature, re-derived].

**Lemma 2 (0/1 points of a subspace) [proved].** A t-dimensional subspace of F_3^s has at most
2^t vectors with entries in {0,1}. If it has more than (3/4)·2^t, it is a *partition subspace*
on its support: spanned by indicator vectors of t disjoint sets (0/1 points = the 2^t unions).
*Proof.* Choose t pivot coordinates; the projection to them is injective and maps 0/1 vectors to
{0,1}^t. In systematic form each non-pivot coordinate is a linear form ℓ_c(z) = Σ c_i z_i of the
pivot vector z. If c = e_i the coordinate copies pivot i; if c = 0 it is identically 0. Otherwise
either c = 2e_i, failing (value 2) on the 2^{t−1} patterns with z_i = 1, or c has two nonzero
entries at i ≠ j, and for each of the 2^{t−2} settings of the other pivots at least one of the
four settings of (z_i, z_j) gives ℓ_c ∉ {0,1} ((1,1): z_i = z_j = 1 gives 2; (1,2): z_i = 0,
z_j = 1 gives 2; (2,·) similar). So a non-copy coordinate kills ≥ 2^{t−2} of the 2^t pivot
patterns. ∎

**Lemma 3 (what a gain of d costs in dependencies) [proved].** If X realizes H with dim H = d ≥ 1,
choose y_h ∈ {0,1}^X with φ(y_h) = h and put H̃ = span{y_h}, t = dim H̃, K = H̃ ∩ D(X). Then
φ(H̃) = H, dim K = t − d, 3^d ≤ 2^t, hence
  t ≥ d·log₂3 ≈ 1.585 d and dim K = t − d ≥ d(log₂3 − 1) ≈ 0.585 d.
In particular d = 1 needs one dependency inside H̃ (KOW's t = 2) and d = 2 needs at least two
(t ≥ 4). Columns of X outside the supports of K are unused (every y_h vanishes there) and can be
dropped from X.
*Proof.* φ(H̃) ⊆ H since the generators map into H, and ⊇ H; so dim φ(H̃) = d and dim K = t − d.
The 3^d vectors y_h are distinct 0/1 points of H̃, so 3^d ≤ 2^t by Lemma 2. If all κ ∈ K vanish
at coordinate i, then y_{2h}(i) − 2y_h(i) = 0 for all h (as y_{2h} − 2y_h ∈ K), forcing
y_h(i) = 0. ∎

## 2. Theorem 2: generic dependency bundles gain one dimension

Fix a basis κ^1..κ^k of a subspace K ⊆ D(X); the **pattern** of coordinate i is
π_i = (κ^1_i, …, κ^k_i) ∈ F_3^k. For a 2-dimensional realization y_α (α ∈ F_3^2, y_0 = 0) the
relations y_α − α_1 y_{e1} − α_2 y_{e2} ∈ K read, coordinate-wise,
  y_α(i) − α_1 y_{e1}(i) − α_2 y_{e2}(i) = ⟨c_α, π_i⟩,  c_α ∈ F_3^k.
Call y_i := (y_α(i))_α ∈ {0,1}^{F_3^2∖0} the **local assignment** at i and
e(y_i) := (y_i(α) − α_1 y_i(e_1) − α_2 y_i(e_2))_{α ∉ {0,e_1,e_2}} ∈ F_3^6 its **defect**; let
E_2 = {e(y) : y a local assignment} ⊆ F_3^6 (|E_2| = 240 [exact]). With C the 6 × k matrix with
rows c_α, the relations say exactly **e(y_i) = C π_i for every i ∈ X.**

**Theorem 2 [proved; finite part exact, `generic_piece.py`, `confined_k2.py`].** Let X be a set
of columns whose dependency space D(X) has a basis whose patterns {π_i : i ∈ X} cover
F_3^k ∖ {0} (k = dim D(X)). Then R(X) contains no 2-dimensional subgroup.
*Proof.* Suppose it does, with realizers y_α and relation coefficients c_α as above (K = D(X)).
Then C π ∈ E_2 for every nonzero π ∈ F_3^k, so im(C) ⊆ E_2 ∪ {0}. The exhaustive check
(`generic_piece.out`: 28 lines, 0 independent pairs) shows E_2 ∪ {0} contains no 2-dimensional
linear subspace; hence rank C ≤ 1 and the vectors y_α − α·y lie in a single line ⟨κ⟩ ⊆ D(X).
Then span{y_α} ⊆ span{y_{e1}, y_{e2}, κ} has dimension ≤ 3 and at most 8 zero-one points
(Lemma 2), but the nine y_α are distinct: y_α = y_β gives y_{α−β} ∈ y_α − y_β + K = K, so
φ(y_{α−β}) = 0 = (α−β)-combination of the independent φ(y_{e1}), φ(y_{e2}), impossible. ∎

Remarks. (i) The hypothesis holds for k = 2 and q + 2 uniformly random columns once q is
moderately large: all 8 patterns appeared on 20/20 instances at q = 60 and 19/20 at q = 30
(`extras.out`) [sampled]. (ii) The theorem is about the guaranteed part of R(X). The actual
R(X) of q + 2 random columns does contain 2-dimensional subgroups for small q (28/30 at q = 4,
16/30 at q = 8, 5/10 at q = 9, `calib.out`), but |R(X)| ≤ 2^{q+2} while a subgroup needs 9
specific points among 3^q, so this is a small-q density effect and finding such a subgroup is a
2^{q}-size search. (iii) Consequently, two dependencies on q + 2 columns in general position, the
exact p = 3 analogue of a large-p round with J = 3 blocks, gain only one dimension; the Weil
steering has no combinatorial replacement here because the steering freedom (a scalar from
P ∪ {0} per block) is the 0/1 choice itself, and Lemma 2 counts it.

## 3. Theorems 3–5: what two dependencies can do, exactly

**Theorem 3 (two dependencies, at most two dimensions) [proved; `complete_k2.py`].** If
dim D(X) ≤ 2 then R(X) contains no 3-dimensional subgroup.
*Proof.* Lemma 3 with d = 3: t ≥ 5 and dim K = t − 3 ≤ 2, so t = 5, and H̃ is a 5-dimensional
subspace with 27 > (3/4)·32 = 24 zero-one points, hence a partition subspace with classes
P_1..P_5 (Lemma 2). K ⊆ H̃ is then spanned by class-constant vectors, K = rowspace(M) for a
2 × 5 matrix M, and the 27 cosets of K in H̃ ≅ F_3^5 must each contain a union of classes, i.e.
{0,1}^5 + K = F_3^5. The exhaustive check over all 1210 two-dimensional subspaces of F_3^5
finds none with this property (`complete_k2.out`; for comparison 60 of the 130 two-dimensional
subspaces of F_3^4 have it, which are the d = 2 partition gadgets). ∎

**Theorem 4 (nested-support gadget) [proved; `nested_symbolic.py`, `nested_gadget.py`].** Let
δ, δ′ be independent dependencies on X with supp δ = X ⊇ supp δ′. Write P_{ab} = {i : δ_i = a,
δ′_i = b} (a ∈ {1,2}, b ∈ F_3) and let w_{ab} = Σ_{P_ab} v_i. Put
  h_1 = w_10 + w_11 + w_20,  h_2 = w_11 + w_12 + w_22.
Then every α_1 h_1 + α_2 h_2 is a class-union sum: (0,1) ↦ P_11∪P_12∪P_22, (0,2) ↦ P_12∪P_21∪P_22,
(1,0) ↦ P_10∪P_11∪P_20, (1,1) ↦ P_10∪P_20∪P_21, (1,2) ↦ X, (2,0) ↦ P_11∪P_20∪P_22,
(2,1) ↦ P_20∪P_21∪P_22, (2,2) ↦ P_10∪P_12∪P_21. So R(X) ⊇ ⟨h_1, h_2⟩, and either this subgroup is
2-dimensional or one of the eight unions is itself a zero-sum set.
*Proof.* The two dependencies give w_1• = w_2• (where w_a• = Σ_b w_ab) and w_11 + w_21 = w_12 + w_22.
Each of the eight identities is a linear identity in the six w_ab modulo these two relations;
`nested_symbolic.out` verifies all eight by rank computation (e.g. for (1,2): X-sum − h_1 − 2h_2 =
2w_10 + w_20 + w_11 + 2w_22, and substituting w_20 = w_10 + 2w_11 + w_22 from the relations gives
3(w_10 + w_11 + w_22) = 0). If a h_1 + b h_2 = 0 with (a,b) ≠ 0, the union listed for (a,b) is a
zero-sum set. ∎ The gadget was also checked by direct summation on 20 constructed instances with
q ∈ {6, 10, 20, 40} (`nested_gadget.out`) [sampled].

**Theorem 5 (classification for two dependencies) [exact; `confined_k2.py`].** Let δ, δ′ be
independent dependencies on X = supp δ ∪ supp δ′ with D(X) = ⟨δ, δ′⟩, and let
T = {(δ_i, δ′_i) : i ∈ X} ⊆ F_3^2 ∖ 0 be the set of joint patterns. A 2-dimensional realization
exists for every choice of columns with these dependencies iff T is contained in one of
  T_1 = {1,2} × F_3 (supp δ′ ⊆ supp δ),  T_2 = F_3 × {1,2} (supp δ ⊆ supp δ′),
  T_3 = F_3^2 ∖ {(1,2),(2,1)} (δ′_i ∈ {0, δ_i} on supp δ),  T_4 = F_3^2 ∖ {(1,1),(2,2)} (δ′_i ∈ {0, −δ_i} on supp δ),
and |T| ≥ 4 (130 feasible T in all). *Method.* Enumerate rank-2 maps C: F_3^2 → F_3^6, record
the set of patterns π with Cπ ∈ E_2 ∪ {0}, and require that the local assignments available at
those patterns can make every y_α nonzero (several columns per class may carry different local
assignments). Necessity is Theorem 2's argument restricted to T; sufficiency is the explicit C.
Theorem 4 is the case T = T_1.

Interpretation. A generic pair has all 8 patterns and gains 1. To gain 2 one must *avoid* two
patterns: either δ′ vanishes off supp δ (T_1, T_2: a dependency whose support carries a second
dependency, so |supp δ| ≥ rank(supp δ) + 2), or δ′ takes a prescribed 0/1-type value pattern on
all of supp δ (T_3, T_4). Non-class-union realizers do not enlarge this list (the enumeration
allows arbitrary local assignments per column).

## 4. Self-similarity: every cheap two-dimensional piece hides a hard sub-instance [proved as reductions]

Let δ be the first dependency, S = supp δ, |S| = s (s ≈ 2q/3 for KOW's sparse δ), and let P be
the pool (N columns in F_3^q, D(P) of dimension N − q on random pools).

**(a) Nested supports (T_1).** Need δ′ ∈ D(S) independent of δ, i.e. rank(S) ≤ s − 2. For a
set S of ≤ q columns from a random pool this has probability ≤ 3^{s−1−q}; S = supp δ is not a
uniformly random set, but conditioned on δ ∈ D(S) the columns of S are uniform subject to one
linear relation, and a second relation again has probability ≤ 3^{s−1−q}. A full-support
dependency on a set F with dim D(F) = 2, |F| = q + 2, exists iff the 8 joint patterns of F miss
a whole line of F_3^2 (each coordinate functional kills exactly one of the four lines), which for
random F has probability ≤ 4·(3/4)^{q+2}. So T_1 pieces cost ≥ q + 2 columns for 2 dimensions,
(q+2)/2 per dimension — *this would beat 2q/3* — but their precondition is an event of
probability 3^{−Ω(q)} per candidate set, and choosing the set to force it is a search over
sets, not linear algebra.

**(b) Prescribed pattern (T_3; T_4 is the same with δ′ ↦ −δ′).** δ′_i ∈ {0, δ_i} on S means
δ′|_S = (δ_i z_i)_{i∈S} for some z ∈ {0,1}^S. Put τ_z = −Σ_{i∈S} z_i δ_i v_i. Then δ′ exists with
these values iff τ_z ∈ span(F) for F := supp δ′ ∖ S, and the cost of the piece is s + |supp δ′ ∩ F|.
Two regimes:
- *F large.* If |F| ≥ q and F spans F_3^q, every τ_z is representable; z is free (take z = 0 or
  anything). The representation x of τ_z by F is the unique solution when |F| = q, and for a
  random pool it is a uniformly random nonzero vector of F_3^q given τ_z ≠ 0 (M^{-1}τ with M a
  random invertible matrix), so |supp x| = 2q/3 ± O(√q) w.h.p. Cost s + 2q/3: the same as two
  KOW rounds. Taking |F| = q + r and sampling the affine solution space changes nothing
  (coordinate marginals are uniform, §5).
- *F small.* If |F| = w < q, then span(F) ∩ span(S) has dimension w + (s − 1) − q (random
  pools; 0 if negative), so the τ_z that are representable form a subspace of codimension
  q − w inside span(S); z must be chosen so that τ_z lies in it. That is an F_3 subset-sum
  instance with s vectors (the images of δ_i v_i, i ∈ S, in F_3^q / span(F)) in dimension
  q − w. Solving it with the n²/3 method needs s ≥ (q − w)²/3, i.e. w ≥ q − √(3s) ≈ q − √(2q),
  which puts us back in the F-large regime up to lower order. Making the piece cheaper than two
  KOW rounds, say |F| = 0.58q (where a solution z exists by counting: 2^{2q/3} 3^{w−q} ≥ 1),
  requires solving a subset-sum instance with s = 2q/3 vectors in dimension 0.42q, ratio
  m′/n′ ≈ 1.6: harder than the original problem (whose ratio is ≈ n/3).

**(c) The generic 8/9 piece.** Two dependencies with δ′ random on S and supported on S ∪ W,
|W| = q/3 + 2, exist and cost ≈ 8q/9 (Plotkin-tight), but by Theorem 2 they gain only one
dimension.

Hence [proved as stated]: every piece gaining two dimensions costs either s + (a representation
of a chosen target by fresh columns) or needs a defect-2 support; in both cases the saving over
two KOW rounds equals the saving of a representation or dependency below the averaging weight
2|F|/3, which is syndrome decoding below the Plotkin radius, or an F_3 subset-sum instance at
ratio ≈ 1.6. This is the p = 3 form of report B's self-similarity.

## 5. Model A and Theorem 6 (the barrier)

**Model A (linear-algebraic piece schemes at p = 3).** The algorithm keeps the realized subgroup
U and works with the images of unused columns in F_3^q, q = n − dim U. It builds pieces from
vectors x ∈ F_3^F (F ⊆ unused columns) obtained as follows: it chooses F, a set P ⊆ F with
prescribed values x_P = c, and a target τ ∈ F_3^q, forming the affine space
A = {x : x_P = c, Σ_F x_i v̄_i = τ}; if A ≠ ∅ it receives **uniformly random samples** from A
(polynomially many in total over the run). Pieces, prescriptions, targets, and which samples to
keep may depend on everything seen. A piece X realizes a subgroup H only through 0/1 vectors y
with y − y′ ∈ span(samples) whenever φ(y) = φ(y′) (that is, the certified relations are the
sampled dependencies and their combinations). The run ends when q = 0 (then any column is a
zero-sum completion by Lemma 1).

KOW's algorithm is in Model A: F = the first q + r columns, P = ∅, τ = 0, and the sparsest of
3^r − 1 samples (its derandomization by conditional expectations is replaced by exhausting the
≤ 3(q+1) nonzero elements of A, which is polynomial). Excluded from Model A: finding minimum-
weight elements of A beyond sampling (information-set decoding), solving the 0/1 constraint
systems of §4(b), and searching over sets F for the pattern-gap event of §4(a).

**Lemma 6.1 (sampled weights) [proved].** Let A ⊆ F_3^F be a nonempty affine space and let F′
be the coordinates whose functional is non-constant on A. For x uniform in A, each coordinate in
F′ is uniform on F_3, and two coordinates in F′ whose functionals are not affinely proportional
are independent. Hence E|supp x ∩ F′| = (2/3)|F′| and, if at most ρ|F′| coordinates of F′ are
proportional to another one, Var ≤ (2/9)|F′| + ρ|F′|², so P(|supp x ∩ F′| ≤ (2/3)|F′| − λ) ≤
((2/9)|F′| + ρ|F′|²)/λ². *Proof.* An affine functional non-constant on A is uniform; two
non-proportional ones are jointly uniform on F_3^2 (their difference space has dimension 2);
Chebyshev. ∎ On random pools, proportional coordinate pairs in the relevant A are columns
proportional modulo the fixed part, an event of probability O(3^{−q}) per pair, so ρ = o(1) and
λ = q^{3/4} already gives failure probability o(1) per sample, and poly(m) samples lose at most
O(q^{3/4} log m) below 2|F′|/3 with probability 1 − o(1).

**Lemma 6.2 (fresh support of a sample) [proved for random pools, w.h.p. over the pool].** Let the
pool be uniformly random, let S_old be the union of supports of all previously sampled vectors
of the current piece (|S_old| ≤ q − 1), and let x be a sample from A as above with x ∉ span of the
earlier samples. Then |F′ ∖ S_old| ≥ q − |S_old ∩ F′| − O(1)... more precisely: the columns of
F′ ∖ S_old together with the columns of S_old ∩ F′ carry the homogeneous space A^0 of A, and
every element of A^0 not in the span of earlier samples has Σ_{F′∖S_old} x_i v̄_i ∈ span(S_old),
so |F′ ∖ S_old| ≥ q − dim span(S_old ∩ F′) ≥ q − |S_old ∩ F′| when the columns outside S_old
are in general position modulo span(S_old) (random pool, w.h.p. for the polynomially many sets
the run touches, by a union bound as in report B's Lemma G at p = 3 with the probability
3^{|T| − (q − dim span S_old)} per set). ∎

**Theorem 6 (barrier in Model A) [proved under Model A on uniformly random instances].**
Let an algorithm in Model A solve uniformly random instances with probability ≥ 1/2. Then, with
probability 1 − o(1) over the instance:
(i) if every piece uses at most two sampled dependencies, the number of columns in pieces is
    ≥ Σ_{q=1}^{n} 2q/3 − O(n^{3/2} log m) = n²/3 − O(n^{3/2} log m);
(ii) in general it is ≥ (log₂3 − 1)·Σ_q 2q/3 − o(n²) ≥ 0.195 n² − o(n²).
*Proof.* Consider a piece started at codimension q that gains d. By Lemma 3 it certifies d
through K with dim K ≥ 0.585 d independent sampled vectors, so it contains k ≥ 0.585d samples
x_1, …, x_k, independent modulo earlier ones. Order them as sampled; by Lemma 6.2 the j-th has
≥ q − |S_old ∩ F′_j| non-constant coordinates outside the earlier supports, plus |S_old ∩ F′_j|
non-constant coordinates inside; by Lemma 6.1 it is nonzero on ≥ 2/3 of each part minus
O(q^{3/4} log m). The part inside S_old costs nothing new but puts all three values of x_j on
those coordinates, and if |S_old ∩ F′_j| ≥ 1 the piece's joint patterns contain whole lines
{a} × F_3 on those coordinates. For (i): with two dependencies, Theorem 5 says a gain of 2 needs
T ⊆ T_1, …, T_4. T_1, T_2 need the second dependency inside the first support (|F′_2 ∖ S_old| = 0),
which Lemma 6.2 forbids unless dim span(S_old) ≥ q, i.e. |S_old| ≥ q — then the first dependency
alone already cost ≥ q ≥ 2·(2q/3)·(3/4), and more precisely a first sample with |F′_1| = q + r
has weight ≥ (2/3)(q + r) − o(q), so a second dependency inside its support needs a sample of
A^0 ⊆ D(S_1) with S_1 of size (2/3)(q + r) ≥ q, i.e. r ≥ q/2, and the piece then costs
≥ (2/3)(3q/2) = q for 2 dimensions only if the sampled first dependency has full support on a
defect-2 set, which has probability ≤ 4(3/4)^{|F|} per sampled F (§4(a)). T_3, T_4 need δ′
prescribed on all of S_old = S (values in {0, δ_i}), so F′_2 ∩ S = ∅. The prescription c, hence
the target τ_c = −Σ_S c_i v̄_i ∈ span(S), is fixed before sampling. For a random pool and a fixed
nonzero τ_c, the sample space A is nonempty only if τ_c ∈ span(F_2 ∖ S); for a set W of w fresh
columns, span(W) ∩ span(S) has dimension max(0, w + s − 1 − q), so a *fixed* τ_c lies in it with
probability ≤ 3^{w − q} (over the pool, union-bounded over the polynomially many (c, W) the run
can name), and w ≥ q − O(log m) is needed w.h.p.; then F′_2 ⊇ a set of ≥ q − O(log m) fresh
columns and Lemma 6.1 gives fresh weight ≥ (2/3)(q − O(log m)) − o(q). If τ_c = 0 (c = 0) the
second sample is a dependency on fresh columns, again of fresh weight ≥ (2/3)(q + 1) − o(q).
So a two-dependency piece gaining 2 costs ≥ (2/3)(q + 1) + (2/3)(q − O(log m)) − o(q)
= 4q/3 − o(q). A piece gaining 1 costs ≥ (2/3)(q+1) − o(q). Summing over the
pieces, with q decreasing by the gains, gives (i). For (ii) drop Theorem 5 and use only
k ≥ 0.585d samples each of fresh weight ≥ (2/3)(q − d) − o(q) (a piece can gain at most
k/0.585 ≤ 1.71k, and d ≤ q). ∎

Remarks on the proof. The T_3/T_4 case is where the argument is delicate: in Model A the
prescription c (equivalently z ∈ {0,1}^S) is chosen before the sample, and Lemma 6.2 is applied to
the resulting A; the §4(b) F-small regime is exactly what Model A cannot do (it would need a z
with τ_z in a small span, found by search). I have written the case analysis in full for k ≤ 2
only; the general-k constant 0.195 uses only Lemma 3 and Lemma 6.1/6.2 and is loose.

**What Theorem 6 does not say.** It is not an instance lower bound: with m = cq² columns a
dependency of weight O(q/log q) exists in every instance (sphere packing), and a representation
of some τ_z by 0.58q fresh columns exists by counting. It says that finding them is outside
Model A. Any algorithm beating 1/3 must therefore contain a step that is not a uniform sample
from a linear-algebraically described affine space: a decoding step below the Plotkin radius, a
solver for 0/1 points in subspaces (an F_3 subset-sum instance at ratio ≈ 1.6), or a set-search
for defect-2 supports. The self-similar instances are specified in §4.
