## Overall verdict

**GAP, repairable by text changes. The theorem is CORRECT WITH FIXES, proved given cited
theorems, once the two GAP items below are repaired.** The group theory (Lemmas C and E, the
isomorphism A/⟨z^e⟩ ≅ Z^2 × Z_e, the rank split, H ⊆ A_v, and the index formulas) holds, and
I re-derived each part. The two gaps are in how the quantum subroutines are used:

1. **Step 1 acceptance rule (GAP).** The note says an accepted candidate can only equal e. That
   is false: the exact test f(z^r) = f(1) accepts every multiple of e. Continued fractions on a
   "bad" measurement outcome can return a proper multiple of e below the cutoff. Computed
   instance: e = 3, b = 1, outcome k = 34 out of Q = 512 gives r = 15, which passes the test
   (probability about 7·10^-4 per run). The lcm rule makes this worse, since lcm(3, 15) = 15
   passes too. The failure rate per run is a constant that does not depend on ε, so more
   repetitions make it more likely that some run accepts a wrong value. A wrong e' = ke is then
   output as H = ⟨z^{e'}⟩ ⊊ H in the rank-0 case. Fix: output the gcd (equivalently the minimum)
   of all accepted values.
2. **Kuperberg's input model and the box (GAP).** Kuperberg's Thm 1.5 is stated for a hiding
   function on all of Z^k with polynomial query cost, with no box. The note's claim "B = O(b)
   suffices" is unsupported, because the box Kuperberg's algorithm queries is not given in any
   text I could read. A correct statement is B = poly(b), by a register-width argument, and it
   holds only if Thm 1.5's time bound is a worst-case bound that can be run with only an upper
   bound on n, and the algorithm has bounded error. §7 of Kuperberg has to be read to confirm
   this. The note also never bounds the n that Thm 1.5 actually uses. That bound is O(b) (proof
   below), but the note's §7 justification for it ("S is generated by h^m") is wrong in rank 2.

Even after the fixes, the label must say what it rests on. That is Kuperberg Thm 1.5 (arXiv v1,
unrefereed as far as I know, §7 unread here) and cor:utz, which is itself "AI-checked, pending
human review".

## Primary statements relied on (Kuperberg, arXiv:2507.18499v1)

The copyright rule limits me to one short verbatim quote; everything else is paraphrased with
its number.

* **Thm 1.5.** HSP in Z^k with polynomial query cost for the hiding function is solvable for
  arbitrary hidden subgroups, "uniformly in quantum polynomial time poly(k,n)". Here k is the
  dimension and n the bit complexity of the answer. The text does not say whether n must be
  supplied, what the error probability is, or which points are queried.
* **Cor 1.7.** The same holds in any finitely generated abelian group, in time polynomial in the
  bit complexity of the answer. Its proof (§2.4) pulls f back along v ↦ e_1^{v_1}⋯e_k^{v_k} from
  Z^k. That is exactly the F̃ used above.
* **§2.4.** The running time is parametrized by the cost of the calls to f needed to witness
  generators of H. Unless stated otherwise, f costs time polynomial in the input length, with
  elements of Z^k written as binary integers (signed). The hiding is right-periodic: f(x) = f(y)
  iff y = xh.
* **Thm 1.8 is labelled "(Outlined)"**, and Cor 1.9 follows from it. Thm 1.5 and Cor 1.7 are not
  labelled as outlined. The note's remark that Cor 1.9 is not enough here is consistent with
  this; Cor 1.9 is also only as strong as an outlined theorem.
* **Mosca–Ekert §§2, 4.2: not read** (only the abstract page was allowed). The Step 1 analysis
  above is the textbook Shor/Kitaev continued-fraction analysis, checked numerically, not ME's
  text.
