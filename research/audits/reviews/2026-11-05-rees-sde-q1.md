## 0. Verdict

**Q1 is not fully solved. It is reduced to one precise obstruction, the absorption load.**

1. **The critical case is solved [proved].** Take any stall with |B∖U_L| = q. This includes the
   case Q1 names: q = 1, |B∖U_L| = 1, no unused column. At such a stall, B∩U_L spans U_L, and a
   backward pass restricted to U_L succeeds (Lemma A).
   - This needs no column count beyond reaching the stall.
   - It fails with probability ≤ ρ·max(1/G*_3(p), κ/(p−1)) per pass, the bound of Theorem 2.
   - This is ideas (1) and (2) of the brief: the steering sources are the true-pool columns
     together with B∩U_L.
2. **The search agent's refutation does not reach this repair [computed].** The search report
   shows that the dichotomy as posed, (i) a dense flat or (ii) a successful finishing pass (R4),
   is false on the identity order. Its `chain4` and `chainfull` banks hit the critical case
   exactly.
   - Lemma A is a third branch, outside (R1)–(R5).
   - It solves **all 33** of the search agent's banks on the identity order, deterministically,
     at their budget D_3(a)+a (`closure_on_search_banks.out`).
   - Each bank had 0 vanishing steering functionals and 0/20 single-pass failures.
   - So randomised column orders are not needed for these banks. The deterministic,
     order-by-order statement survives with the new repair.
3. **Theorem Q1 [proved].** Let κ ∈ {2,3}, let J = E = 3 and let f(r) = ⌊(r+2)²/4⌋ + 3r, which is
   D_3(r)+O(r).
   - For **every** bank of rank r with ≥ f(r) columns, ALG-Q1 reduces in deterministic
     polynomial time either to a direct solution or to a single "leaf". A leaf is a valid flag
     with sources satisfying the steering hypothesis. Back substitution then succeeds with
     probability ≥ 1/2 per pass.
   - The cost depends on one number c, the absorption load of the leaf, i.e. the most blocks
     added to one round:
     - every round has ≤ 3+c blocks;
     - expected time is κ^{3+c}·poly(r, log p);
     - the prime must satisfy p ≥ max(8κ^{2(3+c)}(3+c)², 2(3+c)rκ^{3+c}).
   - **c ≤ 2 unless a heavy stall occurs.** Then the procedure is polynomial at explicit primes:
     - κ = 2: p ≥ max(62000, 320r);
     - κ = 3: p ≥ max(3.75·10⁶, 2430r).
   - Always c ≤ ⌊r/2⌋.
4. **The obstruction: heavy stalls exist [computed].** A heavy stall has:
   - codimension q ≥ 3, q⁺ ≤ 1 and b ≥ q−1 (notation in §1);
   - remaining directions concentrated in one round, so absorption load ≥ 3;
   - both checkable recursion counts failing.

   What the computations show:
   - Hill climbing found 8 heavy stalls with load 3. All have the shape κ = 2, a = 7, q = 3,
     b = 2, with one 6-column round holding every remaining direction.
   - Every one is still solved: by the Y-recursion, and also by forcing the 6-block absorption
     (0/20 single-pass failures each, `heavy_absorb.out`).
   - No bounded-load guarantee is proved, so **the claim "polynomial for every bank with o(a²)
     columns" stays false.**

## 1. Notation (as in the parent report)

- **Bank and forward pass.** λ_1..λ_M is the bank, of rank r, with span V. SSS(E) works as in
  the parent report §3: a reserved basis B, greedy circuits modulo U, blocks inside classes, swaps
  and true-pool events.
- **Rounds.** Round l has support S_l, relation δ (nonzero on S_l), and blocks
  G_{l,0}..G_{l,n_l−1}.
  - W_{l,b} = Σ_{i∈G_{l,b}} δ_iλ_i, and e_l = Σ_b W_{l,b}.
  - Ω_l = span(W_{l,b} : b ≥ 1), and U_l = U_{l−1} + Ω_l.
- **Flag conditions.** A family of rounds with disjoint supports and blocks inside classes is a
  **flag** if:
  - (F1) for every l, W_{l,1..n_l−1} are independent modulo U_{l−1};
  - (F2) e_l ∈ U_{l−1}.

  It **realizes** U_L. The forward pass produces flags: (F1) is Theorem B(i) of the two-relation
  report, and (F2) holds by construction.
- **Steering functionals.** U_L = Ω_1 ⊕ … ⊕ Ω_L, and Π_j projects U_L onto U_j along
  Ω_{j+1} ⊕ … ⊕ Ω_L. For a cross-class pair (j, b, b′):
  - φ_{j,bb′} = (coord_b − coord_b′) ∘ (Ω_j-coordinates) ∘ Π_j, with coord_0 = 0;
  - φ_{j,bb′} ≠ 0 on U_L;
  - φ_{j,bb′} vanishes on U_{j−1} and on Ω_l for every l > j.
- **Stall quantities.** At a stall with U = U_L and q = r − dim U ≥ 1:
  - Fr is the free set (columns in no round), and B ⊆ Fr;
  - Fin = Fr ∩ U, and X = Fr ∖ U;
  - b = |B∩U|, and ε = dim U − b;
  - Rout is the set of round columns outside U;
  - U⁺ = span(round columns), and q⁺ = r − dim U⁺.
- **Primes.** G*_E(p) is as in the parent report §1. It is nonincreasing in E, since it is a
  minimum over 1 ≤ e ≤ E.

## 2. Lemmas

**Lemma 2 (steering without circuits) [proved].**
- *Setting.* Let rounds 1..L form a flag realizing U_L, with n_l ≤ E_max blocks per round and
  G*_{E_max}(p) ≥ 1. Let Src ≠ ∅ be a set of columns outside every S_l, with span(Src) ⊆ U_L.
  Let ρ be the number of cross-class pairs over all rounds.
- *Hypothesis (S).* For every cross pair (j, b, b′), φ_{j,bb′} does not vanish on
  span(Src) + span(e_l : l > j).
- *Conclusion.* Run the backward pass of Theorem 2 from τ = −Σ_{σ∈Src} t_σσ, with t_σ i.i.d.
  uniform in P. Each pass returns a nonzero x ∈ (P∪{0})^M with Σx_iλ_i = 0, supported on
  Src ∪ ⋃S_l, with probability ≥ 1 − ρ·max(1/G*_{E_max}(p), κ/(p−1)).

*Proof.*
- **Values.** Round l gets x_i = δ_i(β_{b(i)} + s) with β_0 = 0. These lie in P∪{0} iff
  s ∈ Good_l(β), by Theorem B(ii) of the two-relation report, which uses only that the blocks lie
  inside classes. Then Σ_{i∈S_l} x_iλ_i = Σ_{b≥1}β_bW_b + s e_l. So τ_{l−1} = Π_{l−1}(τ_l) − s e_l,
  which lies in U_{l−1} by (F2).
- **Telescoping.** The sum telescopes to Σx_iλ_i = −τ_L + τ_L − τ_0 = 0, since U_0 = 0. And
  x ≠ 0, since Src ≠ ∅ and t_σ ≠ 0.
- **Offset differences.** Induction gives τ_j = Π_j(τ_L) − Σ_{l>j} s_lΠ_j(e_l). So the offset
  difference at (j, b, b′) is F = −Σ_σ t_σφ(σ) − Σ_{l>j} s_lφ(e_l).
- **Failure needs a coincidence.** A pass fails only if some level has a cross-class
  coincidence. Otherwise equal same-class offsets merge, ≤ n_l distinct offsets remain, and
  |Good_l| ≥ G*_{n_l} ≥ G*_{E_max} ≥ 1.
- **Bounding the first coincidence.** Bound, for each cross pair, the probability that the
  first coincidence (scanning downward) is at that pair. Theorem 2(c) does this; that argument
  never uses the circuit property.
  - Case 1: some l > j has φ(e_l) ≠ 0, and m is the least such l. Given the history before s_m,
    F is affine in s_m with nonzero slope. s_m is uniform on a set of ≥ G*_{E_max} elements,
    since level m had no coincidence. So the probability is ≤ 1/G*_{E_max}.
  - Case 2: otherwise, by (S), some σ ∈ Src has φ(σ) ≠ 0. Then F = 0 has probability
    ≤ 1/|P| = κ/(p−1).
- Summing over the ρ pairs gives the bound. ∎

Theorem 2(c) is the special case Src = B: there span(B) = V = U_L, and (S) is automatic.

**Lemma A (closed prefix) [proved].**
- *Statement.* At any moment of the forward pass, and for any t ≤ L, let Fr_t be the columns in
  no round 1..t, and suppose span(Fr_t ∩ U_t) = U_t ≠ 0. Then Lemma 2 applies to rounds 1..t with
  Src = Fr_t ∩ U_t, E_max = E and ρ = ρ_t ≤ ρ.
- *Proof.* Rounds 1..t form a flag. Each φ_{j,bb′} (j ≤ t) is a nonzero functional on U_t, so it
  is nonzero on span(Src) = U_t. ∎

**Corollary A (structure of a stall, and the critical case) [proved].**
- *Statement.* At a stall:
  - pool ⊆ span(B∩U);
  - Fin = (B∩U) ∪ pool spans span(B∩U), of dimension b;
  - |B∖U| = q + ε;
  - ε = 0 ⇔ |B∖U| = q ⇔ Lemma A applies with t = L.
- *In particular,* every stall with |B∖U_L| = q is solved. This includes the Q1 critical case
  q = 1, |B∖U_L| = 1, no unused column, and its use needs no column count.
- *Proof.*
  - A true-pool column c lies in span(B∩U_l) at its event. Swaps remove only σ ∈ B∖U, and U only
    grows, so B∩U_l ⊆ B∩U_L and the pool lies in span(B∩U_L).
  - The unused columns T are independent modulo U, so they lie outside U.
  - The columns of B∩U are independent, so b = dim span(B∩U), and |B∖U| = r − b = q + ε.
  - Fin spans U iff b = dim U. ∎

**Lemma R (absorption by re-splitting) [proved].**
- *Statement.* Let a flag realize U_L. Let i be a round column of round l in a block G_{l,b}
  with |G_{l,b}| ≥ 2, and with λ_i ∉ U_L. Replace G_{l,b} by G_{l,b}∖{i} and append the new block
  {i} with index n_l, so round l now has n_l + 1 blocks. The result is a flag realizing
  U_L ⊕ Fλ_i.
- *Moreover,* every round column outside the current realized space lies in a block of size ≥ 2.
  So repeated absorption reaches U⁺ after exactly q − q⁺ steps, and any set of round columns
  independent modulo U can be absorbed in any order.
- *Proof.*
  - The relation and e_l are unchanged, so (F2) holds, and the blocks remain inside classes.
  - The new generators of round l span U_{l−1} + Ω_l + Fλ_i. If b ≥ 1, W_b = W′_b + δ_iλ_i; if
    b = 0, W_{1..} are unchanged.
  - By induction the new realized spaces contain U_{l′} + Fλ_i for every l′ ≥ l. So the final
    space contains U_L + Fλ_i, of dimension dim U_L + 1.
  - It is spanned by Σ_{l′}(n_{l′} − 1) = dim U_L + 1 generators. Hence all generators are
    independent, which is (F1) for every round.
  - *Singleton blocks.* A singleton block {i} with b ≥ 1 has λ_i ∈ Ω_l. A singleton block 0 has
    δ_iλ_i = e_l − Σ_{b≥1}W_b ∈ U_l.
  - U⁺ is spanned by the round columns, and U ⊆ U⁺. ∎

**Lemma S (singleton top rounds never spoil lower steering) [proved].**
- *Statement.* Let rounds 1..L form a flag realizing U. Let Fr be columns outside the S_l with
  span(Fr) = V. Let rounds L+1..L+m be built from columns of Fr, **every block a singleton**,
  such that all L+m rounds form a flag realizing V. Let Src = Fr ∖ (top supports). Then (S)
  holds for every cross pair of every lower round j ≤ L.
- *Proof.*
  - φ = φ_{j,bb′} is nonzero on V and vanishes on Ω_l for all l > j, in particular on every
    Ω_top.
  - For a singleton-block top round, span(e_top) + Ω_top = span{λ_i : i ∈ S_top}.
  - So if φ vanished on Src and on every e_l with l > j, it would vanish on Src ∪ (top columns)
    = Fr, which spans V. That is a contradiction. ∎

**Lemma T′ (top pair at codimension 1) [proved].**
- *Statement.* Let a flag realize a hyperplane U ⊂ V. Let Fr be free, with span(Fr) = V, and
  |X| ≥ 3 where X = Fr∖U. Take any distinct a_1, a_2 ∈ X and the top round S = {a_1, a_2} with
  δ_{a_1} = 1, δ_{a_2} = −λ̄_{a_1}/λ̄_{a_2} (bars are coordinates in V/U), and blocks {a_1}, {a_2}.
  This gives a flag realizing V, and Src = Fr∖{a_1, a_2} satisfies (S). Lemma 2 then applies,
  with ρ + 1 pairs and the same E_max.
- *Proof.*
  - (F1): δ_{a_2}λ_{a_2} ∉ U. (F2): e has zero image in V/U.
  - The lower pairs are covered by Lemma S.
  - The top pair's functional is a nonzero multiple of v ↦ v̄. It is nonzero at λ_x for any
    x ∈ X∖{a_1, a_2} ⊆ Src. ∎

This replaces the counting version of Lemma T used earlier in this pass (at most one bad pair per
lower pair). That version was correct but weaker: `check_lemmaT_core.out` tests it, and its "bad"
pairs ignore the source β. On actual codimension-1 snapshots no pair was ever bad, as Lemma T′
predicts (`check_lemmaT.out`).

## 3. Theorem Q1

**ALG-Q1** (`alg_thm.py: solve_thm`). Let E = 3, κ ≤ 3 and f(r) = ⌊(r+2)²/4⌋ + 3r. A zero column
is returned as a solution. Run the Theorem-2 forward pass. If it returns a direct solution, return
it. If it reaches V, the leaf is (flag, Src = B). At a stall (q ≥ 1), take the first case that
applies:

| # | condition | action |
|---|---|---|
| 1 | ε = 0 | **closure**: leaf (flag, Fin), Lemma A |
| 2 | q ≥ 3, b ≤ q−2 | recurse on the columns in Y = span(B∩U) |
| 3 | q⁺ ≥ 2 | recurse on the columns in U⁺ |
| 4 | q⁺ ≤ 1 | absorb q − q⁺ directions (Lemma R) and reach U⁺; if q⁺ = 0 the leaf is (flag, B); if q⁺ = 1, run CODIM1 |

- **CODIM1** (flag realizing a hyperplane H, all round columns in H): closure if Fr∩H spans H;
  otherwise a top pair (Lemma T′) if |Fr∖H| ≥ 3; otherwise recurse on the columns in H.
- **Load.** The code absorbs into the least-loaded round. Before a load-≥3 absorption it also
  tries the two checkable recursions (on Y and on U) whenever their counts hold.
- **Leaf.** A solution of a sub-bank, extended by zeros, solves the bank.

**Theorem Q1 [proved].**
- *Statement.* Let κ ∈ {2,3} and let p be a prime. Let the bank have rank r ≥ 1 and at least
  f(r) columns.
  - (a) ALG-Q1 runs in deterministic time poly(M, a, log p). It returns a direct solution or a
    leaf (flag, Src) that satisfies (S), lies in a sub-bank of rank r′ ≤ r, and has rounds of
    ≤ 3 + c blocks. Here c, the leaf's absorption load, satisfies c ≤ q − q⁺ ≤ ⌊r/2⌋.
  - (b) **c ≤ 2 unless the recursion passes a heavy stall**, i.e. case 4 with q ≥ 3, b ≥ q−1 and
    load ≥ 3.
  - (c) If G*_{3+c}(p) ≥ 1, each back substitution fails with probability
    ≤ ((3+c)r/2)·max(1/G*_{3+c}(p), κ/(p−1)).
    - For c ≤ 2 this is ≤ 2.5r·max(1/G*_5, κ/(p−1)) ≤ 1/2 when:
      - κ = 2: p ≥ max(62000, 320r);
      - κ = 3: p ≥ max(3.75·10⁶, 2430r).
    - In general it is ≤ 1/2 when p ≥ max(8κ^{2(3+c)}(3+c)², 2(3+c)rκ^{3+c}).
    - Each round costs ≤ 2κ^{3+c} expected coset draws.

*Proof.* Induction on r. The forward pass is Theorem 2(a). At a stall, Theorem 2(b) and
M ≥ f(r) ≥ D_3(r) + r give π ≥ 1. Hence U ≠ 0, b ≥ 1 (pool ⊆ span(B∩U), Corollary A) and r ≥ 2.
The decomposition M = r + |Rcols| + π + |T| holds, with |Rcols| ≤ D_3(r) − D_3(q) and |T| ≤ q.
So π ≥ 2r + D_3(q) − q.

The facts used about f are these:
- f is increasing;
- f(r) − f(r−1) = ⌊(r+2)/2⌋ + 3 ≥ 4;
- f(r) − f(r−2) = r + 7 for r ≥ 3, and f(2) − f(0) = 10;
- D_3(q) − D_3(q−2) = q + 1 for q ≥ 3.

The cases:
- **Case 1.** Corollary A and Lemma A.
- **Case 2.** Y = span(B∩U) has dimension b ≤ q − 2 < r, and contains B∩U and the pool. So it
  holds ≥ b + π ≥ b + 2r + D_3(q) − q columns. Since D_3(b) ≤ D_3(q−2) = D_3(q) − q − 1, this
  is ≥ D_3(b) + 3b = f(b) whenever 2r + 1 ≥ 2b, which is true. The sub-bank has rank b, and
  induction applies.
- **Case 3.** The columns outside U⁺ lie in X = (B∖U) ∪ T, because round columns and Fin lie in
  U⁺. So |X| ≤ (q + ε) + q = r − b + q.
  - If q ≥ 3, case 2 failed, so b ≥ q−1 and |X| ≤ r+1.
  - If q = 2, then |X| ≤ r+1 because b ≥ 1. (q = 1 cannot reach case 3.)

  So U⁺ holds ≥ f(r) − (r+1) ≥ f(r−2) ≥ f(r−q⁺) columns, and its rank is r − q⁺ < r.
- **Case 4, absorption.** Lemma R reaches U⁺ after q − q⁺ absorptions, each adding one block to
  one round. So c ≤ q − q⁺. For q ≤ 2, c ≤ 2. For q ≥ 3, b ≥ q−1 and ε ≥ 1 give
  r = q + b + ε ≥ 2q, so c ≤ q ≤ ⌊r/2⌋.
- **Case 4, leaf.** If q⁺ = 0, the leaf is (flag realizing V, B), and (S) holds because
  span(B) = V. If q⁺ = 1, CODIM1 applies with H = U⁺:
  - closure is Lemma A;
  - the top pair is Lemma T′;
  - otherwise |Fr∖H| ≤ 2. The columns outside H are exactly Fr∖H, so H holds
    ≥ f(r) − 2 ≥ f(r−1) columns, and induction applies.
- **Recursion depth.** Every recursion lowers the rank, so the depth is ≤ r, and the whole
  descent is deterministic. Only the leaf's back substitution is random.
- **(c).** Apply Lemma 2 with E_max ≤ 3 + c. The pair count satisfies
  ρ ≤ Σ_l C(n_l, 2) ≤ ((3+c)/2)·Σ_l(n_l − 1) ≤ (3+c)r/2.
  - For E′ = 5, Weil (parent §1) gives G*_5 ≥ κ^{−5}(p − 5 − 4(κ⁵−1)√p). This is ≥ p/64 for
    κ = 2 and p ≥ 62000, and ≥ p/486 for κ = 3 and p ≥ 3.75·10⁶. Then 2.5r·64/p ≤ 1/2 and
    2.5r·486/p ≤ 1/2 give the stated ranges.
  - The general range is Corollary 4's computation with E′ = 3 + c.
  - Expected draws per round are p/G* ≤ 2κ^{3+c}. ∎

**Remarks.**
- **Arity.** f(r) − D_3(r) = 3r, versus r for Conjecture 5. The extra 2r is used only in cases
  2–4. Case 1 (closure) needs no count, and that is why it already settles the search agent's
  banks at the budget D_3(a)+a.
- **[argued] Minimising the load.** Any set of Rout columns independent modulo U can be absorbed
  (Lemma R). So the least achievable max-load is a matroid-intersection value (linear matroid on
  Rout modulo U, against the partition matroid by rounds), computable in polynomial time. The
  code uses a greedy rule, which can only overestimate the load. On the heavy stalls found, the
  greedy value is optimal, since all of Rout lies in one round.
- **Ideas of the brief.**
  - (1) Pool columns with B∩U as steering sources: this is Lemma A, and it works exactly when
    ε = 0.
  - (2) Charging true-pool events to flats: this is case 2. All pool columns lie in the flat
    span(B∩U), which gives b + π columns there.
  - (3) A new invariant: the pair (ε, q⁺), together with Lemma S. Lemma S is what makes
    singleton top rounds free of steering conditions on the lower flag.

## 4. Strongest counterexample or limitation

- **The deterministic dichotomy (i)/(ii) of Q1 is false.** This is the search agent's result:
  see `2026-11-05-rees-sde-q1-search.md` §0 and §2, and its `banks/`. It is not repeated here.
  Lemma A solves every one of those banks (`closure_on_search_banks.out`, 33/33).
- **Heavy stalls exist [computed].** `heavy_find.py 3 60` ran 13,176 banks (`heavy_find_3.out`,
  `heavy_found_3.jsonl`).
  - Heavy stalls found: 8, each with greedy load 3.
  - All 8 have κ = 2, p = 10007, a = r = 7, q = 3, q⁺ = 0, b = 2 and ε = 2.
  - Their round profile is two pairs (or one triple) and one 6-column, 3-block round holding
    5–6 of the Rout columns.
  - Each was resolved by the Y-recursion, with 28–30 columns against f(2) = 10. Forcing the
    absorption instead (6 blocks, G*_6) also succeeded, with 0/20 single-pass failures each
    (`heavy_absorb.out`).
  - **No bound on c is proved.** A family forcing c → ∞ with both recursion counts failing would
    make ALG-Q1 super-polynomial. None is known.
- **Constraints a heavy stall must meet [proved, from the case analysis].**
  - q ≥ 3 and 2q ≤ r;
  - b ≥ q − 1 and ε ≥ 1;
  - q⁺ ≤ 1;
  - every absorption basis has some round with ≥ 3 columns;
  - π ≥ 2r + D_3(q) − q.
  - For the fallbacks to fail as well: cols(span(B∩U)) < f(b) and cols(U) < f(r−q).
- **Not covered.** E ≥ 4 or κ ≥ 4: the case-2 and case-3 counts were done only for E = 3. The
  budget D_3(a)+a of Conjecture 5: cases 2–4 use the extra 2r.

## 6. Claim gates that must stay false

- "A polynomial-time solver with D_3(a)+O(a), or any o(a²), columns exists for **every** bank."
  Theorem Q1 needs c = O(1); c = O(log a) would give quasi-polynomial cost with p ≥ poly(a).
- "Heavy stalls cannot occur." This is false: there are 8 computed instances.
- "Conjecture 5 is proved." Q1 uses 3a, not a, extra columns, and does not bound c.
- "A quadratic column count is necessary for existence, or for polynomial time." The first is
  false (parent Proposition 1); the second is unproved.
- "The result is uniform in p." It needs p ≥ max(62000, 320r) or max(3.75·10⁶, 2430r), or
  κ^{O(c)}.
- "The paper's proved arity for arbitrary columns changes." It stays at (a+1)(a+2)/2.
- Any novelty, priority or speedup claim.
