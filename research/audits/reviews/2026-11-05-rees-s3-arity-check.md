## 1. What the objects are

- **c** is the nilpotency class. Γ_0 is the set of grades d with κ_d = gcd(d, p−1) = p−1. Since
  d ≤ c < p, Γ_0 ≠ ∅ only if p = c+1, and then Γ_0 = {c}. So "1+⌈log₂ c⌉" means
  1+⌈log₂(p−1)⌉.
- **g = g_d** is the public dimension of γ_d/γ_{d+1}. **n = a_d = dim K_d^⊥ ≤ g_d** is the
  unknown label rank.
- **Weights.** At d = p−1, s^d ∈ {0,1}, so the node must find a nonempty zero-sum subset:
  average-case BinSIS(a_d, M, p) (`rem:fc-zero-sum-sis`(a),(b)).
- **Column law.** The labels are i.i.d. uniform on K_d^⊥ and independent of all earlier records
  on the non-abort event (`lem:fc-forest`(a)). After the echelon step, the coordinates are
  i.i.d. uniform on F_p^{a_d}, outside an event of probability ≤ p^{a−t}/(p−1)
  (`lem:s3-moment`(d), checked: (p^a−1)/(p−1)·p^{−t} < p^{a−t}/(p−1)).

## 2. The recursion: input law at every level (re-derived)

The question is whether each inner solver receives the law it needs. My argument:

1. **Coordinates.** A call 𝒜_j(d, ·) touches only coordinates 1..d of the columns it reads.
   This holds directly (β uses coordinate d, the inner calls and the recursion use 1..d−1) and by
   induction. Its number of reads is a stopping time for the filtration generated by
   coordinates 1..d of the stream.
2. **Fresh columns.** Every call starts on fresh columns at a stopping time of the full
   filtration. By the strong Markov property of an i.i.d. sequence, its columns are i.i.d.
   uniform and independent of the past.
3. **Uniform β.** Fix the σ-field of coordinates 1..d−1 of the whole stream. The sequence of
   switch blocks (I_k, α_k) of one loop is then determined, and α_k ≠ 0 (the bottom column always
   keeps weight 1; at the base level the kernel vector is nonzero). Coordinate d of the stream is
   still i.i.d. uniform, so the β_k are i.i.d. uniform, independent of (C_k, α_k), and
   independent across blocks.
4. **Wald.** K is a stopping time for (β_k), and {K ≥ k} ∈ σ(β_1..β_{k−1}) is independent of
   C_k. Wald gives E = σ_p·N_{j+1}(d−1).
5. **Read count.** The read count of 𝒜_j(d,t) is a deterministic function of the stream that
   does not depend on t. This is stronger than "its law does not depend on t". So
   N_j(d) = N_j(d−1) + σ_p N_{j+1}(d−1).
6. **Inner targets.** The inner targets are 0 at the switches and t-dependent only in the
   recursion. The recursion's inputs are fresh, so a target that depends on the past is
   harmless. Level j* is reached only through switches, with target 0.
7. **Correctness.** Correctness is deterministic once the subset sums cover F_p. Halving gives
   x − x' = α with x, x' ∈ D^{(j)}, including j = 0, where α ∈ {0,±1} gives x, x' ∈ {0,1}.
   Index sets are disjoint because every read is fresh.

**Exact checks** (`exact.json`):

  values (computed by my own DP over reachable sets). The bound σ_p ≤ min(p, ⌈2log₂(p−1)⌉+4)
  holds.
- The DP also re-checks that R + β = R with β ≠ 0 never occurs.
- N_0 at p = 3 equals 1+3n(n+1)/2 for n ≤ 100. The closed-form bound holds for n ≤ 200 at
  p ≤ 17, and N_0 is increasing.
- The log-log slopes from n to 2n at n = 100 are 1.99, 3.00, 4.01 and 5.03 at p = 3, 5, 7, 11:
  degree 1 + j*.

**Statistical check of the input law** (`indep.json`). Chi-square tests at every level j, on
runs at (p, n) = (3,24), (5,8), (7,6), (11,4):
- the law of β for the first switch of each loop, which has no selection;
- all β's pooled;
- the contingency of β_{k+1} on β_k;
- the contingency of β_k on whether C_k exceeds its median.

All 38 p-values (two tests have too few cells) lie in [0.076, 0.99]. My first pair test, a goodness-of-fit test on the joint
cells, rejected strongly. That was my own error: survival to k+1 depends on β_k, so the joint
law is biased while the conditional law is not. The contingency test is the right one.

**Negative control (peek).** The switch draws two inner solutions and keeps the one with the
smaller β, so it reads coordinate d before choosing. The uniformity tests then reject
(p ≤ 3·10⁻³ at every level, down to 0), and every output is still exact. So the diagnostics have
power, and the freshness/reading restriction is what the uniformity rests on.

## 3. Arity and abort accounting (Cor. P.4)

- **Spanning event.** t = g + ⌈log_p(2/τ)⌉ gives Pr[W ≠ K^⊥] ≤ τ/(2(p−1)).
- **Overruns.** Outside that event, each run on its block of L ≥ 2N_0(g) ≥ 2N_0(a) labels
  overruns with probability ≤ 1/2 (Markov). The runs are independent because the blocks are
  disjoint. With k = ⌈log₂(2/τ)⌉ blocks, all overrun with probability ≤ τ/2. Total ≤ τ.
- **Termination.** Every inner call reads at least one label, so a capped run always terminates.
- **Labels outside W.** A label outside W is detected. Labels inside W are mapped injectively, so
  a witness found in coordinates is a witness for the labels. The node never returns a wrong
  output.
- **Arity.** M = t + kL = O_c(g^{1+⌈log₂c⌉}·log(1/τ)).
- **Tree accounting.** With τ_d = ε/(9(c−1)Sn_d), as for the existing variant after
  `lem:fc-zero-sum`, the abort sum over Γ_F ∪ Γ_0 is at most |Γ_F ∪ Γ_0|·ε/(9(c−1)) ≤ ε/9, so
  `lem:fc-forest`(b) is unchanged.
- **Gap G1 (fixed).** (R1) requires every arity to be computed from public data. N_0 involves the
  exact rational σ_p, a 2^p DP that the report does not mention. The inserted text uses N̄_0,
  which is N_0 with the public bound min(p, ⌈2log₂(p−1)⌉+4) in place of σ_p. N_j is monotone in
  σ, so Markov still applies. My runs used exact N_0, so they are slightly more demanding.

**Measurements** (`reads.json`, `node.json`):
- **Reads.** 18 rows: p = 3 (n ≤ 48), 5 (n ≤ 14), 7 (n ≤ 8), 11 (n ≤ 6), with 20–120 runs each.
  The mean reads match the exact N_0 with max |z| = 1.87. Every output, and every intermediate
  output at every level, was checked exactly: weights in D^{(j)}, weighted sum equal to the
  target, nonempty. Inhomogeneous targets at levels 0 and 1, p ∈ {5,7,11}: 90/90 exact.
- **Node.** 12 rows: p ∈ {3,5,7,11}, g from 2 to 12, τ ∈ {0.05, 0.5}, a uniform in [0, g]. The
  abort rate was ≤ 0.01 in every row (bounds 0.05 and 0.5). Every abort was a spanning failure.
  No block overran: the measured Pr[R > 2N_0] = 0 in 1300 runs, against the Markov bound 1/2, and
  Pr[R > N_0] = 0.40–0.47. Every witness was checked in F_p^g.
- **Arity vs g.** At τ = 10⁻³ and exact N_0, the slopes of log₂ M from g to 2g at g = 128 are
  1.99, 3.00, 4.01 and 5.03 for p = 3, 5, 7, 11. The claimed degrees are 2, 3, 4 and 5; Schedule 1
  has 4, 12, 18 and 40. My M at (3,12,0.05) is 2836, the same as the report's.
- **Small g.** At small g the node's arity far exceeds Davenport's g(p−1)+1 (2836 vs 25 at
  p = 3, g = 12). The node trades arity for polynomial time; it does not reduce arity relative to
  the existing zero-sum node (Imprecision I2 below).

**Negative controls** (`neg.json`):
- **Biased columns.** Columns with i.i.d. {0,1} entries (p = 5, 7): the mean reads miss N_0 by
  z = 16.8–20.4. The exact expectation genuinely needs uniform columns.
- **Hyperplane bank.** The first g labels are e_1..e_g, and every later label has v_g = v_1. Every
  top-level β vanishes, and the node aborted in 80/80 trials (p = 3, 5, 7). It never returned a
  wrong witness. This confirms that the node is not total, as the report's Part D says.

  - (iv) is correctly labelled a reading.

  - (b): the supermartingale is valid because B'_d is predictable.
  - (c): sparse relations are a property of the first M stream columns, union over d ≤ δ/2.
  - (d): the counting holds.

    weightings per block only.
