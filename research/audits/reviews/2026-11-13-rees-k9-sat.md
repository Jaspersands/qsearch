## 3. Correctness arguments

### 3.1 Symmetries used (PROVED)

- **Scaling, m ↔ 9 − m.** If B solves (p, κ, K), then B' = g^r·B is again of the form
  F1 + F2 + F3, B'(0) ≠ 0, and cl(B'(x)) = cl(B(x)) + r ∈ (K + r) − |x|. So it solves K + r. With
  r = −m this maps {0, m} to {−m, 0} = {0, 9 − m}. Hence m and 9 − m are equisatisfiable, and the
  gauge conditions are preserved, since zeros stay zero.
- **Choice of primitive root (remark).** Solutions for (g^u, K) correspond to solutions for
  (g, uK) through B*(x) = B(u^{-1}x), with u a unit mod κ. B* keeps the form because a coordinate-wise
  permutation preserves it, and it keeps B*(0) = B(0). So K = {0} is independent of the primitive
  root, which removes the "g = 2" caveat of 11-12 item 8. Scanning m = 1..8 at g = 2 covers every
  pair (primitive root, two-class target). The runs above used g = 2 only.
- **Also proved but not used in the runs:** P_κ-scaling fixes F1(0,0) ∈ {1, g^m}
  (`sat3_sub.py` options `sym`/`one`). Translation by t together with scaling by g^{|t|} shows that
  "B(0) ≠ 0" can be replaced by "B ≢ 0".

### 3.2 Gauge fixing for K ≠ {0} (PROVED, kept)

The gauge F2(0,·) = F3(0,·) = F3(·,0) = 0 is reached by three shifts that leave B pointwise
unchanged:
- F1 += a(l), F2 −= a(l), with a(l) = F2(0,l);
- F1 += b(j), F3 −= b(j), with b(j) = F3(0,j), which does not touch F2;
- F2 += c(i), F3 −= c(i), with c(i) = F3(i,0). This changes F2(0,·) and F3(0,·) by c(0) = F3(0,0),
  which is already 0.

The argument never uses the allowed sets, so it holds for every K, including {0, m}.

Empirical check: at (7,6) the gauge-free independent encoding never disagrees with sat3.py, and
(3,2) brute force agrees with and without the gauge.

### 3.3 Encoding

`sat3.py` encodes exactly:
- one-hot F values;
- S = F1 + F2 through implications S[u+v] ⇐ F1 = u ∧ F2 = v; with exactly-one F values, S then
  contains the true sum, and extra true S values only add constraints;
- forbidden (S = w, F3 = t) whenever w + t is not allowed.

So a model gives a valid B; this is checked independently by `verify_model.py` for every SAT
reported. Conversely, a valid B gives a model: set S to the exact sum. UNSAT is therefore sound,
but no UNSAT was obtained at κ = 9.

## 4. Four-level (and higher) joint contraction: count only (UNKNOWN)

An ℓ-level contraction is a B: Z_κ^ℓ → F_p in the space of sums of functions of ℓ − 1 coordinates.
That space has dimension κ^ℓ − (κ−1)^ℓ: B lies in it exactly when its ℓ-fold mixed difference based
at 0 vanishes. The cell condition is B(x) ∈ {0} ∪ ⋃_K Q_{m−|x|}, with 1 + |K|(p−1)/κ allowed values
out of p.

## 6. Adversarial self-check

- **Timeouts are not evidence.** Nothing at 37 is UNSAT. The tiny (7,6,{0,1}) also timed out at
  120 s with both encodings, so CDCL difficulty is intrinsic here and is not a sign of
  near-satisfiability.
- **Is the (19,9) SAT real?** Two verifiers, one sharing no code with the generator, check every
  cell and all 512 basis tensors. The decoding in `verify_model.py` assumes the variable layout of
  `sat3.py`; that layout is the first 3κ²p variables, in order, and the one-hot check passed.
- **Is it the right object?** The model gives a three-level contraction with classes in {0,1}. Using
  it as an {0,1}-node relies on the ℓ = 3 tensor (IS Lemma 12, ℓ = 3) with arity
  (a+1)(8a+1)(64a+1) as stated in `sat3.py`. I did not re-derive that tensor, and the paper states
  only the ℓ = 2 union target. A referee should check the ℓ = 3 analogue of lem:app-s2-witness /
  union-target before any use.
- **Degree accounting at 19.** Arity is (a+1)(8a+1)(64a+1) per stage, so two stages give degree 6.
  F0 uses −1 ∈ P_9 at 19. This holds because −1 = g^{(p−1)/2} = g^9 has class 0 (P_9 = {±1}).
  It does not need Weil or Gaussian elimination.
- **The 25 is untouched** by anything here. The p = 19 gain affects a non-binding prime.
- **Primitive-root remark.** The remark is a relabelling argument, and the CNFs were built with
  g = 2 only. The claim "m = 1..8 at g = 2 covers all roots" holds only once all eight m are decided,
  which they are not at 37.
- **Not done:** p = 73 for m = 2..4 (m = 1 timed out); LRAT certification (nothing UNSAT); four-level search; cadical runs.
