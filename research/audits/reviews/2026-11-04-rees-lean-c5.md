## 1. The quintic BCH group (`formal/Formal/BCHClassFive.lean`) — DONE

Law (`QSearch.BCHClassFive.bch`), over any field `F`:

```
x ⋆ y = x + y + [x,y]/2 + ([x,[x,y]] + [y,[y,x]])/12 - [y,[x,[x,y]]]/24
      - ([y,[y,[y,[y,x]]]] + [x,[x,[x,[x,y]]]])/720
      + ([x,[y,[y,[y,x]]]] + [y,[x,[x,[x,y]]]])/360
      + ([y,[x,[y,[x,y]]]] + [x,[y,[x,[y,x]]]])/120
```

The degree-5 terms are the standard BCH ones; the exact model
`2026-11-04-rees-lean-c5/model5.py` checks `log(exp x exp y) = x ⋆ y` modulo
words of length 6 in the free associative algebra over Q.

Proved (no `sorry`, axioms `propext, Classical.choice, Quot.sound` only):

- `classFive_of_lowerCentralSeries`: `lowerCentralSeries F L L 5 = ⊥` implies every
  right-normed length-6 bracket vanishes.
- `bch_assoc_of_classFive` / `bch_assoc`: associativity, assuming only
  `(2 : F) ≠ 0`, `(3 : F) ≠ 0`, `(5 : F) ≠ 0` and the class bound. So every
  `ZMod p` with `p > 5` (and every field of characteristic 0 or > 5) is covered.
- `bch_zero_left/right`, `bch_neg_left/right` (identity and inverses, no class
  hypothesis), `bch_of_lie_eq_zero` (commuting elements add), `map_bch`
  (naturality in Lie homomorphisms), `bch_smul_same`.
- `instGroup`: `Group (BCH F L hnil)` under `[NeZero 2] [NeZero 3] [NeZero 5]`;
  `val_mul`, `val_mul_formula`, `val_one`, `val_inv`, `val_pow`, `val_zpow`;
  `lieHom`, `lieEquiv` and their `id/comp/symm` lemmas.

### Proof strategy (scaled from `BCHClassFour`)

Same as class four: both sides of associativity are expanded by one `simp only`
call (bilinearity, `lie_lie` to right-normed form, length-6 vanishing) into
right-normed brackets of `x, y, z`, then `match_scalars` + `field_simp` + `ring`
compare coefficients. Uniqueness of the normal form is what makes this work, so
the rewrite set was completed to a full basis:

- degree 2: innermost pair sorted (`hyx, hzx, hzy`, `lie_self`);
- degree 3: `jacobi3 x y z` (`[z,[x,y]] ↦ [y,[x,z]] - [x,[y,z]]`);
- degree 4: six rules `r4a`–`r4f` (class four used only three of them: `r4a, r4b,
  r4e`; `r4c, r4d, r4f` are the `jacobi4c` instances `[a,[b,[a,b]]] = [b,[a,[a,b]]]`);
- degree 5: six rules `r5a`–`r5f`, each proved in Lean from ONE `lie_skew x W`
  instance (W a degree-4 normal word) after normalising with the lower rules.

The irreducible words number 3, 3, 8, 18, 48 in degrees 1–5, which are the
dimensions of the free Lie algebra on three generators, and the model checks they
are linearly independent; so the normal form is a basis and unique. Every rule has
integer coefficients and a single ±1 certificate. The rules were found by
`2026-11-04-rees-lean-c5/rules5.py` and printed by `gen_lean.py`; Lean does not
rely on these scripts (it proves each rule and compares the two normal forms).

Cost: the whole file checks in about 15 s (the associativity `simp` is under
`maxHeartbeats 4000000`; the default 200000 is not enough). No intermediate
grading or decomposition was needed.

Build command (from `formal/`, `PATH=$HOME/.elan/bin:$PATH`):
`lake env lean Formal/BCHClassFive.lean` — no errors, no warnings, all eight
`#print axioms` guards pass.

## 2. Prime-field subgroups are Lie subalgebras (`formal/Formal/BCHClassFiveSubgroups.lean`) — DONE

Lazard's subgroup direction at class five over `ZMod p`, `p > 5` (instances
`[Fact p.Prime] [NeZero 2] [NeZero 3] [NeZero 5]`; `neZeroTwo/Three/Five (hp : 5 < p)`
install them). Proved, no `sorry`, eight `#print axioms` guards pass:

- `bch_comm`: `log(x y x⁻¹ y⁻¹) = commPoly x y` (10 normal-form terms, degrees 2–5).
- `commPoly_left/right` (degree-3 iterated commutators `p3x, p3y`),
  `commPoly_ll/rl/rr` (degree 4: `p4xx, p4yx, p4yy`), and six degree-5 lemmas
  `commPoly_xxx … commPoly_yyy` (a commutator with a degree-4 word is its bracket).
  Group-level versions `val_comm`, `val_comm_left`, …, `val_comm_yyy`.
- `bracketWord x y` = `comm x y` times powers of the 2 + 3 + 6 iterated commutators
  of degrees 3, 4, 5 (coefficients −1/2, −1/2; 1/3, 1/4, 1/3; −1/4, −3/4, 7/12,
  −2/3, 1/2, −1/4); `val_bracketWord : (bracketWord x y).val = ⁅x.val, y.val⁆`.
- `addWord x y` = `x * y` times powers of the exact bracket monomials
  `bracketWord …` of degrees 2–5 (coefficients −1/2; 1/6, 1/3; −1/24, −1/8, −1/8;
  1/120, −1/60, 1/20, −1/20, 1/10, 1/30); `val_addWord : (addWord x y).val = x.val + y.val`.
  (This differs from class four, which corrected with commutator words; using the
  exact bracket monomials keeps every correction term a single monomial.)
- `bracketWord_mem`, `addWord_mem`, `mk_smul_mem`, `mk_lie_mem`, `mk_add_mem`,
  `toLieSubalgebra hnil H` (the logarithm of an ARBITRARY subgroup is a Lie
  subalgebra), `toSubgroup`, and the two round-trip lemmas
  `toLieSubalgebra_toSubgroup`, `toSubgroup_toLieSubalgebra`.

Two-letter normal form: `[b,a] ↦ -[a,b]` and `jacobi4c a b`; no degree-5 rule is
needed (the six words `a·w`, `w` a degree-4 normal word, are a basis). Words and
coefficients come from `2026-11-04-rees-lean-c5/words5.py`; the Lean file is
written by `gen_subgroups_lean.py` (re-running it regenerates the file exactly).
