## 1. What "21 is the floor of the calculus at 37" means (task 1)

## 2. The ℓ-level tensor (PROVED; this discharges "IS Lemma 12 at ℓ = 3")

Notation as in app:s2-tensor: κ ≥ 2 with κ | p−1, a coset generator ξ, z_m = ξ^m for m = 0..κ−1,
classes ind(·) ∈ Z_κ, Q_0 = P_κ, and W = {w ∈ F_p^κ : Σ_m z_m w_m = 0}. For y ∈ Z_κ^ℓ write
z^y = ∏_r z_{y_r}, so that ind(z^y) = |y| := Σ y_r (mod κ).

**Lemma T_ℓ (ℓ-level tensor).** Let M_ℓ(a) = ∏_{t=0}^{ℓ−1}((κ−1)^t a + 1). From any M_ℓ(a) columns
λ_b ∈ F_p^a one computes deterministically, with poly(a, κ^ℓ) field operations, O(M_ℓ) coset tests
and no roots, the following data:
- pairwise disjoint cells S_y ⊆ [M], one for each y ∈ Z_κ^ℓ;
- weights w_b ∈ Q_0 for the b in the cells, with a designated b* ∈ S_0 and w_{b*} = 1.

They satisfy the axis relations: the values T_y = Σ_{b∈S_y} w_b λ_b obey Σ_{y_r ∈ Z_κ} z_{y_r} T_y = 0
for every axis r and every choice of the other coordinates.

*Proof.*
- **ℓ = 1.** Take a nonzero dependence c of a+1 columns and normalise one nonzero entry to c_{b*} = 1.
  Put b in S_{ind(c_b)} with w_b = c_b / z_{ind(c_b)} ∈ Q_0. Then Σ_m z_m T_m = Σ_b c_b λ_b = 0.
- **ℓ−1 → ℓ.** Take N = (κ−1)^{ℓ−1}a + 1 level-(ℓ−1) objects μ on disjoint fresh columns.
  - The vectors V^μ = (T^μ_y), with y running over (Z_κ∖0)^{ℓ−1}, are N vectors in a space of
    dimension N − 1. So there is a dependence θ ≠ 0; normalise it to θ_{μ*} = 1.
  - **Claim:** Σ_μ θ_μ T^μ_y = 0 for every y ∈ Z_κ^{ℓ−1}. This holds when y has no zero coordinate.
    Otherwise induct on the number of zero coordinates: if y_r = 0, the axis relation of each μ gives
    z_0 T^μ_y = −Σ_{m≠0} z_m T^μ_{y[r:=m]}, and the right side has one fewer zero coordinate. The
    relation is linear in μ, so the sum vanishes.
  - Put j(μ) = ind(θ_μ) and w'_μ = θ_μ / z_{j(μ)} ∈ Q_0, so w'_{μ*} = 1. Define
    S_{(y,j)} = ∪_{μ: θ_μ≠0, j(μ)=j} S^μ_y, with weights w'_μ w_b. Then
    T_{(y,j)} = Σ_{μ: j(μ)=j} w'_μ T^μ_y.
  - New axis: Σ_j z_j T_{(y,j)} = Σ_μ θ_μ T^μ_y = 0 by the claim.
  - Old axis r: Σ_{y_r} z_{y_r} T_{(y,j)} = Σ_{μ: j(μ)=j} w'_μ Σ_{y_r} z_{y_r} T^μ_y = 0.
  - The cells are disjoint because the objects and their cells are disjoint.
  - b* of μ* lies in S^{μ*}_0 ⊆ S_0, with weight 1.
  - Column count: N·M_{ℓ−1}(a) = M_ℓ(a). ∎

For ℓ = 2 this is lem:app-s2-tensor, written with x-form weights w_b = ω_b^κ instead of roots.

**Definition.** An *ℓ-level K-contraction* at (p, κ) is a table C: Z_κ^ℓ → F_p such that:
- (i) every nonzero C_y lies in ∪_{k∈K} Q_k;
- (ii) C_0 ≠ 0;
- (iii) Σ_y C_y X_y = 0 for every X that satisfies the axis relations.

*Normal form (sufficiency, PROVED):* C_y = z^y B(y) satisfies (iii) whenever B = Σ_r B_r with B_r
independent of y_r. For then
Σ_y z^y B_r(y) X_y = Σ_{y_{−r}} (∏_{t≠r} z_{y_t}) B_r(y_{−r}) Σ_{y_r} z_{y_r} X_y = 0.

Such a decomposition exists exactly when the ℓ-fold mixed difference
Σ_{S⊆[ℓ]} (−1)^{|S|} B(y with y_S := 0) vanishes for every y. Write E_r for "set y_r := 0". If
∏_r(1−E_r)B = 0, then B is a combination of E_S B with S ≠ ∅, and each E_S B is independent of every
y_r with r ∈ S. The converse is clear.

In this normal form (i) and (ii) read: B(y) = 0 or ind(B(y)) ∈ K − |y|, and B(0) ≠ 0. For ℓ = 2 this
is lem:app-s2-normal. For ℓ = 3 it is exactly what `sat3.py` encodes, as B = F1 + F2 + F3.

**Lemma W_ℓ (contraction gives a K-relation).** Take the output of Lemma T_ℓ and an ℓ-level
K-contraction C. Put x_b = C_y w_b for b ∈ S_y, and x_b = 0 for b in no cell. Then:
- x ≠ 0;
- Σ_b x_b λ_b = 0;
- every nonzero x_b has class in K.

*Proof.*
- Σ_b x_b λ_b = Σ_y C_y T_y, and this vanishes coordinate by coordinate by (iii), because each
  coordinate of (T_y) satisfies the axis relations.
- x_{b*} = C_0 ≠ 0.
- ind(x_b) = ind(C_y) ∈ K, since w_b ∈ Q_0. ∎

**Consequence (PROVED, AI-checked).** An ℓ-level {0}-contraction at (p, κ) is a deterministic,
law-free {0}-node of arity M_ℓ(a), so of degree ℓ. An ℓ-level K-contraction is a K-node of degree ℓ:
a two-class stage node when |K| = 2, or a finish node in Lemma F. Roots are needed only at the end, as
for every other node (s_b = x_b^{1/κ}).

The k9-sat note left "IS Lemma 12 at ℓ = 3" as an open condition. It is the case ℓ = 3 here, and
needs nothing from IS. The construction is the IS collision recursion at depth ℓ; no priority is
claimed.

## 3. Composition: chains are product contractions (Lemma P, PROVED)

**Lemma P.** Let B_1 be an ℓ_1-level table in normal form with B_1(0) ∈ Q_0, every nonzero B_1(x) of
class in K_1 − |x|, and outgoing class s(x) = |x| + ind(B_1(x)) ∈ R. Let f: R × Z_κ^n → F_p have
the form f(s, y) = F(y) + Σ_{r=1}^{n} G_r(s, y_{−r}). Suppose that every nonzero f(s, y) has class in
K − s − |y|, and that f(0, 0) ≠ 0.

Put B(x, y) = B_1(x) f(s(x), y), with B = 0 where B_1(x) = 0. Then B is an (ℓ_1+n)-level
K-contraction table in normal form.

*Proof.*
- Write B_1 = Σ_r h_r with h_r independent of x_r. Then B_1(x)F(y) = Σ_r h_r(x_{−r})F(y), and each
  term is independent of x_r.
- B_1(x) G_r(s(x), y_{−r}) is independent of y_r.
- Classes: ind(B) = ind(B_1) + ind(f) ∈ (s − |x|) + (K − s − |y|) = K − |x| − |y|.
- B(0) = B_1(0) f(0, 0) ≠ 0, because s(0) = 0. ∎

A flexible-line chain step RC(D; R → K) is the case n = 1, with f(s, y) = α_{y mod D} + β_{s mod D}.
Its D-class condition gives exactly the κ-class bookkeeping above.

**Corollary P1 (the K_L ≠ {0} chain corollary, a second proof).** A chain whose last step is
(D_L, K_L) gives an (L+1)-level lift_κ(K_L)-contraction. By Lemma W_{L+1}, it is a
lift_κ(K_L)-node of degree L+1. Its arity is M_{L+1}(a) instead of the binomial C(a+L+1, L+1), with
the same degree.

This proof is independent of the induction claim C(t) in the proof of thm:app-s2-chain, which is the
route the bottleneck referee used. Every chain witness of `witness_dump.out` was composed and verified
as such a table (`chains_as_tensors.out`): the {0,4}, {0,1}, {0,1}, {0,3,8} and {0,2,5} nodes at 37,
73, 19, 19 and 37, and the {0}-chains at 181 and 433.

**Corollary P2 (the three-level SAT timeouts were satisfiable instances).**
- The chain (1,{0}) → (3,{0}) → (9,{0,4}) at 37 is a 3-level {0,4}-contraction.
- The k9-sat instance (37, 9, {0,4}) (sha 4fcfc41d7e0b67d6) timed out after 1500 s with kissat.
  With the chain's table fixed by unit clauses it is SAT in under 2 s, and the k9-sat verifier

f(0, 0, 0) ∈ Q_0. Lemma P with n = 2 composes it after any node whose output classes lie in R.

The cheapest use at κ = 9 starts from the two-level κ = 3 contraction RC(3; Z_3 → {0}), whose output
