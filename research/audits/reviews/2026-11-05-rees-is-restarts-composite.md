## 1. Setting (as in the 11-05 note)

- F_p^* = H_π × H_π′, |H_π| = n_π = ∏_{ℓ|κ} ℓ^{ν_ℓ}, H_ℓ the ℓ-Sylow subgroup. For a
  subgroup C ≤ H_π write C_ℓ for its ℓ-part and c_ℓ(C) = v_ℓ|C_ℓ|. Subgroups of the cyclic
  ℓ-group H_ℓ are totally ordered.
- The variant (V0)–(V4) of the 11-05 note:
  - anchor α = `_kernel_vector` of columns 0..a, π-parts γ_k (k ∈ K = supp α), k₀ = min K;
  - η₁ generates H₁ = ⟨γ_k⟩;
  - at the start and after every trigger the anchor test T(η) runs: T succeeds iff
    e_k ≡ e_{k₀} (mod g), where e_k = log_η γ_k and g = gcd(κ, |⟨η⟩|);
  - at a trigger, `_Restart(γ)` with γ ∉ ⟨η⟩ sets η := join(η, γ), a generator of ⟨η, γ⟩;
  - a restart is counted only when T fails.
- D_ℓ := the subgroup generated by the ℓ-components of γ_k γ_{k₀}^{−1} (k ∈ K); δ_ℓ = v_ℓ|D_ℓ|;

## 2. Theorem A [proved]

**Lemma 2 (test criterion).** Let H₁ ≤ C = ⟨η⟩ ≤ H_π. Then T(η) succeeds iff for every ℓ | κ:
D_ℓ = 1 or c_ℓ(C) ≥ δ_ℓ + e_ℓ. Call ℓ *failing at C* when D_ℓ ≠ 1 and c_ℓ(C) ≤ δ_ℓ + e_ℓ − 1.

*Proof.*
- Let h = |C| and g = gcd(κ,h). Then C^κ = ⟨η^κ⟩ = ⟨η^g⟩. Since g | h, η^x ∈ ⟨η^g⟩ iff g | x.
  So T succeeds iff every γ_kγ_{k₀}^{−1} = η^{e_k−e_{k₀}} lies in C^κ.
- C is the internal direct product of its parts C_ℓ, and (∏_ℓ y_ℓ)^κ = ∏_ℓ y_ℓ^κ, so C^κ is
  the product of the C_ℓ^κ. Write κ = ℓ^{e_ℓ}u with ℓ ∤ u. On the ℓ-group C_ℓ, y ↦ y^u is an
  automorphism, so C_ℓ^κ = C_ℓ^{ℓ^{e_ℓ}}. Hence x ∈ C^κ iff each ℓ-component of x lies in
  C_ℓ^{ℓ^{e_ℓ}}, and T succeeds iff D_ℓ ≤ C_ℓ^{ℓ^{e_ℓ}} for all ℓ.
- In the cyclic group C_ℓ, |C_ℓ^{ℓ^{e}}| = ℓ^{max(c−e,0)} with c = c_ℓ(C). Subgroups are
  totally ordered, so D_ℓ ≤ C_ℓ^{ℓ^e} iff δ_ℓ ≤ max(c−e, 0). For D_ℓ ≠ 1 (δ_ℓ ≥ 1) this
  says c ≥ δ_ℓ + e. □

Failing is monotone: if ℓ fails at C′ ⊇ C, it fails at C, since c_ℓ(C) ≤ c_ℓ(C′).

**Theorem A.** Let p be an odd prime, κ | p−1 with κ ≥ 2, a ≥ 1, and take any columns with
M ≥ N. Let R be the number of restarts of the variant.
- (i) R ≤ ρ(p,κ) − 1, so the variant makes at most ρ(p,κ) runs.
- (ii) More precisely, if some prime fails at H₁, then R ≤ R*(α), where
  R*(α) := max over ℓ* failing at H₁ of [ Σ_{ℓ≠ℓ*}(ν_ℓ − h_ℓ) + min(ν_{ℓ*}, δ_{ℓ*}+e_{ℓ*}−1) − h_{ℓ*} ].
  If no prime fails at H₁, T(η₁) succeeds and no run is made.
- (iii) R*(α) is the length of the longest strict chain H₁ = S₀ ⊊ S₁ ⊊ … ⊊ S_R in H_π with
  T failing at every S_i. Over all anchors, the maximum of R*(α) is ρ − 1.

*Proof.*
- **The chain.** By the 11-05 note (proof of Lemma 1(i)), the states form a strict chain
  S₀ = H₁ ⊊ S₁ ⊊ … in H_π, with S_i = ⟨η⟩ after the i-th trigger.
  - The algorithm stops at the first trigger whose test succeeds, or when a run completes.
  - If R ≥ 1 restarts occur, T therefore fails at S₀, S₁, …, S_R.
  - Each strict step in a cyclic group multiplies the order by an integer ≥ 2. Hence
    R ≤ Ω|S_R| − Ω|S₀| = Σ_ℓ (c_ℓ(S_R) − h_ℓ).
- **The bound.** T fails at S_R, so by Lemma 2 some ℓ* fails at S_R, and by monotonicity
  ℓ* also fails at H₁. Then c_{ℓ*}(S_R) ≤ min(ν_{ℓ*}, δ_{ℓ*}+e_{ℓ*}−1). For ℓ ≠ ℓ*,
  c_ℓ(S_R) ≤ ν_ℓ. Summing gives R ≤ R*(α), which is (ii).
- **(i).** Since δ ≤ h, min(ν*, δ+e*−1) − h* ≤ e* − 1, and h_ℓ ≥ 0. Hence
  R*(α) ≤ e_{ℓ*} − 1 + Σ_{ℓ≠ℓ*}ν_ℓ ≤ ρ − 1. Runs ≤ R + 1 ≤ ρ.
- **(iii).** Fix ℓ* failing at H₁. Let S* have parts H_ℓ for ℓ ≠ ℓ* and an ℓ*-part of
  exponent t = min(ν*, δ*+e*−1). Here t ≥ h*, because ℓ* fails at H₁.
  - A maximal chain from H₁ to S* (all steps of prime index) has length
    Ω|S*| − Ω|H₁|, which is the bracket of R*(α) at ℓ*.
  - ℓ* fails at every state of the chain, by monotonicity, since every state is ⊆ S*.
  - Conversely, the proof of (ii) shows no failing chain is longer.
  - The anchor (ω*, 1), with ω* of order ℓ* and ℓ* attaining ρ, gives h = δ = 1 at ℓ* and
    h_ℓ = 0 elsewhere. So R* = e* − 1 + Σ_{ℓ≠ℓ*}ν_ℓ = ρ − 1.
- **The identity ρ = max_{ℓ*}(e_{ℓ*} + Σ_{ℓ≠ℓ*}ν_ℓ).** This equals
  ν − min_ℓ(ν_ℓ − e_ℓ) = ν − min_ℓ v_ℓ((p−1)/κ).
- **Special cases.** For ω(κ) = 1, ρ = e. For ω ≥ 2, pick ℓ* ≠ argmax ν_ℓ: then
  ρ ≥ 1 + max_ℓ ν_ℓ. And ρ ≤ ν because κ | p−1. □

Remarks.
- (i) also holds under level-by-level evaluation: only the anchor (computed before the first
  run) and the strict chain are used.
- (ii) is never weaker than Lemma 1(iii) of the 11-05 note (R ≤ ν − Ω(h₁)). The ℓ*-term is
  ≤ ν_{ℓ*} − h_{ℓ*}, so R*(α) ≤ Σ_ℓ(ν_ℓ − h_ℓ).

## 3. Theorem B: explicit families [proved]

**The chain.** Fix ℓ* | κ. Let g_ℓ generate H_ℓ; it is found by search, and is used only to
*build* the family. Let z₁, …, z_ν ∈ H_π be the elements g_ℓ^{ℓ^{ν_ℓ−j}} (of order ℓ^j),
taken in this order (`chain`):
1. the ℓ*-steps j = 1, …, e*; so z₁ = ω* has order ℓ*;
2. for each ℓ ≠ ℓ*, the steps j = 1, …, ν_ℓ;
3. the ℓ*-steps j = e*+1, …, ν*.

Put Z_i = ⟨z₁,…,z_i⟩. Then [Z_{i}:Z_{i−1}] is prime, and Z_ν = H_π. Each z_i ∈ H_π, so its
π-part is itself. Put ρ* := ρ_{ℓ*} = e* + Σ_{ℓ≠ℓ*} ν_ℓ, which equals ρ when ℓ* minimises
ν_ℓ − e_ℓ (`best_ell_star`).

**Blocks.** For c ∈ (F_p^*)^a, B(c) is the a+1 columns e₁,…,e_a, −Σc_j e_j of F_p^a. Its
first-free-column kernel vector is (c₁,…,c_a, 1). Scaling the block by s ≠ 0 does not change
the kernel vector.

**Family A** (`family_a`; any κ ≥ 2, a with (κ(a+1)−1)a ≥ ν−1).
- The first κ(a+1)² columns are the κ(a+1) blocks of the first level-2 node:
  - block 0 is B(z₁, 1, …, 1);
  - blocks 1, 2, … are filled with z₂, z₃, …, z_ν, a per block, in order, padded with 1.
- The remaining columns are arbitrary nonzero.

**Family C** (`family_c`; κ ≥ 3, any a ≥ 1, spread=False). It is built from *good nodes*.
Take x = z₁.
- A **level-2 good node with merge coefficient y**:
  - child 0 = B(x,1,…,1);
  - child 1 = (−y)·child 0, a scaled copy;
  - all other children are copies of child 0.
- It is a **spine** node if y = x, and a **free** node if y is the next unused chain element
  (or x once the chain is used up).
- A **level-L good node** (L ≥ 3):
  - child 0 is a good level-(L−1) node whose level-2 descendant along child 0 is a spine node;
  - child 1 = (−x)·child 0, a scaled copy of all its columns;
  - children 2, …, n_L−1 are good level-(L−1) nodes, where n_L = κ^{L−1}(a+1).
- The first G(κ,a) columns form one good level-κ node; the rest are arbitrary nonzero.
- Free slots are counted as s₃ = n₃ − 2 and s_L = (n_L − 1)s_{L−1}, and s(κ,a) = s_κ.
  - At κ = 6, a = 1: s = 70·431·2591·15551 = 1 215 628 978 970.
- **Family B** (`family_b`, a = 1) is the level-3 special case with no spine: it uses only the
  first 2κ² level-2 nodes, so it needs ρ ≤ 2κ².
- In family C every level-1 coefficient is x or 1. The chain appears only as level-2 merge
  coefficients, so pre-joining or testing all level-1 relations does not defeat it.

**Lemma 3 (evaluation order) [proved, by reading `theorems/rees_is_sde_solver.py`].**
- No classification happens before the first run, apart from `zero_sum_of_powers`, which uses
  its own PiParts and no Classifier, and the anchor computation of (V0).
- `is_sde_solve` calls `_accumulate(level L)`. It descends to `children[0]` down to accumulate
  level 1, whose children are level-0 leaves and need no computation. It then calls
  `theorem11` on columns [0, G).
- `theorem11` calls `lemma12(level κ)`. Each `lemma12(level ℓ ≥ 2)` evaluates its children
  (`lemma12(level ℓ−1)` on consecutive slices) in index order, and only then its own merge
  kernel. At level 1 it computes the kernel and classifies its nonzero coefficients in index
  order (`_classified_kernel`).
- So every run is a depth-first traversal of one Lemma 12 tree on [0, G), starting at
  column 0. A `_Restart` at the first coefficient outside ⟨η⟩ ends the run.
- `_row_reduce` is the identity on both families, because the first a columns are e₁, …, e_a
  and every further column is expressed in that basis. No family column is zero, so the
  zero-column exit does not fire.

**Lemma 4 (good nodes) [proved].** Let ⟨η⟩ ⊇ Z₁ with c_{ℓ*}(⟨η⟩) ≤ e*.
- (a) r_x ≠ 0, where r_x = (log_η x) mod κ.
- (b) If a good node of level L ≥ 2 is evaluated with no trigger inside it, its output (the
  concatenation of its w_a over keys) is nonzero, provided that L ≥ 3 or the node is a spine
  node.
- (c) The only elements a good node classifies are x, 1, and the merge coefficients y of its
  free level-2 descendants. These are classified in depth-first order, and the copies repeat
  the y's of the subtree they copy.
- (d) A subtree scaled by s ≠ 0 computes the same kernel vectors and classes, and outputs
  multiplied by s.

*Proof.*
- **(a).** Let e = log_η x ∈ [0,|⟨η⟩|) and let η_* be the ℓ*-component of η, of order
  ℓ*^{c} with 1 ≤ c ≤ e*.
  - x is an ℓ*-element of order ℓ*, so η_*^e = x. Hence e ≡ ℓ*^{c−1}u (mod ℓ*^c) with ℓ* ∤ u.
  - If ℓ*^{e*} | e, then ℓ*^c | e, so η_*^e = 1, a contradiction. So ℓ*^{e*} ∤ e.
  - Since ℓ*^{e*} | κ, r_x ≡ e ≢ 0 (mod ℓ*^{e*}).
- **(d).** Induct on the level.
  - A scaled block has the same first-free-column kernel vector. So the same coefficients
    are classified with the same results, and its w's scale by s.
  - At a merge, all concatenated child vectors scale by s. Gauss–Jordan with the
    first-free-column rule then gives the same pivots and the same kernel vector.
- **(b), level 1.** On B(x,1,…,1), the kernel vector is (x,1,…,1,1). The shift to target 0
  puts x in class 0 and the 1's in class (−r_x) mod κ, which is not 0 by (a). Hence
  w_{(0)} = β^κ e₁ ≠ 0.
- **(b), level 2.** Let u ≠ 0 be child 0's output (level 1).
  - Child 1's output is −y·u by (d), and the other children output u.
  - Gauss–Jordan pivots at column 0. Column 1 reduces to zero, so it is the first free
    column, and the kernel vector is (y, 1, 0, …, 0), whatever the other children are.
  - It classifies y and 1. After the shift to target 1, y has class 1 and 1 has class
    (1 − r_y) mod κ.
  - For a spine node, y = x and r_x ≠ 0. So the two classes differ, the keys (k,1) carry
    β^κ u_k, and the output is nonzero.
- **(b), level L ≥ 3.** Child 0's output u is nonzero by induction, and child 1's output is
  −x·u. The kernel vector is (x, 1, 0, …), with the classes separated as above (target L−1).
  So the output is nonzero.
- **(c).** This follows from the three cases. Coefficients with value 0 are not classified. □

**Theorem B.** Let κ ≥ 2, κ | p−1, a ≥ 1 and ℓ* | κ.
- (i) If (κ(a+1)−1)a ≥ ν−1, the default algorithm makes exactly ν+1 runs on family A, with
  `spread` and `early_exit` arbitrary.
- (ii) Under the same condition, the variant makes exactly ρ* runs on family A.
- (iii) If κ ≥ 3, spread=False and ν−1 ≤ s(κ,a), the variant makes exactly ρ* runs on
  family C.
- (iv) Taking ℓ* = `best_ell_star`, (ii) and (iii) give exactly ρ runs. For κ = ℓ^e, family A
  with only z₁, …, z_{e+1} placed (e slots, and e ≤ 2κ−1 ≤ (κ(a+1)−1)a) gives exactly e runs
  for every a. So Lemma 1(ii) of the 11-05 note is attained by real columns.
- (v) Under the hypotheses of (iii), the default makes at least ρ*+1 runs on family C, and
  at least ρ*+2 when ρ* < ν.

*Proof.*
- **What is classified.** By Lemma 3, a run first classifies the chain slots in order, and
  between them only elements of Z₁ ∪ {1}:
  - in family A, the coefficients of the first κ(a+1) blocks, before the first merge;
  - in family C, the elements listed in Lemma 4(c), valid while c_{ℓ*} ≤ e*.
- **Induction.** A run whose η generates Z_i triggers exactly at z_{i+1}: earlier slots hold
  z_j with j ≤ i, or 1, or x, and z_{i+1} ∉ Z_i. The new η then generates
  ⟨Z_i, z_{i+1}⟩ = Z_{i+1}. In family C, the copies only repeat chain elements that are
  already in ⟨η⟩.
- **(i).** The default starts at η = 1 = Z₀. Runs 1, …, ν trigger at z₁, …, z_ν, giving ν
  restarts. Then η generates Z_ν = H_π, so the last run has no trigger. Hence exactly ν+1
  runs. (Independently, ν restarts is the maximum.)
- **(ii)/(iii).** The anchor is block 0 with kernel vector (z₁,1,…,1): H₁ = Z₁ and
  D_{ℓ*} = ⟨z₁⟩, so δ* = h* = 1, while D_ℓ = 1 for ℓ ≠ ℓ*.
  - By Lemma 2, T fails at Z_i iff c_{ℓ*}(Z_i) ≤ e*, that is, iff i ≤ ρ*. It fails at Z₁,
    so run 1 starts at Z₁.
  - Run i triggers at z_{i+1}. For i+1 ≤ ρ*, the test fails and a restart is counted. This
    gives ρ*−1 restarts (runs 1, …, ρ*−1).
  - Run ρ* either triggers at z_{ρ*+1}, where the ℓ*-exponent becomes e*+1, so T succeeds and
    the variant stops (collapsed); or, if ν* = e*, it meets no element outside Z_ν = H_π.
  - Either way the count is exactly ρ*.
  - In family C, Lemma 4 applies in runs 1, …, ρ*, since c_{ℓ*}(Z_i) ≤ e* for i ≤ ρ*.
    Its last run classifies in the same way until z_{ρ*+1} or until the end of the node.
- **(iv).** The argument of (ii) applies verbatim to the truncated chain, since z_{e+1} is
  placed; when ν = e, the chain ends at H_π.
- **(v).** The default starts at η = 1, and its first classification is x = z₁ (block 0), so
  run 1 triggers and η then generates Z₁. From then on, the runs with η generating Z_i,
  1 ≤ i ≤ ρ*−1, satisfy Lemma 4 and trigger at z_{i+1}, as in (iii). That is
  1 + (ρ*−1) = ρ* restarts, so at least ρ*+1 runs.
  - When ρ* < ν (that is, ν* > e*), the run with η generating Z_{ρ*} still satisfies Lemma 4
    (c* = e*). It triggers at z_{ρ*+1}, and the default has no test, so this is one more
    restart. □

**Corollary [proved; Dirichlet's theorem cited].** Let κ have two distinct primes.
- (a) For every K there are p and a such that the variant makes exactly ρ ≥ K runs and the
  default exactly ν+1 ≥ K runs, on family A.
  - Take ℓ | κ and k ≥ K. Choose a prime p ≡ 1 (mod κℓ^k): there are infinitely many, by
    Dirichlet. Then ρ ≥ 1 + ν_ℓ ≥ 1 + k.
  - Take a with (κ(a+1)−1)a ≥ ν−1.
  - Hence no bound in terms of κ alone holds for either algorithm.
- (b) At fixed a ≥ 1, the worst case of the variant over all p is at least s(κ,a)+1.
  - Pick ℓ ∈ π and set n := s(κ,a)+1 − Σ_{ℓ″≠ℓ} e_ℓ″, which is ≥ e_ℓ because s is huge.
  - Put t_ℓ = n and t_ℓ″ = e_ℓ″ for ℓ″ ≠ ℓ. Take the residue class r modulo
    ∏_{ℓ″|κ} ℓ″^{t_ℓ″+1} with r ≡ 1 + ℓ″^{t_ℓ″} (mod ℓ″^{t_ℓ″+1}) for every ℓ″. It is coprime
    to the modulus.
  - By Dirichlet it contains a prime p, and then v_ℓ″(p−1) = t_ℓ″ for every ℓ″ | κ.
  - Then ν = s(κ,a)+1 and min_ℓ(ν_ℓ − e_ℓ) = 0, so ρ = ν. Family C applies, since
    ν−1 = s(κ,a), and gives exactly ρ = s(κ,a)+1 runs (Theorem B(iii)).
  - Whether the worst case is bounded at fixed (κ, a) at all is open, because the families
    need ν−1 ≤ s(κ,a).

**Remark B.1 (node order) [proved].** The machine 𝓜 of the remark evaluates Lemma 12 level by
level, for all Theorem 11 calls of one accumulation level together
(`2026-11-04-rees-is-runtime-tm.md`).
- **Family A.** Every trigger used in the proof of B(i), (ii) lies in the first κ(a+1)
  level-1 nodes, including the collapse at z_{ρ*+1}. Under either order these nodes come
  first, in column order: in 𝓜 the level-1 nodes of all calls are evaluated in column order,
  following the layout of the -tm note. Otherwise the last run has η = H_π and cannot
  trigger. So Theorem B(i), (ii) hold for 𝓜.
- **Family C.** Take the filler, columns G..M−1, to be chain-free good level-κ nodes, i.e.
  `family_c(..., length=1)` repeated. Then every level-1 node of every call classifies only x
  and 1. The level-2 merges are met in column order, so the chain elements appear in the same
  order and copies only repeat earlier ones. Lemma 4 does not depend on the order, so B(iii)
  and (v) hold for 𝓜.

## 4. What this changes in `rem:is-runtime`

- **The variant's run factor.** For composite κ_d it becomes ρ ≤ ν instead of ν+1.
  - It is attained whenever ν−1 ≤ max(s(κ,a), (κ(a+1)−1)a).
  - For κ_d = 6 it equals 1 + max(ν₂, ν₃).
  - It can equal ν, for example when ν₃ = 1.
- **The runtime bound.** Since ν ≤ b−1, the run-count argument cannot remove the factor b
  from T^IS_d = C₁ d³ M_d b³ (g_d²+b²) at composite κ_d, so that bound stands.
  - This is **not** a lower bound on time. On families A and C every aborted run stops inside
    the first level-2 or level-3 node, a negligible fraction of N. Their total work is about
    one full run plus ρ short prefixes.
  - Whether the total work of the variant at composite κ_d obeys a b² bound like
    T^{IS,∗}_d is open [open].
  - A worst case for time would need triggers late in each run. These are η-dependent merge
    coefficients, which the families above do not control.
- **The default.** Attainment of ν+1 runs even at prime κ (B(i)) shows that the restart
  collapse of the 11-05 note genuinely needs the variant, at least for the run count.

## 6. Strongest counterexample; what remains open

- **Against a κ-only bound** (the hope of §9 of the 11-05 note): family C at a = 1, κ = 6,
  p = 4873482210321473860534273. The variant makes 76 runs and the default 77; both are
  forced, and both are the maximum possible (76 = ρ, 77 = ν+1). Letting p grow, together
  with a for family A, shows that no κ-only bound holds.
- **Against improving ρ for this variant:** whenever ν−1 ≤ max(s(κ,a), (κ(a+1)−1)a), ρ is
  attained (Theorem B). So in that range the run bound cannot be lowered without changing the
  algorithm.
- **The open question [conjecture/open].** Can a different deterministic algorithm keep the
  arity and use fewer than ρ runs at composite κ? Natural fixes and why they fail:
  - "Pre-join all level-1 coefficients" and "test every level-1 relation as an anchor" are
    both defeated by family C. There, every level-1 relation has π-parts {x, 1} with
    distinct ℓ*-classes.
  - Precomputing the final subgroup is blocked (11-05 note, Proposition 2).
  - Relabelling an interrupted run is blocked (11-05 note, §5).
  - Under ERH one run suffices for every κ (11-05 note, Remark 4) [cited there, not
    re-checked].
- **What the families do not cover.** They are tuned to the solver's kernel normalisation
  (the free coefficient is 1); they cover both node orders (Remark B.1). A different kernel scaling
  changes the π-parts seen, so the lower bounds are statements about that implementation of
  `thm:is-import`. Theorem A does not depend on either choice.
