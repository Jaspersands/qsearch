## 2. What the existing modules already cover in general class

Read before writing, to avoid duplication:

- `ReesLieConstruction` (any commutative ring, any class): the closure `[γ_r, γ_s] ⊆ γ_{r+s}`,
  the untruncated Rees subalgebra and `mem_rees_iff`, and the grade bound `nilpotent_cutoff`.
  `evaluation a` is a Lie hom for every `a`, `scaling a` a Lie endomorphism and `dilation u` a Lie
  automorphism for units. `rees_class_bound` gives class ≤ c.
- `ReesLieInterpolation`: `hiddenCover h points` is the intersection of the evaluation
  preimages, characterised coefficientwise for a unit determinant at points `1..c`, and is
  dilation-invariant.
- `ReesCentralQuotient` (any `d`): the tail ideals, the quotients `Trunc d`, central top
  kernels, `terminalEquiv : Trunc 1 ≃ₗ L` and the dilation weights.
- `ReesHomogenization.tuple_hides_of_isUnit`: an abstract tuple criterion for given group homs.
- `CentralCharacterDescent`, `CentralQuotientReceiver`: the descent channel for ARBITRARY finite
  groups.

The class-three restriction sits only in `BCHClassThree`, `BCHClassThreeSubgroups`,
`ReesGroupClassThree`, `ReesCentralQuotientBCH`, `ReesClassThreeReceiver` and
`ReesMeasuredReceiver`, which instantiate the group law.

### 3.2 `ReesGeneralLaw.lean`: targets (b) and (c), conditional on an explicit Lazard input

The general-class BCH/Lazard transport is isolated as a hypothesis, not proved:

```lean
structure NilpotentGroupLaw (F : Type u) [CommRing F] (c : ℕ) where
  mul : ∀ (M : Type u) [LieRing M] [LieAlgebra F M], M → M → M
  natural : ∀ {M N} [..] (φ : M →ₗ⁅F⁆ N) x y, φ (mul M x y) = mul N (φ x) (φ y)
  mul_assoc : ∀ M [..], lowerCentralSeries F M M c = ⊥ → ∀ x y z, mul M (mul M x y) z = mul M x (mul M y z)
  zero_mul : ∀ M [..] x, mul M 0 x = x
  neg_mul : ∀ M [..] x, mul M (-x) x = 0
def AdditiveOnCommuting law := ∀ M [..] (x y : M), ⁅x, y⁆ = 0 → law.mul M x y = x + y
def SubgroupsAreSubalgebras law := ∀ M [..] hM (H : Subgroup (LawGroup law M hM)),
  ∃ h : LieSubalgebra F M, H = subgroupOfLie hM h
```

**Argued** (core report §1.2(a), (c); Khukhro Ch. 9–10): for `c < p` the degree-c truncated BCH
product over `ZMod p` satisfies all three. The truncation is a Lie polynomial with coefficients
in `Z[1/c!]`, so it is natural. It is a group law on class ≤ c. It reduces to `x + y` when
`[x, y] = 0`. Its subgroups are closed under `+` and `[ , ]` by the Zassenhaus words, whose
`1/k` roots (k ≤ c) are integer powers in exponent p. That also covers infinite-dimensional `M`.
Over a non-prime field `SubgroupsAreSubalgebras` is false in general (subgroups are only
`F_p`-subspaces), which is why it is a separate hypothesis.

Proved in Lean from these hypotheses, for every class c (`ReesGroup law hnil` is the law group
on `rees`, `BaseGroup law hnil` the one on `L`):

| Theorem | Statement |
|---|---|
| `instGroup`, `lawHom`, `lawEquiv` | the law groups are groups; every Lie hom (equiv) is a group hom (iso) |
| `subgroupOfLie` | a Lie subalgebra is a subgroup, **from naturality alone** (via `h.incl`) |
| `evaluationHom_surjective` | `IsUnit s → Surjective (E_s : G̃ →* G)` |
| `evaluationHom_comp_dilation` | `E_s ∘ δ_u = E_{u s}` as group homs |
| `hiddenSubgroup_eq_iInf` | `exp h̃ = ⨅ i, (exp h).comap E_{s_i}` |
| `hiddenSubgroup_eq` | `exp h̃` is independent of the admissible points |
| **`tuple_hides`** | for any `f` with `f x = f y ↔ x⁻¹*y ∈ exp h`: `(fun i => f (E_{s_i} a)) = (fun i => f (E_{s_i} b)) ↔ a⁻¹ * b ∈ exp h̃` (no invertibility needed) |
| `tuple_hides_coeff` | with `inv`: the same `↔ ∀ r, coeff (a⁻¹*b) r ∈ h` |
| **`tuple_hides_arbitrary_subgroup`** | given `SubgroupsAreSubalgebras law`: for every subgroup `H ≤ G` there is `h` with `H = exp h`, and the tuple oracle hides exactly `exp h̃` |
| `dilation_hiddenSubgroup_iff` | `δ_u x ∈ exp h̃ ↔ x ∈ exp h̃` |

## 4. What remains outside the kernel-checked boundary

1. **The general-class Lazard input itself.** Lean has no construction of the degree-c
   truncated BCH product for c ≥ 4, and no proof of the three hypotheses for it. These are
   naturality and the group law on class ≤ c, additivity on commuting pairs, and subgroups ↔
   Lie subalgebras over `ZMod p`. The smallest next step is a class-four instance: the quartic
   term is `-(1/24)[y,[x,[x,y]]]`, and associativity is a finite identity in the free class-4 Lie
   algebra on three generators. A general-c proof needs the Dynkin formula with the `Z[1/c!]`
   denominator bound and the Hall-basis/free-nilpotent embedding argument of core report §1.2(a).
2. **The composed multi-stage measured receiver in general class.** `ReesMeasuredReceiver`
   (two stages, class three, fresh banks) is not generalised. `step_output` gives each of the
   c − 1 steps; an induction composing them on fresh banks was not attempted.
3. Unchanged from the paper: valid SDE witness policies are inputs; the solvers and arity bounds
   (Theorems `thm:power-sde`, `thm:random-column`, eq. `eq:is-arity`) are outside, as are oracle
   implementation, approximation errors, the final Fourier step and running time.

## 5. Exact statement that now holds

**Lean**, any c ≥ 1, any commutative ring R, any Lie algebra L with
`lowerCentralSeries R L L c = ⊥`:

- The Rees algebra has exactly the nilpotency class of L, and its top grade is central.
- `E_s ∘ δ_a = E_{as}`. For a unit s, `E_s` is onto and maps `⊕_{j>d} t^jγ_j` onto `γ_{d+1}`.
- For every Lie subalgebra h and any c points with unit evaluation determinant,
  `h̃ = ∩_i E_{s_i}^{-1}(h) = ⊕_r t^r(h ∩ γ_r) = ∩_{s∈R} E_s^{-1}(h)`, independent of the
  points, with `E_s(h̃) = h` for units s. Over a field this holds for any c distinct nonzero
  points.

**Lean, conditional on `NilpotentGroupLaw F c`** (plus `AdditiveOnCommuting` where marked, plus
`SubgroupsAreSubalgebras` for arbitrary H):

- The group-level tuple criterion holds for every class: `(f(E_{s_i}a))_i = (f(E_{s_i}b))_i`
  iff `a⁻¹ ⋆ b ∈ exp h̃`, and `exp h̃` is dilation-invariant.
- The central-quotient tower has central, additive step kernels with weights `u^(d+1)`.
- Every measured descent step outputs the next stage's coset source, given a valid SDE witness
  and nonzero traces.
- The terminal source is the additive coset source of all of h.

The access model is the tuple oracle on `G̃` built from the original hiding function f, with no
H-dependent input. No query count, error or running time is charged in Lean.

**Argued, not Lean:** the degree-c truncated BCH product over `ZMod p` with c < p satisfies the
three hypotheses (§3.2).
