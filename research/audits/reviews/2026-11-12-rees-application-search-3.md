### 2.1 Lemma U (unipotent DLP; settles MOR with p-automorphisms on Lazard platforms) [proved]

**Lemma U.** Let U = I + N ∈ GL_d(F_p) have order p^k, and let ν be the
nilpotency index of N. Given U and U^m, the residue m mod p^k is
computable in poly(d, log p) deterministic time.

*Proof.*
1. N^{p^k} = U^{p^k} − I = 0, and N^{p^{k−1}} ≠ 0 because U has order
   p^k. So p^{k−1} < ν ≤ p^k.
2. The minimal polynomial of N is x^ν. So I, N, …, N^{ν−1} are linearly
   independent.
3. U^m = Σ_{j<ν} C(m, j) N^j. Solving one linear system gives each
   C(m, j) mod p.
4. By Lucas, C(m, p^i) ≡ m_i (mod p), the i-th base-p digit of m. This
   holds for every i < k, since p^i < ν. ∎

**Application.** Let G be explicit Lazard (class < p, exponent p), and
let φ be an automorphism of p-power order given by φ(g_i).
- φ is a Lie automorphism of L = log G (Lazard correspondence).
- Its matrix on a basis of L comes from φ(log g_i) and bracket expansions.
- That matrix is unipotent, because it has p-power order in
  characteristic p.

So the MOR cryptosystem with p-automorphisms is classical on every
explicit Lazard platform. This includes Mahalanobis's case b, where φ is
trivial on all sections. That case is unipotent on L even though no
section shows it.

For class ≥ p, or opaque encodings, the problem is a cyclic DLP, which
Shor solves. It is never a Rees-type HSP.

Check: `unipotent_dlp_check.py/.out`, 200 random instances at p = 2, 3,
5, 7 with d ≤ 9 and orders up to p^k, 0 failures. This may be folklore;
no priority is claimed.

### 2.2 Lemma S (SDLP over Lazard semidirect products) [proved]

Let Γ = G ⋊ ⟨σ⟩ be an explicit Lazard group. That is, σ is an
automorphism of order p, and Γ has class c_Γ < p and exponent p. The
SDLP gives h = g σ(g) ⋯ σ^{t−1}(g), the G-component of (g,σ)^t, and asks
for t.

*Proof.*
1. In Lazard coordinates on Γ, log((g,σ)^t) = t·X, with
   X = log(g,σ).
2. The G-component of exp(tX) is a public polynomial map of t, of degree
   at most c_Γ < p. Its coefficients come from the BCH and inverse-BCH
   formulas of class c_Γ.
3. So h = P(t) is a system of univariate polynomial equations of degree
   below p.
4. t mod p is a common root. Cantor–Zassenhaus on the gcd of the
   coordinate equations finds it in randomized poly(m, log p) time.
5. Every root r satisfies P(r) = h, so any root is a valid shared-key
   exponent. ∎

For σ of order prime to p the problem leaves this setting. Imran–Ivanyos
then gives a quantum algorithm for solvable G [intro]. In no case is the
SDLP an HSP with an arbitrary hidden subgroup.

### 2.3 K11 in detail (extension-field Legendre)

**The oracle is a multivariate Legendre function.** For q = p^r, the
quadratic character of F_q is η = χ_p ∘ N_{F_q/F_p}, a standard fact.
So the extension-field Legendre PRF, x ↦ η(x + k), is literally
x ↦ χ_p(N(x + k)) on F_p^r: the L1 oracle with Q = N(x + k) of
degree r. Pandey's arXiv 2604.04833 [intro] studies this primitive, and
recommends degree d ≥ 2 keys. For those, Q = N(f(x)).

**Its unipotent symmetry is trivial in the Lazard range [argued].**
1. Over F̄_p, N is a product of r independent linear forms. So
   Stab_{GL_r}(N) is the norm-one torus times the permutations of the
   forms that commute with Frobenius, that is, T_1 ⋊ Gal.
2. Its p-elements therefore lie in Gal, which has order r. So none exist
   for r < p.
3. Affine maps preserving N(x + k) fix the vertex −k, so they are
   τ_k^{−1} Stab_{GL}(N) τ_k.
4. When p | r, σ^{r/p} has order p. F_q is a free F_{q'}[C_p]-module
   (normal basis), so σ^{r/p} has Jordan blocks of size p.
5. A public ambient group containing every possible
   H_k = ⟨τ_{σ'(k)−k} σ'⟩ contains Im(σ'−1) ⋊ ⟨σ'⟩, of class p − 1. That
   class is not fixed.
6. For d = 1 keys, k itself comes from van Dam–Hallgren–Ip's shifted
   Legendre algorithm.

**Computed** (`extfield_legendre_unipotent_check.py/.out`):
- (p,r) = (3,2), (5,2), (5,3), (7,2): no nontrivial unipotent linear map
  preserves N on F_p-points, and the affine unipotent stabilizer of
  N(x + k) is trivial for 3 random k each.
- (p,r) = (3,3): 26 nontrivial unipotent elements. These are the 13
  conjugates of Gal ≅ C_3 under the order-13 torus. Each has
  nilpotency index 3 = p, and every affine one has translation part
  Uk − k.

**Consequence for L1.** The one published family of multivariate
Legendre oracles has trivial unipotent H in the range Theorem `thm:main`
covers. So L1 still has no consumer.

## 3. The survivor: finite-index HSP in UT_n(Z)

### 3.1 Problem

- Input: n ≥ 2 fixed, and G = UT_n(Z), with elements as integer matrices
  (a unique encoding).
- A coherent oracle f on integer matrices of bounded bit-size hides
  H ≤ G, with promise [G:H] = N ≤ 2^b.
- Output: generators of H.

The Mal'cev basis is x_ij = I + E_ij, ordered by distance from the
diagonal. Write G_k for the resulting normal series, with infinite
cyclic factors.

### 3.2 Lemmas [proved; computed; independent AI referee: CORRECT]

**N1.** If H has index N in a nilpotent group G, then g^N ∈ Core_G(H)
for all g.

*Proof.*
1. P = G/Core(H) is finite nilpotent. It acts faithfully and
   transitively on G/H, with stabilizer S.
2. S = ∏_q S_q is the product of its Sylow parts. Each P_q is
   centralized by the other Sylows, so Core_{P_q}(S_q) is normal in P
   and lies in S. Hence it is trivial.
3. So P_q acts faithfully on q^{a_q} points, with N = ∏ q^{a_q}. A
   q-element of Sym(q^a) has cycle lengths that are powers of q, at most
   q^a, so its order divides q^a.
4. Hence exp(P) | N. ∎

**N2.** Let e_ij be the least positive integer with x_ij^{e_ij} ∈ H. Then
e_ij ≤ N (pigeonhole) and N | ∏ e_ij.

*Proof.*
1. N = ∏_k [G_k : G_{k+1}(H ∩ G_k)], because each G_{k+1} is normal in
   G_k.
2. The k-th factor is the index of a subgroup of Z that contains
   x_k^{e_k}, so it divides e_k. ∎

The map t ↦ f(x_ij^t) hides e_ij Z, so Shor/Kitaev period finding
returns e_ij. Here x_ij^t = I + tE_ij has O(b) bits, and f(x^e) = f(I)
verifies each period.

**N3.** If (n−1)!·N′ | M, every g ∈ Γ(M) = ker(UT_n(Z) → UT_n(Z/M)) is
an N′-th power in UT_n(Z).

*Proof.* With M = (n−1)!·c·N′, log(g)/N′ is (n−1)! times an integer
strictly upper triangular matrix. Each term (log(g)/N′)^j / j! with
j ≤ n−1 is then integral, so Y = exp(log(g)/N′) ∈ UT_n(Z) and
Y^{N′} = g. ∎

The factor (n−1)! cannot be dropped: the control M = N′ gives
non-integral roots in 9 to 48 of 60 trials for n = 3 to 6. In a
torsion-free nilpotent group roots are unique, so those g have no
integral root.

Checks:
- `finite_index_lemmas_check.g/.out` (GAP): 26 random subgroups of
  UT_4(Z/12), UT_4(Z/10) and UT_5(Z/6), most non-normal. N | ∏ e_ij and
  exp(G/Core) | N held every time; 0 failures. This tests N1 and N2 on
  the finite quotients.
- `congruence_root_check.py/.out`: N3 at n = 3 to 6, 0 failures in 240
  trials.

### 3.3 Composition [argued from the lemmas and cited theorems]

1. Set N′ = ∏ e_ij and M = (n−1)!·N′. Then
   Γ(M) ⊆ G^{N′} ⊆ G^N ⊆ Core(H) ⊆ H (N3, then N | N′, then N1).
2. So f̄(ḡ) = f(lift(ḡ)), with lift entries in [0, M), hides H̄ = H/Γ(M)
   in UT_n(Z/M), at one query of f per query of f̄.
3. Factor the e_ij (Shor). By CRT, UT_n(Z/M) = ∏_q UT_n(Z/q^{k_q}).
   H̄ is nilpotent, so it is the product of its Sylow parts, and f̄
   restricted to the q-factor hides the q-part.
   - Primes q that do not divide N′ need no work, since H̄_q is then the
     whole factor. This was the referee's pruning remark.
   - **q > n−1:** a q-group of class n−1 < q, given as matrices (unique
     encoding, explicit multiplication). Cor `cor:black-box-pe` applies,
     at any exponent, conditional on Thm `is-import`.
   - **q ≤ n−1:** Imran–Ivanyos Thm 1 [cited, arXiv 2304.08376]:
     bounded class, prime factors bounded by a constant, unique
     encoding, exact. Unbounded exponent is allowed; the theorem bounds
     primes, not exponent (its "Related results" paragraph). The referee
     flagged this hypothesis, and it is confirmed.
4. Generators of H are the lifts of generators of H̄, together with
   I + M E_ij, which generate Γ(M) (peel the grades in order).
5. Cost: poly(b) queries and time for fixed n. Conditional only on Thm
   `is-import`, together with Shor, Kitaev and Imran–Ivanyos.

### 3.4 Filters and limits

- **Class ≤ 2.** n = 3 (the discrete Heisenberg group) needs only ISS at
  every prime, so it is not new for Rees. Rees is needed for n ≥ 4 when
  primes q > n−1 divide the index. These may be about 2^b, which is
  outside bounded-prime methods and outside FIMSS (bounded exponent).
- **Classical.** Reducing mod p transfers the classical query lower bound
  of `prop:classical-query` for UT_n(F_p), m = n(n−1)/2: set
  f(g) = f_p(g mod p). But n = 2, period finding in Z, is already
  classically hard. So this separation is not specific to the
  non-abelian structure (referee point 4), and must not be presented
  that way.
- **Not an application.** f is an opaque oracle; no native f is known.
  This is the TRAPS 3 / audit contract item 1 failure, unchanged.
- **Arbitrary subgroups G ≤ UT_n(Z).** As stated, the composition is
  **wrong**. The referee's counterexample: n = 2, G = ⟨I + 4E_12⟩,
  H = ⟨I + 8E_12⟩, e = 2, M = 2. Then Γ(2) ∩ G = G ⊄ H.
  - The referee proposed a fix [argued, not checked]. Pass to the
    integral points V(Z) of the Zariski closure, with
    d = [V(Z) : G], and use M = (n−1)!·d·N′. If g = Y^{dN′} with
    Y ∈ V(Z), then Y^d ∈ Core(G) by N1.
  - The fix needs V(Z) and d computed classically, with log d
    polynomially bounded. Only G = UT_n(Z) is claimed here.
- **Prior art.** Horan–Kahrobaei (2018, §5 "Infinite" [cited]) say the
  non-abelian infinite HSP "has not been addressed within the
  literature". Kuperberg (2025, §1 [cited]) solves Z^k with arbitrary
  (also infinite-index) H, plus virtually abelian groups.
  - UT_n(Z), n ≥ 3, is not virtually abelian.
  - Lemmas N1–N3 are elementary and may be folklore (congruence-subgroup
    arguments for nilpotent groups).
  - No search beyond these sources was made. Priority is NEEDS HUMAN
    VERIFICATION.

**Verdict:** a correct-looking conditional corollary that widens the
input model to an externally posed case. It is not a natural problem
with a concrete f, and it does not change the "no application" sentence.

## 5. Motivation assessment (no application)

What the paper can honestly say, ranked by strength. Each sentence is
true as of this pass, and none implies an application.

1. **Imran–Ivanyos open question (strongest, external).** Their §6 asks
   for the bounded-class, smooth-order case, and their Prop 3 says a
   randomized zero-sum finder at poly(np) would give a non-exact
   algorithm. Cor `cor:black-box-pe` answers the p-group part
   non-exactly at every p > c, without smoothness, and by scalar weights
   instead of zero-sum sequences. The paper already says this in "What
   is new". It should lead the motivation, not sit at the end of a
   paragraph.
2. **Automorphism-free grading (the structural point).** Earlier
   class ≥ 3 methods need automorphisms of G that preserve H and scale
   the centre. Characteristically nilpotent algebras such as
   Dixmier–Lister have none (`prop:dl-central-scalars`). So the cover is
   a method whose correctness does not depend on Aut(G).
3. **Matrix p-groups (the standard family).** Every p-subgroup of
   GL_n(F_p) with n ≤ p consists of unipotent matrices. By Kolchin it is
   conjugate into UT_n(F_p), so the algebra generated by g_i − I
   satisfies N^n = 0, hence N^p = 0. §8(a) therefore covers every linear
   p-group in defining characteristic of bounded class, with no
   conjugation needed.
4. **Infinite nilpotent groups (Section 3).** Optional, and conditional
   on owner approval and a priority check.
5. **Group-based cryptography.** KFN 2023 and HK 2018 list the HSP over
   nilpotent and polycyclic platforms as open problems. The schemes
   checked reduce to something else (K1–K6). The paper should say so
   rather than leave the impression of a cryptanalytic use.
