## 1. Mechanism class X and three lemmas

**Class X** (at a prime p, for each κ | p−1, κ ≤ 9) is defined recursively. The κ-solvers are:
- (a) S1;
- (b) chains (Cor. plus-chain) of any length L ≥ 1, with any steps (D_t, Δ_t, Ω_t), D_t | κ and
  any |Ω_t|, whose base is Gaussian elimination (GE) or an X-solver at a proper divisor D_0;
- (c) ℓ-level {0}-contractions (Lemma plus-ell-node) for every ℓ ≥ 1;
- (d) plans (Lemmas plus-stage and plus-finish), with any s ≥ 1, as follows.
  - The node is a {0,m}-node from (b) or (c), or H_{κ/2}.
  - The finish is F0, or F_K for an Ω-node K. K is one of: GE, H_{D′} for D′ | κ, a chain of
    (b), or an ℓ-level Ω-contraction.

X contains every candidate of Def. plus-schedule: it drops the restrictions L ≤ 3, |Ω_t| ≤ 3,
p ≤ 523, "five tables only" and "U_m only at κ = 7". It also uses the same coset generator
ξ = g throughout.

**Lemma A (two-level = TL; PROVED, AI-checked).** A two-level {0}-contraction at (p, κ) exists iff
RC(κ; Z_κ → {0}) is available.
- *Proof.* W^⊥ = span(z), so Ann(W⊗W) = z⊗F^κ + F^κ⊗z, that is, C_ij = z_i a_j + b_i z_j.
- Put α_j = a_j/z_j and β_i = b_i/z_i. Then C_ij = z_i z_j(α_j + β_i).
  - cl(C_ij) = i + j + cl(α_j + β_i), so the class condition (i) of Def. plus-ell is exactly that
    of Def. plus-rc with Ω = {0}.
  - C_00 = α_0 + β_0, which is (ii).
- The converse is the same formula read backwards. ∎

**Lemma B (chains are tables; PROVED, AI-checked).** Let (GE; σ_1, …, σ_L) be a chain with
D_t | κ, D_L = κ and Ω_L = {0}. It defines an (L+1)-level {0}-contraction at (p, κ).
- This is Lemma P of `2026-11-13-rees-k9-below-21.md` §3, which was already checked on every chain
  witness there. I re-derived it as follows.
- Put C^{(1)}_m = z_m. Normalise C^{(t−1)} by C^{(t−1)}_0, an element of P_{D_{t−1}}; this changes
  no D_{t−1}-class. Then set
  C^{(t)}_{(y′,m)} = C^{(t−1)}_{y′} · z_m · (α^t_{m mod D_t} + β^t_{i(y′)}),
  where i(y′) = cl_{D_t}(C^{(t−1)}_{y′}).
- i(y′) lies in lift(Ω_{t−1}) = Δ_t, because the P_κ-weights have D_t-class 0. The class
  condition of σ_t gives cl_{D_t}(C^{(t)}) ∈ Ω_t.
- Expand the factor in brackets. The α-term is C^{(t−1)} ⊗ (zα), which lies in
  Ann(W^{⊗(t−1)}) ⊗ F. The β-term is (C^{(t−1)}β) ⊗ z, which lies in F^{⊗(t−1)} ⊗ z. So
  C^{(t)} ∈ Ann(W^{⊗t}).
- Finally C^{(L)}_0 = α^L_0 + β^L_0 ∈ P_κ. ∎

**Lemma C (floors in X; PROVED given the core's own lower-bound argument in the proof of
lem:plus-exponent).** Let κ ≥ 3.
1. Every X-solver has degree ≥ 2. It has degree 2 iff TL_κ is available.
   - S1 has degree κL ≥ 3.
   - A chain has degree e_0 + L. This equals 2 only for (GE; (κ, Z_κ, {0})), which is TL_κ.
   - A one-level table has C ∝ z, so it hits every class. Two-level tables are TL_κ by Lemma A.
   - A plan has degree s·e_N + e_F. Every {0,m}-node in X with m ≠ 0 has degree ≥ 2 when κ ≥ 3.
     The only equality case left, s = 1 with F0, is inadmissible, because 0 ∈ T_1 would force
     ξ^{−m} ∈ P.
2. For κ = 9, degree 3 requires one of: (α) TW available; (β) a three-level {0}-contraction;
   (γ) a degree-2 {0,m}-node together with an admissible F1, that is, T_1 ⊇ F_p^×.
   - S1 has degree ≥ 9.
   - A chain with base H_3 and one step at modulus 9 has Δ = lift_9{0} = {0,3,6}, so the step is TW.
   - A chain with base GE and two steps is (β) by Lemma B. Three-level tables are (β) directly.
   - A plan needs s = 1 and e_N + e_F = 3. The only degree-1 finish is GE, which gives F1. The
     case e_N = 3 with F0 is inadmissible.
3. {0}-contractions do not depend on ξ, so each UNSAT holds for every coset generator.
   - Replace ξ by ξ^u. Set C′_y = C_{uy mod κ} · Π_r t_{y_r}, where t_m = ξ^{um}/z_{um mod κ} ∈ P.
   - This maps contractions to contractions.
   - Check: (37,9,ℓ=3) is UNSAT for ξ = 5 as well (`lifted_37.out`, 10 s).

## 7. Adversarial self-check

1. **Is X really the core's calculus?** Lemma C uses only the candidate list of Def.
   plus-schedule, enlarged.
   - Grade d always uses κ_d = gcd(d, p−1) through Lemma bezout. A different reduction per grade,
     or solving several grades jointly, is outside X.
   - So is the "multiples" idea. That is why X⁺ is reported separately.
2. **Lemma C(1)'s plan case.** It relies on "every {0,m}-node in X with m ≠ 0 has degree ≥ 2 for
   κ ≥ 3". The nodes in X are:
   - chains: degree ≥ 2;
   - one-level tables: they force Ω = Z_κ ≠ {0,m};
   - H_{κ/2}: degree ≥ 2 by induction, since κ/2 ≥ 2.
   For κ = 2, {0,1} = Z_2 and GE qualifies. But κ = 2 is at its floor 2 anyway, by
   rem:kappa-two and the core argument.
3. **Degree-1 finishes.** These are degree-1 Ω-nodes. In X they are GE (a one-level table, so
   Ω = Z_κ); chains and H_{D′} have degree ≥ 2. So only F1 occurs, and the counting kills it at
   (37, 9).
4. **Encoding soundness for UNSAT.**
   - Exactly-one constraints are imposed on the cells only. The auxiliary sum variables have
     implications only: a true solution sets them to the true sums, and spurious true values only
     add constraints.
   - So any real contraction yields a model, and UNSAT is sound.
   - The B(0) = 1 normalisation is scaling by B(0)^{−1} ∈ P.
   - The LRAT certificate covers the solver; it does not cover the encoder. The encoder's
     correctness is argued above, controlled on 16 instances with known answers, and agrees with
     an independently written encoding.
5. **The B-form reduction.** (W^{⊗ℓ})^⊥ = Σ_r F ⊗ … ⊗ span(z) ⊗ … ⊗ F, and dividing by z^y gives
   the mixed-difference condition. This is standard; it also matches app normal form and k9 §2.
6. **ξ.** For p < 2·10⁶ the paper uses g. Lemma C(3) and the ξ = 5 rerun at 37 make the {0}
   results ξ-independent anyway. The ξ-independence proof was not checked by a second agent.
7. **DFS completeness.** β_0 = 0 is translation. The scaling normalisation maps β ↦ sβ and α ↦ sα
   with s ∈ P_D, which keeps α_0 ∈ P_D and every class. Positive controls exist for D = 4, 6, 7, 9.

   - X⁺ at 631.
   - Three-level searches at 43, 73, 127 and 181.
