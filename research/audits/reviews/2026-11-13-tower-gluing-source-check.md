## 2. Full ray group, explicit subgroup and cutoff

Let K have degree N, absolute discriminant |D|, and nonzero coefficients
(a1,a2,a3,a4). Let S contain all primes above2 and all numerator/denominator
support of the coefficients. Put d1=-a1*a2, d2=-a3*a4 and, for proof only,

    M = K(sqrt(d1),sqrt(d2)),
    m0 = product_{P in S} P^(2*v_P(2)+1),
    m  = m0 times every real place,
    C  = Cl_m(K),
    H0 = kernel(C -> Gal(M/K)).

Quadratic conductors divide m: outside S the extensions are unramified;
at P in S every element of 1+P^(2*v_P(2)+1) is a local square, so local
quadratic characters are trivial there. All real places are explicitly
included. Thus the Artin map factors through C, and

    [C:H0] = [M:K] <= 4.

For P outside S, membership [P]_m in H0 is equivalent to complete splitting
in M, hence to BOTH d1 and d2 being nonzero squares modulo P. They are units
and the residue characteristic is odd there. This equivalence still applies
when one or both quadratic extensions are trivial or coincide.

Apply Theorem1.2 with the source's auxiliary ideal h=(1). If H0 is nontrivial,
it is generated by degree-one prime ideals outside S with [P]_m in H0 and

    NP < B,
    B = ([C:H0] * (2.71*log(|D|*Nm0)
                   + 1.29*r1 + 1.38*omega(m0)) + 4.13)^2.

The logarithm is natural, r1 is the number of real embeddings, and omega
counts DISTINCT prime-ideal factors, not rational primes. The source proof
uses <=B at LF863 although the statement uses <B; the slack cutoff below
contains either convention and does not rely on that boundary discrepancy.
If H0 is trivial its image modulo squares is trivial and needs no generators.

Define bD=bitlength(|D|), bm=bitlength(Nm0), L=2+N+bD+bm. Then

    log(|D|*Nm0) <= bD+bm,
    r1 <= N, omega(m0) <= bm,
    sqrt(B) <= 10.84*bD + 16.36*bm + 5.16*N + 4.13 < 32*L.

Consequently the explicit INTEGER cutoff

    X = (32*L)^2

safely includes a generating set. This is an explicit source-backed
replacement for the paid report's (C*Lambda)^8 with unspecified C.

No ray class group, class field, M, principal ray generator, or Artin table is
constructed by the algorithm. Enumerate rational primes p<=X, decompose
p*O_K, discard primes in S, retain degree-one primes of norm<=X whose two
residue square tests succeed. Keeping additional higher-residue-degree split
primes with norm<=X is harmless; degree-one primes alone suffice for the
proof. At most N*X candidates occur. Enumeration, decomposition, residue
arithmetic and required integer factoring remain charged. This is polynomial
in expanded input size only with the stipulated native field arithmetic and
expanded backends; it is not a logarithmic-in-X enumeration claim.

## 3. Why the square quotient preserves the needed local classes

Assume q is isotropic and both binary summands are anisotropic. Some
isotropic vector supplies a nonzero common value

    b0 = a1*x1^2+a2*x2^2 = -a3*x3^2-a4*x4^2.

At P outside S, all coefficients and d1,d2 are units and P is nondyadic.
The binary representation equations force (d1,b0)_P=(d2,b0)_P=1.
For a unit d at an odd prime, an odd valuation of b0 forces d to be a
local square. Thus every outside-S odd-valuation prime of b0 splits in M.
Write its fractional ideal outside S as

    (b0)_(S-complement) = J*I^2,

where J is squarefree and [J]_m lies in H0. Negative odd valuations cause no
problem: choose parity1 in J and allow I to be fractional. The small split
primes generate H0, so their images generate the image of H0 in C/2C.
Choose a squarefree product J_X of such primes satisfying

    [J]_m = [J_X]_m in C/2C.

Reducing generator exponents modulo2 is legitimate; discarded even powers
are absorbed into an ideal square. The definition of C/2C gives

    J/J_X = A^2*(c),

with A prime to S and c congruent1 modulo every P^(2*v_P(2)+1) in S,
and c positive at every real place. Hence c is a local square at all those
places, and

    (b0/c)_(S-complement) = J_X*(I*A)^2.

For T=S union the enumerated split primes, b0/c belongs to K(T,2) and has
exactly b0's local squareclasses at S and at every real place. At added
primes both d_i are local squares; outside T the valuation of b0/c is even.
Thus no unrecorded local obstruction remains. The original local Hilbert
and real-sign system is feasible on the stipulated complete K(T,2) basis.
The correct finite local equations are

    (d1,b)_P = (a1,a2)_P,
    (d2,b)_P = (-a3,-a4)_P.

At the added split primes their right-hand sides are1 and the equations
are automatic. Standard local-global ternary isotropy then justifies the
stipulated witness-solving step; its arithmetic/output cost is not removed.
Neither b0 nor c is an algorithmic input or something this argument computes.

The split-prime condition is essential for OMITTING the new-prime rows.
An added nonsplit prime is not automatically fatal (even valuations can be
harmless), but an odd valuation there can violate a Hilbert equation. Merely
matching the original local data does not imply global feasibility.

## 4. Exact Sage falsifiers: only the prescribed rational case

Executed with `/opt/anaconda3/envs/qsearch-cas/bin/sage -c`, wrapped using
`/opt/anaconda3/bin/python`. Computations used exact QQ Hilbert symbols,
QQ.is_padic_square, valuations and Kronecker symbols; no float residual,
class-group/unit call, parameter sweep or tower construction was used.

For q=<1,1,-3,-7>, S={2,3,7}, the vector (1,3,1,1) is isotropic and both
binary values equal10. Exhausting the sixteen S-supported rational
squareclasses +/-2^u*3^v*7^w (u,v,w in {0,1}) is one fixed-case check:
positivity plus the first binary Hilbert equations leave exactly b=1,2;
no class satisfies both binary systems. In each case at7,
(-21,b)_7=1 while (3,7)_7=-1. The prime5 has residue symbols
(-1/5)=(-21/5)=1; adding it allows b=10.

assert first == [1,2] and full == []
