## 1. Question and Answer

The [conductor-order audit](NATIVE_RLWE_CONDUCTOR_ORDER_AUDIT.md) left open
ideal-class transport as a potential mechanism. Within the GENERIC NATIVE
FAMILY, that mechanism has a precise classical classification. Let

```
R=Z[X]/(X^d+1), q prime3mod8, d>=4 power-two,
O_0=R+Rj, O_q=R+qRj, j^2=-1,
Lambda_M={(g,f):g=Mf modq}.
```

Restrict to M a unit modq and beta=1+M*bar(M) a unit modq. Then two native
fractional left O_q ideals are equivalent if and only if their ratios belong
to the SAME public dihedral orbit generated by

```
R_action(M)=X^2*M, T_action(M)=-M^-1.
R_action^d=T_action^2=1, T_action*R_action*T_action=R_action^-1.
```

This public D_d action has order2d. A single polynomial ring inverse and2d
signed rotations give a canonical class label in polynomial bit complexity.
The label is NOT a hidden oracle. No short native relation is found by this
classification, and no claim about arbitrary quaternion ideal classes follows.

## 2. Global Equivalence Proof

Suppose Lambda_N=Lambda_M*alpha for an invertible quaternion alpha. Both
native ideals saturate to O_0 because their beta residues are units. Therefore

```
O_0 = O_0*Lambda_N = (O_0*Lambda_M)*alpha = O_0*alpha.
```

So alpha is a UNIT of O_0, not an arbitrary small quaternion or local unit.
The earlier global proof, using the published full real 2-power unit-signature
theorem, gives alpha=v*X^k or alpha=v*X^k*j, up to sign, with v a central
real unit. The central unit does not change the ratio or the underlying
integer lattice: v*Lambda=Lambda.

Right multiplication by X^k sends (g,f) to (gX^k,fX^-k), hence ratio
M to X^(2k)M. Right j sends (g,f) to (-f,g), hence ratio M to -M^-1.
Conversely these exact units transport the full lattice, proving sufficiency.
For the canonical word R^k*T, the RIGHT unit is j*X^k=X^-k*j. Switching
the exponent sign here gives the wrong target; basis-column tests enforce it.

These transports are signed coefficient isometries. Thus equivalent native
ideals admit a CHEAP EXACT isometry, not just a class equivalence with unknown
metric distortion. Canonicalizing the public label cannot improve lattice
successive minima or create a new geometric quantum advantage. A central unit
may change a chosen vector's length while permuting the same lattice; that is
not a new class or lattice geometry.

## 3. Exact Source Counts

Write x=q^(d/2). The CRT source is E x E with |E|=x and conjugation swapping
the factors. Units have both factors nonzero: (x-1)^2. Exclude the x-1 unit
ratios with norm -1, where beta vanishes. The generic source has

```
G=(x-1)*(x-2) ratios among x^2,
Pr_generic=(x-1)*(x-2)/x^2.
```

Rotations act freely because X^2 has exact order d and M is a unit. A fixed
reflection R^k*T requires M^2=-X^(2k). Its norm squares to one. The generic
restriction excludes norm -1, so norm M=1. Put l=X^(k+d/2), with
l^2=-X^(2k); then z=M/l satisfies z^2=1 and norm z=1. In E x E the only
such z are the scalar +/-1. Thus exactly the2d signed monomials have a
reflection stabilizer. They form TWO parity orbits, each of size d.
Every other generic orbit has size2d. Consequently

```
Number of classes represented by generic native source = G/(2d)+1.
```

The division is exact since x=1 mod2d in this CRT regime. This is NOT the
entire class number of O_q, a hardness bound, or an exponential computational
cost: all public class labels in this family are efficiently canonicalized.
The source has many distinct classes, but labeling a GIVEN class is classical.

Complete controls: d4/q3 gives56 ratios in8 classes (two size4, six size8).
d8/q3 gives6320 ratios in396 classes (two size8,394 size16). The actual
saved native d64 ratio has128 distinct orbit members. Every control includes
the whole stated source subset, not a favorable reroll or a planted secret.
Finite source enumeration is exponential calibration, not an algorithm claim.

## 4. Why This Changes The Research Target

An ideal-class oracle restricted to these public native inputs is not a new
quantum primitive. The class equivalence and transport are already available
classically and preserve geometry. HSP stabilizer finding on this PUBLIC
dihedral action likewise does not supply an unknown short relation or an RLWE
secret. A secret-dependent quantum state would need its own sourced reduction.

Algorithms moving to arbitrary nonnative representatives are NOT excluded.
Their transport element, height, precision, level data and final native
short-element guarantee remain essential. In particular, invoking isogeny
paths or quaternion smooth norms is not enough.

[Kohel, Lauter, Petit and Tignol](https://arxiv.org/html/1406.0981) study a
classical heuristic polynomial algorithm for smooth-norm representatives of
maximal quaternion ideals over Q. Their Section3.1 starts with a reduced
four-dimensional ideal basis. That does not supply a growing-degree native
short basis, an algorithm for this nonmaximal O_q, or a short original-metric
output. The input dimension and ideal promises must survive any proposed
transfer. This is a parameter mismatch audit, not a theorem excluding KLPT
extensions or algorithms over larger totally real centers.

Highest-impact surviving tasks:

1. Construct a truly source-valid quantum SHORT-NONGENERATOR primitive, not
   class labeling, PIP, public finite dihedral transport or saturation.
2. For nonnative class transport, prove an actual map and its native geometric
   output before adding quantum walks or amplitude amplification around it.
3. A KLPT-inspired extension must replace its reduced-basis and fixed-dimension
   assumptions explicitly; do not hide native short-vector search in setup.
4. Kill any apparent advantage with the existing native lattice cover and
   matched classical short-element algorithms on growing hard parameters.
