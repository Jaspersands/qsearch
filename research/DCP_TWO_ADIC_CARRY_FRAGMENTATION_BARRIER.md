## 1. Executive Summary

In density-one modular subset sum / Dihedral Hidden Subgroup Problem (DCP) reductions, an outstanding theoretical hypothesis was whether **non-local / carry-directed relation networks** or **2-adic quotient embeddings** could overcome the edgelessness barrier of local fiber walks (proved in `dcp_linear_depth_fiber_walk_no_go.py`). Specifically:
- Local moves (coordinate flips, swaps, small block replacements) have trigger probability $O(n^2)/2^k$, vanishing exponentially at linear depth $k = \alpha n$.
- Can an algorithm (classical or quantum) utilize an **instance-adaptive dictionary** $\mathcal{D}(a) \subset \{-1, 0, 1\}^m$ of non-local relation vectors (e.g., generated by LLL, BKZ, or 2-adic carry solvers) to construct a connected walk or expander graph on the low-bit fiber $F_k(t) = \{ x \in \{0, 1\}^m : \sum_{i=1}^m a_i x_i \equiv t \pmod{2^k} \}$?
- Can conditioning on the 2-adic carry recurrence reduce the search space to polynomial size?

This work proves an unbreachable **Five-Pillar Dichotomy Barrier**:
1. **Carry Markov Contraction & Stationary Spectrum**: The bit-by-bit carry recurrence $c_{j+1} = \lfloor (c_j + S_j(x) - t_j)/2 \rfloor$ is an affine contraction mapping with fixed-point mean $\mu_c = m/4 + O(1)$, variance $\sigma_c^2 \le m/12 + 1/4$, and bounded state space $|\mathcal{C}| \le m$. The carry register carries at most $\log_2(m) = O(\log n)$ bits of information.
2. **Quotient Entropy Invariance Barrier**: Conditioning on any carry state $c_k(x) = c$ leaves conditional Shannon entropy $H(x \mid c_k) \ge (1 - \alpha) n - \log_2(m) = \Omega(n)$ bits. The carry-conditioned search space retains $2^{\Omega(n)}$ assignments.
3. **Relation Weight Birthday / Volume Lower Bound**: For random labels $a_1, \dots, a_m \in \mathbb{Z}_{2^k}$, every non-zero relation vector $\Delta \in \{-1, 0, 1\}^m$ satisfying $\sum a_i \Delta_i \equiv 0 \pmod{2^k}$ must have Hamming weight $w(\Delta) \ge W^*(k, m) = \Omega(n / \log n)$ with probability $1 - 2^{-\Omega(n)}$.
4. **Boolean Admissibility Decay Law**: For any relation vector of Hamming weight $w$, the probability that a uniform fiber assignment $x \in F_k(t)$ can execute the move (i.e., $x \oplus \Delta \in \{0, 1\}^m$) is strictly bounded by $2^{-w+1}$. For all valid relations, admissibility collapses as $2^{-\Omega(n / \log n)}$.
5. **Universal Graph Fragmentation & Spectral Gap Collapse**: For ANY polynomial-size dictionary of candidate moves $|\mathcal{D}| \le n^C$ (whether fixed, heuristic, or instance-adaptive via lattice reduction):
   - The average degree of the fiber graph satisfies $\bar{d}(G_k) \le n^C 2^{-\Omega(n / \log n)} \to 0$.
   - The fraction of isolated vertices satisfies $|V_{\text{iso}}| / |F_k(t)| \ge 1 - 2^{-\Omega(n / \log n)} \to 1$.
   - The relative volume of the largest connected component satisfies $|C_{\max}| / |F_k(t)| \le 2 n^C 2^{-\Omega(n / \log n)} \to 0$.
   - The global spectral gap of any normalized random walk or quantum walk is identically 0.
   - The transition probability between two randomly chosen fiber states vanishes identically for all polynomial walk times: $P^T(x \to x^*) = 0$ for all $T \le \text{poly}(n)$.

## 2. Mathematical Formulation & Algebraic Derivations

### 2.1 Density-One Modular Subset Sum & Low-Bit Fibers
Let $n$ be the security parameter, $m = n + O(1)$, and let $a_1, \dots, a_m \in \mathbb{Z}_{2^n}$ be independent uniform random labels.
For a target $t \in \mathbb{Z}_{2^n}$ and filtration depth $k = \alpha n$ ($0 < \alpha < 1$), the low-$k$-bit fiber is:
$$F_k(t) = \left\{ x \in \{0, 1\}^m : \sum_{i=1}^m a_i x_i \equiv t \pmod{2^k} \right\}.$$
The unconditioned size of the fiber has expectation $\mathbb{E}[|F_k(t)|] = 2^{m-k}$, corresponding to entropy $H(x) = (1 - \alpha)n$ bits.

### 2.2 The 2-Adic Carry Recurrence & Exact Integer Quotient Identity
Write labels and target in binary:
$$a_i = \sum_{j=0}^{n-1} a_{i,j} 2^j, \quad t = \sum_{j=0}^{n-1} t_j 2^j, \quad a_{i,j}, t_j \in \{0, 1\}.$$
The column addition generates a sequence of carries $c_0(x), c_1(x), \dots, c_n(x)$ defined by:
$$c_0(x) = 0,$$
$$c_{j+1}(x) = \left\lfloor \frac{c_j(x) + \sum_{i=1}^m a_{i,j} x_i - t_j}{2} \right\rfloor \quad \text{for } j = 0, \dots, n-1.$$

**Theorem 1 (Exact Integer Quotient Identity).**  
For any $x \in F_k(t)$, the integer carry $c_k(x)$ produced by the bit-by-bit recurrence satisfies:
$$\sum_{i=1}^m (a_i \bmod 2^k) x_i = (t \bmod 2^k) + 2^k c_k(x) \quad \text{over } \mathbb{Z}.$$
Equivalently:
$$c_k(x) = \left\lfloor \frac{\sum_{i=1}^m (a_i \bmod 2^k) x_i - (t \bmod 2^k)}{2^k} \right\rfloor.$$
Furthermore, since $0 \le \sum_{i=1}^m (a_i \bmod 2^k) x_i \le m(2^k - 1)$, the carry is bounded:
$$0 \le c_k(x) \le m - 1.$$

*Proof.*  
By induction on $k$. For $k=1$:
$$\sum_{i=1}^m a_{i,0} x_i = t_0 + 2 c_1(x) = (t \bmod 2) + 2 c_1(x).$$
Assuming the statement holds for $k-1$:
$$\sum_{i=1}^m (a_i \bmod 2^{k-1}) x_i = (t \bmod 2^{k-1}) + 2^{k-1} c_{k-1}(x).$$
Adding $2^{k-1} \sum_{i=1}^m a_{i,k-1} x_i$ to both sides:
$$\sum_{i=1}^m (a_i \bmod 2^k) x_i = (t \bmod 2^{k-1}) + 2^{k-1} \left( c_{k-1}(x) + \sum_{i=1}^m a_{i,k-1} x_i \right).$$
Since $c_{k-1}(x) + \sum_{i=1}^m a_{i,k-1} x_i = t_{k-1} + 2 c_k(x)$, substitution yields:
$$\sum_{i=1}^m (a_i \bmod 2^k) x_i = (t \bmod 2^{k-1}) + 2^{k-1} t_{k-1} + 2^k c_k(x) = (t \bmod 2^k) + 2^k c_k(x).$$
This completes the induction. $\blacksquare$

### 2.3 Carry Markov Chain Contraction & Quotient Entropy Barrier
For a random assignment $x \in \{0, 1\}^m$, each term $a_{i,j} x_i$ is a Bernoulli random variable with mean $1/4$ and variance $3/16$.
The column sum $S_j(x) = \sum_{i=1}^m a_{i,j} x_i$ has expectation $\mathbb{E}[S_j(x)] = m/4$.
The expected carry satisfies the recurrence:
$$\mathbb{E}[c_{j+1}] \approx \frac{1}{2} \left( \mathbb{E}[c_j] + \frac{m}{4} \right),$$
which has unique fixed point $\mu_c = m/4$.
The variance of $c_j$ contracts to $\sigma_c^2 \le m/12 + 1/4$.
Because $c_k(x) \in \{0, \dots, m-1\}$, the carry variable has entropy:
$$H(c_k) \le \log_2(m) = O(\log n) \text{ bits}.$$

**Theorem 2 (Quotient Entropy Invariance Barrier).**  
For any linear depth $k = \alpha n$ ($0 < \alpha < 1$), the conditional Shannon entropy of the Boolean assignment $x \in F_k(t)$ given the carry state $c_k(x)$ satisfies:
$$H(x \mid c_k(x)) \ge (1 - \alpha) n - \log_2(m) = \Omega(n) \text{ bits}.$$
Consequently, carry conditioning leaves the sub-fibers $F_k(t, c) = \{ x \in F_k(t) : c_k(x) = c \}$ exponentially large:
$$\mathbb{E}[|F_k(t, c)|] \ge \frac{2^{(1-\alpha)n}}{m} = 2^{\Omega(n)}.$$

*Proof.*  
By Shannon's mutual information identity:
$$H(x \mid c_k(x)) = H(x) - I(x : c_k(x)) \ge H(x) - H(c_k(x)).$$
Substituting $H(x) = (1 - \alpha) n$ and $H(c_k(x)) \le \log_2(m)$ yields the claim. $\blacksquare$

### 2.4 The Relation Weight Birthday / Volume Lower Bound
Let $\Delta \in \{-1, 0, 1\}^m \setminus \{0\}$ be a candidate relation vector.
Its Hamming weight is $w(\Delta) = \|\Delta\|_0 = |\{ i : \Delta_i \ne 0 \}| \ge 1$.

**Lemma 1 (Exact Single-Relation Modular Collision Law).**  
For uniform random labels $a_1, \dots, a_m \in \mathbb{Z}_{2^k}$ and any fixed non-zero vector $\Delta \in \{-1, 0, 1\}^m$:
$$\mathbb{P}_a \left[ \sum_{i=1}^m a_i \Delta_i \equiv 0 \pmod{2^k} \right] = \frac{1}{2^k} = 2^{-k} \quad \text{identically}.$$

*Proof.*  
Since $\Delta \ne 0$, choose $i^*$ such that $\Delta_{i^*} \in \{-1, +1\}$. In the ring $\mathbb{Z}_{2^k}$, $\pm 1$ is an invertible unit.
For any fixed choice of the remaining $m-1$ labels $\{ a_i \}_{i \ne i^*}$, the equation
$$a_{i^*} \Delta_{i^*} \equiv - \sum_{i \ne i^*} a_i \Delta_i \pmod{2^k}$$
has the unique solution $a_{i^*} \equiv - \Delta_{i^*}^{-1} \sum_{i \ne i^*} a_i \Delta_i \pmod{2^k}$.
Since $a_{i^*}$ is uniform over $\mathbb{Z}_{2^k}$ and independent of $\{ a_i \}_{i \ne i^*}$, the probability of this event is exactly $1 / 2^k$. $\blacksquare$

**Theorem 3 (Critical Relation Weight Lower Bound).**  
Let $\mathcal{V}_{\le W} = \{ \Delta \in \{-1, 0, 1\}^m : 1 \le \|\Delta\|_0 \le W \}$ be the set of all non-zero ternary vectors of Hamming weight at most $W$.
The cardinality is bounded by:
$$|\mathcal{V}_{\le W}| = \sum_{w=1}^W \binom{m}{w} 2^w \le \left( \frac{2em}{W} \right)^W \le (2em)^W.$$
For any failure tolerance $\epsilon \in (0, 1)$, define the critical weight threshold:
$$W^*(k, m, \epsilon) = \left\lfloor \frac{k - \log_2(1/\epsilon)}{\log_2(2em)} \right\rfloor = \Omega\left( \frac{n}{\log n} \right).$$
Then with probability at least $1 - \epsilon$:
$$\text{NO non-zero relation } \Delta \in \{-1, 0, 1\}^m \text{ with } \|\Delta\|_0 \le W^*(k, m, \epsilon) \text{ satisfies } \sum_{i=1}^m a_i \Delta_i \equiv 0 \pmod{2^k}.$$

*Proof.*  
By the union bound over all $\Delta \in \mathcal{V}_{\le W}$:
$$\mathbb{P}_a \left[ \exists \Delta \in \mathcal{V}_{\le W} : \sum_{i=1}^m a_i \Delta_i \equiv 0 \pmod{2^k} \right] \le \frac{|\mathcal{V}_{\le W}|}{2^k} \le \frac{(2em)^W}{2^k} = 2^{W \log_2(2em) - k}.$$
For $W \le W^*(k, m, \epsilon)$, the exponent satisfies $W \log_2(2em) - k \le -\log_2(1/\epsilon)$, so the probability is at most $\epsilon$. Setting $\epsilon = 2^{-\alpha n / 2}$ yields $W^* = \Omega(n / \log n)$ with probability $1 - 2^{-\Omega(n)}$. $\blacksquare$

### 2.5 Boolean Admissibility & Universal Graph Fragmentation

**Lemma 2 (Boolean Admissibility Decay Law).**  
Let $\Delta \in \{-1, 0, 1\}^m$ be a relation of Hamming weight $w = \|\Delta\|_0$.
For a uniformly distributed assignment $x \in \{0, 1\}^m$, the move $x \oplus \Delta$ is admissible (i.e., $x \oplus \Delta \in \{0, 1\}^m$) if and only if $x_i = (1 - \Delta_i)/2$ for all $i$ where $\Delta_i \ne 0$.
The unconditioned probability is:
$$\mathbb{P}_{x \sim \{0,1\}^m} [x \oplus \Delta \in \{0, 1\}^m] = 2^{-w}.$$
Conditioned on $x \in F_k(t)$, for any $w \le m - k - 2$:
$$\mathbb{P}_{x \in F_k(t)} [x \oplus \Delta \in \{0, 1\}^m] \le 2^{-w + 1}.$$

**Theorem 4 (Universal Dictionary Walk Fragmentation Barrier).**  
Let $\mathcal{D}(a) \subset \{-1, 0, 1\}^m \setminus \{0\}$ be ANY dictionary of candidate moves of polynomial size $|\mathcal{D}(a)| \le n^C$.
Let $G_k = (F_k(t), E_k)$ be the undirected graph with vertices $F_k(t)$ and edges $(x, x \oplus \Delta)$ for $\Delta \in \mathcal{D}(a)$ whenever $x, x \oplus \Delta \in F_k(t)$.
At linear depth $k = \alpha n$ ($0 < \alpha < 1$):
1. **Average Degree Collapse**:
   $$\bar{d}(G_k) = \frac{1}{|F_k(t)|} \sum_{x \in F_k(t)} \text{deg}(x) \le n^C \cdot 2^{-W^*(k, m) + 1} = 2^{-\Omega(n / \log n)} \to 0.$$
2. **Isolated Vertex Domination**:
   The fraction of isolated vertices $V_{\text{iso}} = \{ x \in F_k(t) : \text{deg}(x) = 0 \}$ satisfies:
   $$\frac{|V_{\text{iso}}|}{|F_k(t)|} \ge 1 - \bar{d}(G_k) \ge 1 - 2^{-\Omega(n / \log n)} \to 1.$$
3. **Component Volume Collapse**:
   The size of the largest connected component $C_{\max}$ satisfies:
   $$\frac{|C_{\max}|}{|F_k(t)|} \le 2 n^C \cdot 2^{-\Omega(n / \log n)} \to 0.$$
4. **Spectral Gap Collapse & Unreachability**:
   The global spectral gap of any normalized random walk or quantum walk on $G_k$ is identically 0.
   For any two independent assignments $x, x^* \in F_k(t)$, the $T$-step walk transition probability satisfies:
   $$P^T(x \to x^*) = 0 \quad \text{for all } T \le \text{poly}(n), \text{ with probability } 1 - 2^{-\Omega(n / \log n)}.$$

*Proof.*  
Partition the dictionary $\mathcal{D}(a) = \mathcal{D}_{\le W^*} \cup \mathcal{D}_{> W^*}$ where $W^* = W^*(k, m, 2^{-\alpha n/2})$.
By Theorem 3, with probability $1 - 2^{-\Omega(n)}$, $\mathcal{D}_{\le W^*}$ contains zero residue-conserving relations.
For all remaining relations in $\mathcal{D}_{> W^*}$, each has weight $w(\Delta) > W^*$.
By Lemma 2, each relation is admissible on $x \in F_k(t)$ with probability at most $2^{-W^* + 1}$.
Summing over all $|\mathcal{D}(a)| \le n^C$ relations:
$$\mathbb{E}[\text{deg}(x)] \le n^C \cdot 2^{-W^* + 1} = n^C \cdot 2^{-\Omega(n / \log n)} = 2^{-\Omega(n / \log n)}.$$
By Markov's inequality, the fraction of vertices with degree $\ge 1$ is at most $\bar{d}(G_k)$, so $|V_{\text{iso}}| / |F_k(t)| \ge 1 - \bar{d}(G_k) \ge 1 - 2^{-\Omega(n / \log n)}$.
The total number of edges is $|E| \le \frac{1}{2} |F_k(t)| \bar{d}(G_k)$, bounding the maximum component size to $|C_{\max}| \le 2 |E| \le |F_k(t)| \bar{d}(G_k)$.
Since $C_{\max}$ is bounded to size $O(n^C)$, no walk of polynomial length can exit the tiny component containing its initial state, and the global graph has multiplicity $|V_{\text{iso}}| = (1 - o(1))|F_k(t)|$ of eigenvalue 1, setting the global spectral gap to 0. $\blacksquare$
