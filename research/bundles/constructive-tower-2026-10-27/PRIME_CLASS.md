# Sample A Prime Divisor Instead Of Assuming A Uniform Class

Status: independently reviewed counting deduction; see REVIEW_RESOLUTION.md. It specifies
an implementable sampler GIVEN the actual bounded curve representation; no
native higher-genus prime or code is generated by this document.

Fix an existing tower curve of degree e>=8, q=100003, g=5e+1, d=2g+1,
D the22e rational evaluation points, and a=deg(K-3G+D)=2e-9. Let H be the
set of degree-d divisor classes with ell(K-3G+D)>0. The already reviewed
generic-class argument gives

    |H|/h <= B_e = 9^(5e+1)(5e+1)/(q^(3e+9)*315^2),

where h=#J(F_q). This includes the rational3-torsion multiplicity. It does
not assert that a random prime has a uniform class.

Every degree-d rational divisor class has exactly

    M_d = (q^(d-g+1)-1)/(q-1) = (q^(g+2)-1)/(q-1)

effective representatives, by Riemann-Roch. Therefore it has AT MOST M_d
prime representatives. If N_d denotes all degree-d closed primes, uniform
prime sampling gives

    Pr([G] in H) <= |H| M_d/N_d.

The prior prime-count estimate supplies N_d >= q^d/(2d) whenever
q^d >= 4(g+1)^2(d+6)^2, which holds here for all e>=8. The Weil bound gives
h <= (sqrt(q)+1)^(2g) < 318^(2g). Thus

    Pr(bad prime) <= B_e * (2d*q/(q-1)) * (318^2/q)^g.       (1)

This is extremely small even though the prime CLASS distribution has not
been shown close to uniform. The factor M_d is essential; dropping it would
incorrectly transfer the uniform-class probability. The RHS decreases with e:
B_(e+1)/B_e < 2*9^5/q^3, d_(e+1)/d_e<2, and (318^2/q)^5<2, so the ratio
is below8*9^5/q^3<1 for e>=8. Verify the base e=8 exactly. This also proves
the sampler has good classes in its support, without a mixing assumption.

Construct H0(jH0) for a degree-(2g+2) embedding line bundle H0 through j=6.
With i=2, d=2g+1 <= 2deg(H0)-2g=2g+4. The primary
[Bruin Algorithm3.2](https://arxiv.org/html/1003.2563) gives a uniformly
distributed closed prime of degree d. It includes a factor-selection acceptance
correction; picking an arbitrary component of a random section is NOT equivalent.
Its expected cost is polynomial in g under the above prime-count lower bound:
a given prime occurs in a random section with probability
(q^(3g+5-d)-1)/(q^(3g+5)-1), and the correction divides by
floor((4g+4)/d)=2. Overall acceptance is Omega(1/d).

Because d>1, sampled G has no rational point in its support, so it is disjoint
from D automatically. Compute the complete L(G), evaluate it in the original
field, verify rank k=g+2 and Schur square3g+3, and compute the Schur cube.
Reject and resample if the cube does not have rank m. The exact geometric
identity dim((V^3)^perp)=ell(K-3G+D) makes that a sound Las Vegas acceptance
test, not a probability-based admission. Expected prime proposals are at most
1/(1-RHS(1)). Cube products and elimination are polynomial in m,k.

The output is not asserted uniform over Pic^d, matrices or native witnesses.
Rejection does give uniformity on the
set of good degree-d primes, assuming the exact underlying prime sampler.
This argument removes only the uniform-class and disjoint-representative
obligations, conditional on the curve/RR access contract. It proves neither
classical hardness nor a quantum advantage.
