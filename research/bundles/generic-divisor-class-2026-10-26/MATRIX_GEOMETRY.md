## A Known Recovery Mechanism Relevant To This Attack

The auxiliary-code construction currently takes geometric data. That is
an access obligation, but it is not evidence of protection from a classical
matrix-only algorithm. Recovering AG representations from code matrices is
prior art:
[Marquez-Corbella, Martinez-Moro, Pellikaan and Ruano (2014)](https://www.sciencedirect.com/science/article/pii/S0747717113001740).
The following elementary argument explains the quadratic-information part.

Assume the ORIGINAL input B really generates the COMPLETE evaluation code
V=ev_D L(G), with d=deg G>=2g+1 and m=deg D>2d. This is an input promise,
not something the dimensions alone certify. If k=dim V and w=dim V^2,
normal generation and injective evaluation give

    d=w-k,       g=w-2k+1.

Take each nonzero column of B as a projective point of P^(k-1). Form the
m-by-binomial(k+1,2) matrix of all degree-two coordinate monomials at
these columns. Its kernel consists of the quadrics vanishing at the
evaluation points. A quadratic evaluated on the curve is a section of
O_X(2G). If it vanishes at all m>2d points, that section is zero.
Therefore the recovered kernel is EXACTLY I_2(X), not merely a sample
approximation. The computation is ordinary finite-field linear algebra.

This argument is basis invariant and tolerates nonzero scaling of matrix
columns: homogeneous equations have the same zero set. Such scaling must
still be tracked when transferring a native full-support witness back to
the ORIGINAL matrix; projective recovery does not authorize silently
changing B or s.

## Safe Degree Range Versus The Borderline

For d>=2g+2 the classical quadratic-generation theorem says the full
homogeneous ideal is generated by I_2(X). Thus the preceding computation
already gives an explicit projective presentation, under the AG promise.
The precise degree endpoint is also recalled in
[Brown-Erman, Linear syzygies of curves in weighted projective space](https://www.cambridge.org/core/journals/compositio-mathematica/article/linear-syzygies-of-curves-in-weighted-projective-space/C7B17880FDA1605421F0E5297B3E64BA).
This is not a newly discovered reconstruction method.

Our main construction instead has d=2g+1. Quadrics and cubics suffice
there, but quadrics alone can fail. The possible extra lines, isolated
points and scrolls are described by
[Serrano, A Note on Quadrics Through an Algebraic Curve](https://diposit.ub.edu/server/api/core/bitstreams/cf353b34-79f5-4f63-bf51-1832b38abece/content).
Do not assume universal quadratic generation at that boundary. In
particular, the cubic kernel of the evaluation matrix is NOT automatically
I_3(X): m<3d here, so extra sections can vanish on D without vanishing
identically. A Groebner-basis call or a numerical rank cannot erase this
distinction.

For the actual new degree-eight matrix: k43,w126,m176 imply d83,g41.
Its quadratic-relation dimension is binomial(44,2)-126=820. Since176>166,
these are true curve quadrics. But its full cubic evaluation rank176
is smaller than ell(3G)=209, leaving33 curve sections invisible on D.
This is exactly why copying the evaluation cubic kernel into the curve
ideal would be an error. No ideal-generation computation was performed.

## A One-Degree Mutation Does Not Evade This Classical Threat

On the SAME tower curve choose d=2g+2=10e+4 instead. Then

    k=5e+4,   w=15e+8,   m=22e,
    deg(K-3G+D)=2e-12.

For e>=8, m>2d and the previous short-square quantum sufficient estimate
remains at most p^12(2/p^2)^e, below256/p^4 at e=8. The generic-class
counting method applies to this changed residual degree too. But this
mutation places the code in the guaranteed quadratic-reconstruction
range. Adding this degree cannot be justified as hiding geometry.
These are derived parameter identities, not a generated matrix family.

## What Recovery Still Does Not Give For Free

If quadratic generation is established, bounded-degree pieces of the
homogeneous coordinate algebra can be computed by linear algebra on
monomials modulo products of the known quadratic generators. For a FIXED
maximum degree, such as7, the number of monomials is polynomial in k.
This is a potentially expensive polynomial, not a practical implementation.

[Bruin's input contract](https://arxiv.org/html/1003.2563) uses explicit
truncated graded multiplication, and additionally the zeta polynomial
for its uniform Jacobian sampler. The hyperplane line bundle and
evaluation points are available from the presentation. Matching its local
trivializations with B, producing canonical/divisor arithmetic, obtaining
the zeta data, and computing class coordinates still require charged
algorithms. The prime-coset search retains its2^(r_2/2) cost even when all
access becomes polynomial. No rank bound follows from knowing equations.
