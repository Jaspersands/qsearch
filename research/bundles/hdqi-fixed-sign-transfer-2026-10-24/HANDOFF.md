# Bounded Integration Handoff

This bundle is outside the unverified migrating checkout. Do not copy into
Desktop or migration staging. Verify the authoritative local repository
first. No commit, push, UI work, new agent, or automated search is required
for this handoff.

1. Read TRANSFER.md and retain its LOCAL UNREVIEWED status. This is a
   fixed-sign transfer audit, not a new Gibbs sampler or a refutation of
   the published random-sign theorem.
2. After migration is verified, integrate the fixed-sign obligation into
   the existing proof/reduction ledger. A fixed target must bound coherent
   bad mass w, not just decoder failure r. An independent-sign average
   cannot be used as a fixed-input certificate.
3. Preserve the exact native input, Pauli phases, target normalization,
   decoder environment, pilot approximation error and enumeration costs.
   The new certify_transfer function certifies only IDEAL pilot transfer;
   it does not certify pilot preparation, reversible decoder cost, classical
   hardness, or a useful output distribution.
4. Add the repeated-term countercertificate as a negative transfer test,
   not a new CandidateRecord. Keep random-sign and injective positive
   controls. Low-weight collisions and budget exhaustion must refuse
   certification with reasons; they are not classical-hardness evidence.
5. Keep ker B (scalar aliases) distinct from ker X minus ker B (physical
   diagonal interference). Apply the existing classical baselines to any
   surviving family before claiming progress toward advantage.
6. Run this bundle's tests, regenerate receipt.json, compare every source
   hash, and run the repository's existing validation after integration.
   The external test run is not whole-repository validation.

The remaining task for a reasoning model is a concrete family/reduction,
not more wiring: specify a sign-preserving native output task, bound its
fixed-sign transfer, price its quantum source, and attack its classical
sampling law. Known hard circuit-parent inputs already have known quantum
preparation, so a new contribution must explain what it improves.
