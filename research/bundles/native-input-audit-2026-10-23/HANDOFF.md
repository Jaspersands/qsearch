Do not edit the moving source or migration staging. After the destination
is verified, attach NATIVE_INPUT_GATE.md to the existing source proof chain.

Keep these distinctions explicit in the existing registry, without adding
a new generic subsystem:

- Genuine weak evaluator supplied: eligible for the conditional source theorem.
- Only bare varieties or independently pairing-compatible auxiliary data:
  missing global-isogeny input obligation, not an accepted source.
- The exact density bound rejects uniform independent mark fabrication,
  not all source-acquisition algorithms and not honest weak evaluations.
- Receiver controls and a conditional surface IsERP extension do not imply
  general isogeny pathfinding, a protocol break, or Shor-level significance.
- Padding a partially known source with known factors does not repair the
  missing-order obligation: the one-sided stabilizer can be identical for
  every secret gluing. Keep the precise coset-state limitation, not a claim
  that every quantum algorithm for partial-source inputs is impossible.

The arithmetic code is a proof diagnostic, not a geometric consistency
validator. The next implementation should target a real input bridge or
same-input attack, not create more synthetic candidate families.
