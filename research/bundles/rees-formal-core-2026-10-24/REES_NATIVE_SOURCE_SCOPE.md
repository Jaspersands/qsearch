# Native Copy-Only Rees Acquisition

2026-10-24. Machine-checked source acquisition and composition, conditional
on native input and public-operation contracts. Not an executed quantum
algorithm, efficient circuit implementation, novelty certificate or speedup.

## Selection And Input Model

The preceding pass proved recursive Rees conversion but supplied its
top-stage source. This pass first reread the main research priorities,
class-three application audit, succinct-polynomial filters and HPGP
interface audit. The obvious graph/code/low-degree applications are already
covered; high formal degree alone does not escape their classical attacks.
No defensible new hard application emerged from reusing those routes.

The selected question is therefore concrete: does the original copy-only
input actually produce the top-stage source with the claimed cost, without
a hiding-function oracle, inverse preparation, or rare postselection?

Input is independent copies of the normalized mixed left-coset source

    rho_H[x,y] = |G|^(-1) * 1[y^(-1)*x in H].

H is unknown. Public group arithmetic and the specified evaluation maps
must be reversible, and a fresh uniform address must be preparable. No
routine that reads H, a hidden lift, or the source-preparation inverse is
provided to the operational definition. Public GROUP inversion is used;
it must not be confused with inversion of an unknown source preparation.

## Checked Channel

For public homomorphisms phi_i:A->G and independent target sources rho_Hi,
prepare a uniform A address and apply

    |a>|t_i> -> |a>|t_i * phi_i(a)^(-1)>.

Uncompute the public evaluation work and discard the targets. For an
arbitrary address/reference matrix, the resulting entries are multiplied
by 1[r^(-1)q in intersection_i phi_i^(-1)(H_i)]. With a uniform address,
this is exactly the normalized mixed coset source of that preimage group.

ReesNativeSource.lean derives this from the literal controlled permutation
and partial trace. It first proves the native regular correlation equals
the subgroup indicator. No injectivity, surjectivity or hidden kernel
information is needed for the general pullback. In particular, a public
free-Lie preimage map can use this identity once its separately charged
group-homomorphism implementation has been supplied.

The actual Rees construction uses one source per evaluation point. Its
preimage subgroup is proved equal to the constructed hidden Lie subgroup
of the cover. A public full-prefix inverse makes the top quotient an actual
group equivalence, with the correct hidden image and cardinality. Relabeling
by this bijection yields the exact top-stage density used by the previous
recursive proof. The native source is now substituted into both its
retained-record and averaged source-tree theorems.

This resolves the formal top-source-input gap. It does not implement the
uniform coordinate-state preparation or a reversible finite-field compiler.
The displayed density maps use explicit finite sums, not an efficient
classical simulation or a quantum circuit extraction.

## Resource Consequence And Falsifiers

For class c and c evaluation points, one top-stage preparation consumes c
native copies. A terminal source therefore consumes

    c * product_(j=2..c) M_j

native copies, using the previously checked fresh-leaf product. There is
no success-probability denominator in this acquisition. Final receiver
copies, operation time, workspace and approximation errors remain charged
separately in REES_RESOURCE_AND_PRIOR_ART.md.

The finite physical control uses the actual two-step Rees cover of a
Heisenberg Lie algebra over F_3. It tests trivial, full and nonhomogeneous
noncentral hidden subgroups. The channel accepts only target density
matrices, not the hidden-subgroup description used by the expectation
checker. A one-map noninjective control also has unit trace and the correct
preimage source without conditioning on its kernel.

- Left multiplication instead of the specified right multiplication gives
  output trace distance approximately 0.59259259 from the required source.
- Retaining the injective evaluation tuple as garbage dephases the address,
  giving trace distance 2/3 in this control.
- Naively projecting two original target registers onto the Rees evaluation
  image succeeds with probability 1/9 here. For r independent Heisenberg
  factors over a promised odd prime p, group order is p^(3r), cover order
  p^(4r), and that projection probability is p^(-2r). This exact dimension
  count proves the naive acquisition can have exponential overhead. The
  controlled channel still uses two independent native copies.

These controls falsify interface shortcuts. They do not establish a new
algorithm by extrapolating a small group. The universal acquisition and
composition identities are checked separately by Lean.

## Remaining Scientific Obligations

The intended Lazard application still needs the base BCH law and full
subgroup-to-Lie-subalgebra correspondence, and effective public group/Lie
coordinates or the separately justified public free pullback. Complete
central-character plans and nonzero diagonal witnesses remain algorithmic
inputs to the recursive theorem. The final Fourier/nullspace receiver,
total precision/runtime certificate and efficient coherent compiler are not
formalized here. Correlated target banks are still excluded.

This source conversion is not claimed as a new principle. Subgroup-state
conversion already appears in [Imran--Ivanyos, sections 2.3--2.4](https://arxiv.org/html/2304.08376v1).
The purpose is to verify its actual use in this proposed Rees construction,
not count a standard ingredient as a discovery. No new independent review
was commissioned this pass.

The largest impact risk remains a correct but unimportant conditional
algorithm. Keep the explicit native classical filters and novelty review
active. Do not replace the missing application with an opaque-label
benchmark, or mark a speedup gate passed because this receipt is green.
