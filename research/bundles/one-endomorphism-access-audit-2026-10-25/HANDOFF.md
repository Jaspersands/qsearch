# Handoff: Keep The Input Promises Separate

This pass produces scoped negative results, not a new promoted algorithm.
ACCESS_CEILING.md contains the proofs, exceptions and live higher-upside
questions. Main source/staging/Git were not changed. The retained rigidity
note is an exact read-only snapshot, not an edited successor proof.

When mechanical integration is safe:

- Import the receipt's negative records with their explicit operation/input
  scopes. Never label them a quantum lower bound or a no-go for geometry.
- Reject using the full-rank suborder transcript solver on a quadratic
  action. Its projective commutant must be one-dimensional for that solver.
- Keep arbitrary primitive-map degree, a chosen minimal representative,
  and a known common degree multiple distinct. The h^k countercontrol
  invalidates only the universal primitive-map bound for quadratic input.
- Product stabilization and correctly typed Frobenius arrows cannot by
  themselves promote rank-two knowledge to a full quaternion order.
  Preserve the known-self-Frobenius/noncommuting-operator exception.
- A Gram-invariant query set needs an actual closure/recovery argument;
  the previous HSP receiver cannot be attached just because each individual
  matrix has a valid polarization.

The full-rank proposed source is neither withdrawn nor certified by this
audit. Independent combined-proof review is still pending. Do not spend a
wiring pass inventing that proof, adding more small matrix benchmarks, or
promoting a candidate without an explicit native algorithmic mechanism.
