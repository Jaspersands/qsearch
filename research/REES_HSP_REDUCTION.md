## 1. The Question And Input Contract

Can ordinary-oracle access make an arbitrary hidden subgroup invariant
under public scalar dilations, without learning a hidden potential or
recursively computing hidden intersections first?

Input: genuine explicit structure constants for an n-dimensional Lie
algebra L over F_p, odd prime p, fixed nilpotency class c<p, and coherent
ordinary hiding function f on its Lazard group G=exp(L). Use the convention
f(x)=f(y) iff x^-1*y belongs to H. The output sought is a basis of h=log(H).
Lazard subgroup correspondence makes h an F_p Lie subalgebra.

No black-box-to-Lie conversion is implicit. No quantum state source is
silently promoted to an ordinary oracle. The prime may grow, but c is
fixed. Prime powers, unrestricted growing class, dihedral groups, GI, code equivalence,
and cryptanalytic applications do not follow from this statement.

## 2. Public Homogeneous Cover

Let gamma_1(L)=L and gamma_(r+1)(L)=[L,gamma_r(L)]. Define

    A = direct_sum_(r=1..c) t^r gamma_r(L)  subset L[t].

Use the actual pointwise polynomial bracket. Since
[gamma_r,gamma_s] is contained in gamma_(r+s), A is closed; for r+s>c
the bracket is genuinely zero. A is not obtained by arbitrarily discarding
nonzero polynomial coefficients. Jacobi and nilpotency are inherited.
It has dimension D=sum_r dim gamma_r(L)<=cn and class at most c.

Crucially A_1=tL, NOT L/[L,L]. Original derived and central directions
remain in grade one and also occur at later grades. This duplication is
what allows full recovery rather than only an abelianized image.

There is a useful dimension lower bound WITHIN THIS COVER ANSATZ. If B is
any positively graded Lie algebra with a Lie homomorphism pi:B->L such
that pi(B_1)=L, then gamma_r(L) is contained in pi(B_r): lift each input
of an r-fold bracket to B_1 and use the homomorphism law. Hence
dim B_r>=dim gamma_r(L), and dim B>=sum_r dim gamma_r(L). Our A attains
this bound. This is not a lower bound on all HSP algorithms or all oracle
reductions, but it rules out dimension compression while retaining this
particular public degree-one-surjection interface. A is generated by A_1;
graded/Carnot covers are therefore also relevant prior-art terminology.

For every s in F_p, evaluation E_s:A->L is a Lie homomorphism. For nonzero
s, Delta_s(a(t))=a(st) is an automorphism of A, scaling grade r by s^r.
All these statements pass to BCH groups because c<p. Choose c distinct
nonzero evaluation points s_1,...,s_c; 1,...,c suffice.

## 3. Exact Ordinary-Oracle Reduction

Define on exp(A):

    f_hat(a) = (f(exp(E_s1(log a))), ..., f(exp(E_sc(log a)))).

The operational map has no H, h, potential, or hidden coefficient input.
It uses exactly c original queries. Reversibly compute each evaluation,
query f into its own output register, and UNCOMPUTE the evaluation
workspace while retaining the input a and the output label. Discarding
uncleaned evaluation workspace instead would destroy coset coherence.
Producing one mixed coset source then discards only the tuple labels.
Oracle label width and the public group encoding are charged to gate
overhead; this query count does not supply a free label table or QRAM.

For a,b in exp(A), put C(t)=log(a^-1*b)=sum_(r=1..c) C_r t^r.
Evaluation is a group homomorphism, so

    f_hat(a)=f_hat(b) iff E_si(C) is in h for every i.

The matrix M_ir=s_i^r is diag(s_i) times an ordinary Vandermonde matrix.
Its determinant is (product_i s_i)(product_(i<j)(s_j-s_i)), nonzero.
Thus C_r=sum_i (M^-1)_ri E_si(C). Linearity of h gives the equivalence

    every E_si(C) in h iff every C_r in h.

Consequently f_hat hides exactly exp(h_tilde), where

    h_tilde = direct_sum_(r=1..c) t^r (h intersect gamma_r(L)).

It is a Lie subalgebra and is invariant under every Delta_s with s!=0.
No transversality, normality of H, or knowledge of any intersection is
required. The intersections occur in the proof, not in the compiler.

This replaces the multivariate potential/jet semidirect construction for
this ordinary-oracle input model. It does NOT invalidate that earlier
work or transfer this reduction to its state-only input model.

## 4. Central Descent Without Transversality

The old uniform-label proof imposed H intersect Z=1. That restriction is
unnecessary, but its normalization cannot simply be reused.

Let Z be an elementary abelian central subgroup of an arbitrary finite G,
K=H intersect Z, R_g|x>=|x*g^-1>, and chi_lambda the additive character.
The mixed coset matrix and central spectral projector are

    rho_H = (1/|G|) sum_(h in H) R_h,
    Pi_lambda = (1/|Z|) sum_(z in Z) chi_lambda(-z) R_z.

Centrality makes Pi commute with rho_H. Character orthogonality gives

    Pr(lambda) = |K|/|Z| if chi_lambda restricted to K is 1,
                 0 otherwise.

For every positive-mass label the NORMALIZED source is

    rho_lambda = (1/(|G|*|K|)) sum_(h,z) chi_lambda(-z) R_(h*z).

Tracing a right action now gives

    Tr(rho_lambda R_g) = chi_lambda(z) if g=h*z belongs to HZ,
                        0 otherwise.

To check this normalization, each g in HZ has exactly |K| decompositions
g=h*z. They give equal character values because lambda annihilates K.
The multiplicity cancels the |K| in the denominator. A forbidden label
is a zero branch and must not be normalized. In the extreme H>=Z only
lambda=0 occurs; this is not a source failure or exponentially rare event.

Suppose Delta_s preserves H and acts on Z by multiplication by s^d.
For fresh sources and observed labels lambda_1,...,lambda_M, solve

    sum_i s_i^d lambda_i = 0,  with (s_i) not all zero.

Apply controlled R_(Delta_si(sigma(q))) on each active target, where
sigma is any public representative map for q in G/Z. Zero-scale sources
are consumed and discarded, not acted on by a nonexistent Delta_0.
Initialize the q register uniformly and trace all targets.

For q,r, write g=sigma(r)^-1*sigma(q). If g is outside HZ, every active
correlation is zero: Delta_si preserves HZ. If g=h*z, the product is
chi_(sum_i s_i^d lambda_i)(z)=1. The output entry is therefore

    (1/|G/Z|) [q^-1*r is in HZ/Z].

This holds for EVERY positive-probability complete label tuple, regardless
of the nonuniform law or the solver's choice among valid witnesses.
The normalized output does not depend on the measured records. Fresh
disjoint preparations give fresh quotient sources recursively. Neither
uniform labels nor an estimate of K is needed. Correct marginal states
alone are insufficient: the existing correlated-source falsifier still
applies. Fourier registers must be restored before literal right actions;
the established full-register instrument supplies this operation.

## 5. Full Recovery And Complexity

At stage d use A/(direct_sum_(r>d) A_r). Its grade d is central,
elementary abelian of rank r_d=dim gamma_d(L), and scales by s^d.
The image of h_tilde remains homogeneous. Apply the preceding conversion
for d=c,...,2. The final quotient is the additive vector space tL.
The image of h_tilde is EXACTLY th. Ordinary abelian Fourier sampling
recovers h perpendicular; a nullspace computation returns all of h.

No hidden-intersection recursion, normalizer, unknown section potential,
image callback, or quantum oracle inversion remains in this composition.
The public compiler does not implement the coherent receiver or a general
SDE solver. Those algorithmic primitives require real implementations,
but the theoretical fixed-degree SDE algorithm is a published ingredient.

A sufficient published SDE arity is

    B_d(r) = [d^(d(d-1)/2) (r+1)^d]^ceil(log2(d+1)).

If d does not divide p-1, reduce the exponent to gcd(d,p-1), solve, and
convert powers using Bezout; the displayed d-bound remains conservative.
Do not replace the solver by a field-sized exhaustive search.

One terminal source costs P=product_(d=2..c) B_d(r_d) lifted sources,
each costing c original f queries. With n+t final samples the total is
c(n+t)P. At fixed c and fixed total error, its dimension exponent is at
most 1+sum_(d=2..c) d*ceil(log2(d+1)); c=9 gives145. This is polynomial
only for FIXED class, not a DCP algorithm.

Use t=ceil(log_p(3/epsilon)); rank failure is at most
1/((p-1)p^t). Count every node of every fresh-source tree. Assign each
solver a capped abort probability epsilon/(3*N_solver), and each full
instrument error epsilon/(3*N_instrument). Hybrid/union bounds apply to
complete instruments with records and abort outcomes, not normalized
rare branches. Exact arithmetic in recovery_budget computes these counts.

## 7. Prior Art And Research Decision

The public lower-central filtration, Rees construction, interpolation,
Lazard correspondence, abelian HSP, and character orthogonality are
standard mathematics, not claimed as new. The potential contribution is
their specific composition making an arbitrary ordinary hidden subgroup
dilation invariant with only c oracle calls per source.

[Ivanyos-Sanselme-Santha, arXiv0707.1260](https://arxiv.org/pdf/0707.1260)
already uses automorphism-twisted right actions and simultaneous linear
and quadratic phase cancellation for nil-2 groups (Proposition1 and
Lemmas5-6). Thus neither scalar automorphisms nor tensor phase erasure is
new here. The proposed cover makes H itself invariant, eliminating the
hidden-element correction in their action law and permitting iteration
at higher grades. This specific extension still needs independent review.

[Ivanyos-Santha, arXiv1503.09016](https://arxiv.org/pdf/1503.09016)
provides the fixed-degree diagonal-equation algorithm and its arity
analysis in Section3. Its stated HSP application concerns certain
semidirect products, not this proposed general Rees composition.

[Imran-Ivanyos, arXiv2304.08376](https://arxiv.org/pdf/2304.08376)
already gives arbitrary-H central-source conversion using zero-sum
subsequences (Lemma2). That conversion is NOT new. Here the proposed
extra ingredient is H-preserving graded dilations, allowing dth-power
weights after the public Rees reduction, rather than binary subsequence
weights. Their stated general fixed-class result also bounds the primes.

These are scope comparisons, not an exhaustive novelty audit. Exact-term
web searches did not identify a Rees-HSP construction, but failure to find
a search hit is not evidence of novelty. Corpus retrieval also returned
existing growing-class descent barriers; this route explicitly does not
evade those barriers. Do not erase or overrule them.

Priority: independent whole-proof and prior-art scrutiny of this short
composition. It is preferable to extending the old potential machinery
for the same input model. Do not admit a breakthrough candidate yet.
After correctness/novelty, find a meaningful explicitly represented
application and attack it with linear/module, low-degree and orbit
algorithms. Worst-case ordinary-oracle HSP hardness is not proof that
such an application exists, and this result would not by itself be
comparable in impact to Shor's algorithm.

### Faithful Operator Compression

Write each input density as rho=|G|^-1 sum_g c(g)R_g. The R_g are linearly
independent in the regular representation. Operator multiplication is
therefore genuine group-algebra convolution, not a predicted target kernel.
The code computes P_lambda*rho*P_lambda^dagger by TWO convolutions, takes
the identity coefficient as the trace/mass, and normalizes only positive
branches. Original source coefficients come from the verified whole coset
partition, not a hidden-subgroup argument to the channel.

For observed packets and public scales it then computes

    F(g)=product_i c_i(Delta_si(g)^-1).

This is the actual product of regular-action traces. Its support is contained
in the intersection of the explicitly transported coefficient supports;
outside that intersection a factor is exactly zero. Every remaining value
is checked, and constancy on EVERY central fiber is tested, not assumed.
If constancy holds, C_out(pi(g)^-1)=F(g) gives the quotient's full regular
operator. Faithfulness then checks every address-pair entry for that record
without allocating a 78125-square matrix. This is a finite numerical check:
group coordinates are exact mod5; character phases use complex floating point.

An independent dense C5^2 test compares convolutions, measured branch masses,
normalized projected matrices and the controlled-action partial trace. Its
nonhomogeneous diagonal subgroup leaves a nonzero character phase, which
the sparse calculation MUST retain. Replacing coefficients by magnitudes
would fail this control. This prevents the harness from simply manufacturing
the desired untwisted coset operator.
