# Response Paths: Collision Ideals And Weighted Unitary Readout

This is a mathematical diagnostic, not an admitted algorithm or universal
quantum lower bound. It uses original public noisy-linear observations. It
does not grant a phase evaluator for an unknown hidden shift, a normalized
fibre oracle, independent fresh observations, or free postselection.

## Why The Previous Collision Argument Failed

Native pair digits are v0=(1,0), v1=(-1,1), v2=(0,-1). Differences of
two-positive-call sums can equal 3*v0: two v0 digits minus v1 and v2.
Modulo9 this is nonzero but NOT a unit. Its random-label collision
probability is1/3 per coordinate, not1/9. Modulo3 it vanishes identically.
The actual M1,n1,q9 two-call collision mean is25/81, not67/243.

For one site, two-call ordered path pairs have counts:

    integer zero:15; nonzero divisible by3:12; unit coefficient:54.

The map from fixed-length occupancy counts to pair coefficients has an
index-three lattice obstruction: if a+b+c=k then (a-b)-(b-c)=k-3b.
Treating these coefficients as arbitrary independent ring elements erases
real structure. More calls can introduce higher valuations. The tool must
calculate the generated ideal, not guess a full-ring uniform law.

## Exact Higher-Call Law

Let k be the number of positive word copies/path phases, M the pair sites,
q=3^d, n the label dimension. For a single site count all ordered k-digit
sums X in Z^2 with multiplicity c_k(X). A forward integer convolution with
the three native digits constructs c_k without enumerating3^k sequences.
There are (k+1)(k+2)/2 distinct sums. The difference histogram is

    h_k(delta)=sum_X c_k(X)*c_k(X-delta), total mass3^(2k).

For each delta=(delta0,delta1), set v(delta)=v3(gcd(q,delta0,delta1)),
with zero moduloq capped at d. Let S_h be the fraction of local ordered
path pairs whose valuation is at least h. At M independent pair sites,
the ideal generated by ALL original-label coefficients has minimum
valuation V. Exactly:

    Pr[V=h]=S_h^M-S_(h+1)^M, h<d;
    Pr[V=d]=S_d^M.

IID uniform original labels map that ideal uniformly to
(3^h Z_q)^n. This follows from the surjective additive group homomorphism
from all original labels onto that ideal; all output fibres have equal
size. Therefore its zero probability is3^(-(d-h)n), including1 at h=d.
The exact population collision density is

    E_A C_k = sum_h Pr[V=h] * 3^(-(d-h)n).

This holds for arbitrary k,M,n,d in the stated IID-label model. The finite
implementation caps exact certificate sizes; exceeding a cap is UNKNOWN,
not an algorithm failure or negative theorem. Counts contain no noise
information and do not certify distinguishability or an implementable
measurement. Correlated/conditioned original labels need a different law.

For k2,d>=2 this reduces to

    (5/27)^M + ((1/3)^M-(5/27)^M)*3^n/q^n
               + (1-(1/3)^M)/q^n.

For d1 it is (1/3)^M+(1-(1/3)^M)/3^n. Multiplying the old
15^M count by an assumed1/N outside the zero class is invalid.

## Actual Two-Call Unitary, Not Two Copies

The measured schedule is F_D^dag D_y F_D D_y |+_D>, D=3^M.
F_D[v,w]=exp(2*pi*i*v*w/D)/sqrt(D). D_y uses phases constructed
from actual public labels, values, and a known mask. It is not a granted
oracle for the unknown secret. The actual native preparation is already
factorized over pair sites; the cyclic Fourier transform is a known
logical unitary, but a physical qutrit circuit is NOT compiled here.

For output x, the amplitude is

    D^(-3/2) sum_(w,v) exp(2*pi*i*(eta_y(w)+eta_y(v))/q)
                         * exp(2*pi*i*v*(w-x)/D).

All path phases are retained. Squaring this sum gives the full D-outcome
Born law, including destructive interference. Root order lcm(q,D) is a
power of three and the bounded controls reduce it exactly in a cyclotomic
field. No probability is set equal to an unweighted collision density.

Under uniform-secret averaging, only pairs of paths with

    f_A(w)+f_A(v) = f_A(w')+f_A(v') modq

survive. Their FOURIER WEIGHTS and original error phases still matter.
The producer verifies this identity two ways: a complete secret census,
and weighted sums grouped by total frequency. Private secret/error data
appear only in the calibration report, never in the readout API.

Two copies projected onto the uniform pair state instead have probability
D^(-4)*|sum_(w,v) exp(i*(eta_y(w)+eta_y(v)))|^2. That is a different
physical schedule. Its collision census cannot certify D_y V D_y for an
arbitrary mixer V. This distinction is an explicit regression test.

## Baseline, Falsifiers And Research Decision

The same public phases permit classical FFT simulation of this particular
measured schedule using D amplitudes and O(D logD) work. D=3^M is exponential
in pair sites. This finite baseline does NOT dequantize the scalable
algorithm; the logical quantum Fourier transform can be much cheaper than
that dense simulation. Conversely, failure of a classical FFT size cap
does NOT establish classical hardness or a quantum advantage.

Every exact probability is normalized; all outcomes are retained; replay
checks the numerical same-data FFT against exact finite probabilities.
Python tests use explicit dense matrices, exhaustive original-label banks,
and brute-force digit sequences. The independent JS checker constructs
local sum counts using multinomial occupancies rather than the producer's
forward convolution, and reconstructs actual weighted path phases.

Next useful work is to find an efficiently implementable weighted schedule
that exposes noise-sensitive information unavailable to paid classical
attacks, then prove scaling and the relevant reduction. Collision ideals
identify terms worth investigating; they do not by themselves supply such
a schedule. Reflection-amplification bounds apply to their specified
reflection family, not every response-dependent quantum computation.

`node research/certificates/native_response_path_valuation_crosscheck.js`.

No novelty, speedup, general impossibility, or new active negative is admitted.
