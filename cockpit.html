Agent cockpit

What the research agents have been doing, read straight from the repository: the shared handoff log, the commit history, the progress snapshot and the working tree. It is rebuilt by a script, not written by hand.

Built by build_cockpit.py from AGENT_HANDOFF.md, git log and git status.

Directions and agents are guessed from wording, so read them as estimates. The README lists the rules and how well they hold up.
