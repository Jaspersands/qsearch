Design Rationale

Why the repository uses a modular layout

Q-Search contains over 788 interconnected theorem verification modules, algebraic reductions, and classical baselines located in theorems/, with the core operating system framework in core/.

This architecture ensures that all theorem scripts, unit test runners, and the unified CLI toolchain (python3 qsearch.py <command>) execute with zero packaging friction, identical path resolution, and an uncluttered root directory.
